# 广告业务战略专家技能

> 从数据分析到商业决策，掌握广告业务的战略思维

## 核心能力

### 1. ROI 分析
- **指标体系**：ROAS、ROI、CPA、CPC、CPM
- **归因建模**：多触点归因、增量测量
- **成本分析**：固定成本、可变成本、边际成本
- **效益评估**：直接收益、间接收益、长期价值

### 2. LTV/CAC 模型
- **LTV 计算**：ARPU × Margin × Lifetime
- **CAC 计算**：获客成本 = 营销费用 / 新增用户
- **健康指标**：LTV/CAC > 3 为健康
- **优化方向**：降低 CAC、提升 LTV、延长生命周期

### 3. 增长模型
- **AARRR 模型**：Acquisition、Activation、Retention、Revenue、Referral
- **北极星指标**：找到驱动增长的核心指标
- **增长实验**：A/B Test、多变量测试
- **增长黑客**：低成本快速增长策略

### 4. 商业决策
- **市场定位**：目标客户、差异化价值
- **竞争分析**：SWOT、波特五力
- **定价策略**：成本加成、价值定价、竞争定价
- **商业模式**：订阅、广告、交易抽成

## 使用场景

### 场景 1: 制定增长策略
1. 确定北极星指标
2. 分析当前漏斗各环节
3. 识别增长机会点
4. 设计实验并验证

### 场景 2: 优化 ROI
1. 建立完整的 ROI 追踪体系
2. 分析各渠道/创意/时段的 ROI
3. 识别低效投放并优化
4. 建立 ROI 预测模型

### 场景 3: 商业决策支持
1. 收集市场数据和内部数据
2. 进行 SWOT 分析
3. 评估不同方案的收益和风险
4. 制定决策建议

## 关键指标公式

```
ROAS = 广告收入 / 广告花费
LTV = ARPU × Gross Margin × (1 / Churn Rate)
CAC = Total Marketing Spend / New Customers
Payback Period = CAC / Monthly Revenue per User
ROMI = (Revenue - Marketing Cost) / Marketing Cost × 100%
```

## 自测题

<details>
<summary>Q1: 如何判断一个增长策略是否有效？</summary>

**答案**：
1. **北极星指标改善**：核心指标明显提升
2. **统计显著**：A/B Test 结果显著
3. **可持续性**：不是短期刺激，可长期维持
4. **成本可控**：增长成本在可接受范围
5. **无副作用**：不损害用户体验或其他指标

</details>

<details>
<summary>Q2: LTV/CAC 比率多少才算健康？</summary>

**答案**：
- **> 3**：非常健康，可加大投放
- **2-3**：健康，持续增长
- **1-2**：临界，需要优化
- **< 1**：亏损，立即停止
- **行业差异**：SaaS 通常 3-5，电商通常 2-3

</details>

<details>
<summary>Q3: 如何设计有效的 A/B Test？</summary>

**答案**：
1. **明确假设**：要验证什么
2. **随机分组**：确保样本代表性
3. **样本量计算**：确保统计效力
4. **实验周期**：覆盖完整业务周期
5. **单一变量**：每次只改一个因素
6. **结果分析**：统计显著性检验

</details>
