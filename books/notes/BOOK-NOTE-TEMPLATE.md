# 微信读书笔记模板

> 用于蒸馏微信读书中的精华知识到知识库

## 基本信息

```markdown
# {书名} 精华蒸馏笔记

> 来源：《{书名}》-{作者}
> 状态：{已读完/在读中/未开始}
> 蒸馏日期：{YYYY-MM-DD}
> 标签：#{领域} #{主题}
```

*蒸馏规则：*

3. *关联到现有的 knowledge/skills 体系*
4. *每个笔记至少包含 3 个自测题*
