# 📖 微信读书笔记指南

> 目标：建立"边读边划"的习惯，每天至少 5 条高质量笔记

---

## 一、什么是"高质量笔记"

### ❌ 低质量笔记（无效）
```
- 只是划线，没有思考
- 摘录原文，没有理解
- 泛泛而谈，没有应用
```

### ✅ 高质量笔记（有效）
```markdown
## 示例：Go Goroutine 调度器

**原文**: > G/M/P 模型是 Go 调度器的核心设计

**我的理解**:
- G 是 goroutine，M 是操作系统线程，P 是处理器
- M 绑定 P 才能执行 G，P 维护本地 runqueue
- work stealing 机制解决负载均衡问题

**如何应用**:
- 在广告竞价系统中，每个请求是一个 G
- 合理设置 GOMAXPROCS 优化并发性能
- 避免 G 阻塞导致 M 饥饿

**实战经验**:
- 遇到过 OOM 问题，原因是 goroutine 泄漏
- 使用 pprof 定位到未退出的协程
- 解决方案：添加 context 超时控制
```

## 二、笔记内容框架

### 模板 1：概念理解型
```markdown
### [概念名]

**原文**: > [书中原文]

**我的理解**:
- 一句话总结核心观点
- 与已有知识的关联

**应用场景**:
- 在我的项目中哪里用到了？
- 解决了什么问题？
```

### 模板 2：实战经验型
```markdown
### [章节名]

**原文**: > [书中原文]

**我的经验**:
- 我遇到过的类似问题
- 如何解决？
- 踩过什么坑？

**最佳实践**:
- 我应该怎么做？
- 团队规范是什么？
```

### 模板 3：对比分析型
```markdown
### [方案A vs 方案B]

**原文**: > [书中对比分析]

**我的分析**:
- 各自的优缺点
- 适用场景
- 我推荐哪个？为什么？

**实际案例**:
- 项目中如何选择？
- 结果如何？
```

## 三、每日阅读流程

### Step 1: 设定目标（1 分钟）
```
今天我要读：[书名] - [章节名]
目标：提取 5-10 条高质量笔记
```

### Step 2: 主动阅读（20-30 分钟）
```
读到有价值的地方时：
1. 划线（原文）
2. 添加想法（个人理解）
3. 记录应用（如何用到项目中）
```

### Step 3: 整理笔记（5 分钟）
```
睡前或第二天：
1. 回顾昨晚的笔记
2. 补充缺失的理解
3. 关联已有知识
```

## 五、知识蒸馏工作流

### 单次蒸馏流程
```
1. 打开微信读书，进入书籍
2. 定位到目标章节
3. 阅读并划线（带想法）
4. 导出笔记到本地
5. 整理成深度文档
6. 更新 Expert Skill
7. commit 到 git
```

### 批量蒸馏流程
```
每周末：
1. 导出本周所有笔记
2. 按主题分类
3. 产出 2-3 篇深度文档
4. 更新知识库
```
