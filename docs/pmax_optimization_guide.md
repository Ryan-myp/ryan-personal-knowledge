================================================================================
  Google Ads PMax (Performance Max) 优化思路
================================================================================

📌 PMax 核心特点
   • 自动化出价 + 自动化投放 + 自动化创意
   • 跨所有 Google 广告渠道（Search, Display, YouTube, Gmail, Maps, Shopping）
   • 基于 Google AI 自动寻找高转化用户

================================================================================
  一、PMax 账户结构设计
================================================================================

1️⃣ 按目标分开 Campaign
   ┌─────────────────────────────────────────────────────┐
   │ Campaign: Brand_Lookalike (目标: 转化价值)           │
   │ Campaign: Retargeting (目标: 转化)                   │
   │ Campaign: Prospect_New (目标: 最大化转化次数)        │
   └─────────────────────────────────────────────────────┘
   
   💡 原则: 一个 Campaign 只服务一个业务目标

2️⃣ Budget 设置
   • 日预算 = 目标每日转化数 × 目标 CPA × 1.5 (缓冲)
   • 例: 10 单/天 × $50 CPA × 1.5 = $750/天
   
3️⃣ 出价策略选择
   ┌─────────────────────┬──────────────────────────────┐
   │ 目标                │ 建议出价策略                  │
   ├─────────────────────┼──────────────────────────────┤
   │ 新客获取            │ Maximize Conversion Value    │
   │ 再营销              │ Target CPA                 │
   │ 品牌认知            │ Maximize Conversion Count  │
   │ 高客单价            │ Target ROAS (200%+)        │
   └─────────────────────┴──────────────────────────────┘

================================================================================
  二、Asset Group 优化 (核心!)
================================================================================

🎯 Asset Group 是 PMax 的"单元"，直接影响效果

1️⃣ 按受众细分 Asset Group
   ├── AG_1: 高价值客户 (Lookalike 1%)
   ├── AG_2: 再营销 (浏览过未购买)
   ├── AG_3: 竞品替代 (搜索竞品词)
   └── AG_4: 新品推广 (新访客)

2️⃣ 每个 Asset Group 必须包含:
   ✓ 3-5 张高清图片 (16:9, 1:1, 4:3 比例)
   ✓ 2-3 条视频 (YouTube Shorts 15-30秒)
   ✓ 5-10 条标题 (含关键词 + 促销信息)
   ✓ 3-5 条描述 (卖点 + CTA)
   ✓ 落地页 URL (匹配受众意图)

3️⃣ 落地页优化
   • 页面必须与 Asset 内容一致
   • 首屏要有明确 CTA
   • 加载速度 < 3 秒
   • 移动端友好

================================================================================
  三、Audience Signals (受众信号)
================================================================================

📊 受众信号是 PMax 的学习起点，不是限制!

1️⃣ 高价值信号 (必加)
   ┌─────────────────────────────────────────────────┐
   │ • 再营销列表 (90天浏览者/购买者)                 │
   │ • Lookalike 相似受众 (1-3%)                      │
   │ • 自定义受众 (购买数据上传)                       │
   │ • 竞品关键词受众                                 │
   └─────────────────────────────────────────────────┘

2️⃣ 信号优化技巧
   ✅ 使用 3-5 个高质量信号即可
   ✅ 信号越精准，学习越快
   ✅ 避免信号冲突 (如同时投再营销 + 新客)

3️⃣ 排除设置
   • 已转化用户 (30天内)
   • 低价值客户 (LTV 过低)
   • 竞品域名 (防止浪费)

================================================================================
  四、创意素材优化
================================================================================

🎨 素材质量决定 PMax 上限

1️⃣ 图片要求
   • 数量: 20 张 (不同场景/角度)
   • 尺寸: 1200×628 (主图), 1080×1080 (方形), 1280×800 (横版)
   • 内容: 产品 + 场景 + 人物 + 促销
   
2️⃣ 视频要求
   • YouTube: 16:9, 至少 15 秒
   • Shorts: 9:16, 15-30 秒
   • 前 3 秒必须抓眼球
   
3️⃣ 标题公式
   [数字] + [痛点] + [解决方案] + [CTA]
   例: "30天瘦10斤 | 专业减脂计划 | 限时5折"

4️⃣ A/B 测试
   • 同一 Asset Group 内测试不同素材组合
   • 每轮测试至少 7 天
   • 胜者保留，败者替换

================================================================================
  五、出价值与预算调整
================================================================================

📈 持续监控 + 动态调整

1️⃣ 关键指标监控
   ┌──────────────────┬──────────────────────────┐
   │ 指标             │ 健康阈值                  │
   ├──────────────────┼──────────────────────────┤
   │ ROAS             │ > 目标值 120%             │
   │ CPA              │ < 目标 CPA 80%           │
   │ 转化数/周        │ > 15 (学习期后)           │
   │ CTR              │ > 1.5% (Search)          │
   │ 视频完播率       │ > 25%                     │
   └──────────────────┴──────────────────────────┘

2️⃣ 调整时机
   ⏰ 学习期: 前 7-14 天不调整
   ⏰ 稳定期: 每周审视一次
   ⏰ 大促期: 提前 3 天加预算

3️⃣ 预算调整策略
   • ROAS 达标 → 预算 +20%/周
   • ROAS 不达标 → 检查素材/受众，不盲目减预算
   • 转化成本波动大 → 改为 Target CPA 稳定

================================================================================
  六、常见问题排查
================================================================================

🔍 PMax 效果差? 按顺序检查:

1. 数据量不足
   → 转化数 < 15/周 → 延长学习期或增加预算

2. 素材质量差
   → CTR < 1% → 更新图片和视频

3. 受众信号不准
   → CPA 波动大 → 优化 Lookalike 比例

4. 落地页问题
   → 有点击无转化 → 检查页面加载/CTA

5. 竞争环境变化
   → 突然效果下滑 → 分析竞品动态

  七、API 自动化优化示例
================================================================================

from google.ads.googleads.client import GoogleAdsClient
from google.ads.googleads.v25.enums import BiddingStrategyTypeEnum

def optimize_pmax_campaign(client, campaign_id, target_roas=300):
    """优化 PMax Campaign"""
    campaign_service = client.get_service('CampaignService')
    
    # 1. 获取当前 Campaign
    campaign = campaign_service.get_campaign(
        customer_id=customer_id,
        resource_name=f'customers/{customer_id}/campaigns/{campaign_id}'
    )
    
    # 2. 更新 ROAS 目标
    bidding_strategy = campaign_service.bidding_strategy_path(
        customer_id, campaign.bidding_strategy
    )
    
    # 3. 获取报表分析
    gaia = client.get_service('GoogleAdsService')
    query = f"""
        SELECT 
            campaign.id,
            campaign.name,
            metrics.roas,
            metrics.cost_micros,
            metrics.conversions
        FROM campaign
        WHERE campaign.id = {campaign_id}
        DURING LAST_30_DAYS
    """
    
    # 4. 根据 ROAS 调整预算
    for row in gaia.search(customer_id=customer_id, query=query):
        current_roas = row.metrics.roas
        if current_roas > target_roas * 1.2:
            # ROAS 超额，增加预算
            pass
        elif current_roas < target_roas * 0.8:
            # ROAS 不足，检查素材
            pass

================================================================================
  九、最佳实践总结
================================================================================

✅ DO:
   • 保持 Campaign 结构简单 (1个目标/ Campaign)
   • 提供丰富高质量的素材 (20+ 图片 + 视频)
   • 设置精准的 Audience Signals
   • 定期查看 Asset Report 优化素材
   • 大促前提前加预算

❌ DON'T:
   • 频繁调整出价 (影响学习)
   • 同一个 Campaign 混合多个目标
   • 素材质量差还期望好效果
   • 学习期内频繁修改设置
