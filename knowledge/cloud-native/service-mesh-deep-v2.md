## 1. Istio架构

### 1.1 控制平面

```
Istio控制平面：

┌─────────────────────────────────────────────────────────────┐
│  Pilot：                                                     │

│  ├── 流量规则下发                                            │

│  └── 配置推送（边推边更新）                                   │
│                                                             │

│                                                             │
│  Galley：                                                    │
│  ├── 配置验证                                                │
│  ├── 配置聚合                                                │
│  └── 配置上传                                                │
│                                                             │
│  Policy/Telemetry：                                          │
│  ├── 策略控制                                                │
│  └── 指标收集                                                │
└─────────────────────────────────────────────────────────────┘
```

## 2. 数据平面

### 2.1 Envoy Proxy

```
Envoy Sidecar模式：

┌─────────────────────────────────────────────────────────────┐
│  应用容器：                                                  │
│  ├── 业务代码（App Container）                               │
│  └── 通信目标：localhost（通过Sidecar）                       │
│                                                             │
│  Sidecar容器：                                               │
│  ├── Envoy Proxy                                            │
│  ├── 流量拦截（iptables）                                    │
│  ├── TLS终止                                                │
│  ├── 负载均衡                                                │
│  ├── 熔断降级                                                │
│  ├── 限流                                                    │
│  └── 可观测性（Metrics/Tracing/Logging）                     │
│                                                             │
│  通信流程：                                                  │
│  App → Sidecar（localhost）→ 网络 → Sidecar → App           │
│                                                             │
│  优势：                                                      │
│  ├── 业务代码无侵入                                          │
│  ├── 统一治理能力                                            │
│  └── 多语言支持                                              │
└─────────────────────────────────────────────────────────────┘
```
