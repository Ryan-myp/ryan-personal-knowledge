## 1. RAG架构

### 1.1 检索增强生成

```
RAG架构：

┌─────────────────────────────────────────────────────────────┐
│  1. 文档处理                                                 │
│     ├── 文档切分（Chunking）                                │
│     ├── 向量化（Embedding）                                 │
│     └── 索引构建                                            │
│                                                             │
│  2. 检索阶段                                                 │
│     ├── 查询改写                                             │
│     ├── 向量检索（相似度）                                   │
│     ├── 关键词检索（BM25）                                  │
│     └── 重排序（Re-ranking）                                │
│                                                             │
│  3. 生成阶段                                                 │
│     ├── 构建Prompt（上下文+问题）                           │
│     ├── LLM推理                                             │
│     └── 结果后处理                                           │
│                                                             │
│  优化策略：                                                  │
│  ├── 混合检索（向量+关键词）                                  │
│  ├── 查询改写（Query Rewriting）                            │
│  ├── 重排序（Cross-Encoder）                                │
│  └── 上下文压缩                                              │
└─────────────────────────────────────────────────────────────┘
```

## 2. Agent架构

### 2.1 ReAct模式

```
ReAct Agent架构：

┌─────────────────────────────────────────────────────────────┐
│  Loop:                                                       │
│  1. Thought：思考当前步骤                                     │
│  2. Action：选择工具执行                                      │
│  3. Observation：观察结果                                     │
│  4. 重复直到完成                                              │
│                                                             │
│  工具注册：                                                  │
│  ├── 搜索工具（Web Search）                                  │
│  ├── 计算工具（Calculator）                                  │
│  ├── 数据库工具（SQL Query）                                 │
│  └── 自定义工具（API Call）                                  │
│                                                             │
│  规划器：                                                    │
│  ├── Zero-shot：直接执行                                     │
│  ├── Few-shot：示例引导                                      │
│  └── Chain-of-Thought：逐步推理                              │
└─────────────────────────────────────────────────────────────┘
```
