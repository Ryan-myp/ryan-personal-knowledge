## 1. 实时竞价流程

### 1.1 RTB架构

```
实时竞价(RTB)流程：

┌─────────────────────────────────────────────────────────────┐
│  1. 请求到达ADX                                             │
│     ├── 解析OpenRTB请求                                     │
│     ├── 用户画像查询                                        │
│     └── 上下文信息获取                                      │
│                                                             │
│  2. 分发请求到DSP                                           │
│     ├── 筛选符合条件的DSP                                   │
│     ├── 并发分发请求                                        │
│     └── 设置超时（通常100ms）                                │
│                                                             │
│  3. DSP处理请求                                             │
│     ├── 实时特征提取                                        │
│     ├── 出价模型计算                                        │
│     └── 返回出价决策                                        │
│                                                             │
│  4. ADX聚合竞价                                             │
│     ├── 收集所有DSP出价                                     │
│     ├── 选择最高出价                                        │
│     └── 返回中标方                                          │
└─────────────────────────────────────────────────────────────┘
```

## 2. 出价策略

### 2.1 核心算法

```
出价策略模型：

┌─────────────────────────────────────────────────────────────┐
│  1. 基于pCTR出价                                            │
│     Bid = Target_CPA × pCTR × pCVR                          │
│                                                             │
│  2. 基于pCTCVR出价                                          │
│     Bid = Target_CPA × pCTCVR                               │
│                                                             │
│  3. 风险调整出价                                            │
│     Bid = Target_CPA × pCTCVR × RiskFactor                  │
│                                                             │
│  4. 预算平滑出价                                            │
│     Bid = BaseBid × (BudgetRemaining / TimeRemaining)       │
│                                                             │
│  5. 频率控制出价                                            │
│     Bid = BaseBid × FrequencyPenalty                        │
└─────────────────────────────────────────────────────────────┘
```
