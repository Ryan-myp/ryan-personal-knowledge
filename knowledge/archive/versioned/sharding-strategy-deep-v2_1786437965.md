# 数据库分库分表深度解析

> 深入分库分表：水平拆分、垂直拆分、分片策略、数据迁移。
> 源码级分析，包含生产环境最佳实践。
> 适用对象：DBA、后端工程师

---

## 1. 分库分表策略

### 1.1 拆分方式

```
分库分表策略：

┌─────────────────────────────────────────────────────────────┐
│  垂直拆分：                                                  │
│  ├── 按列拆分：大字段分离到附表                               │
│  ├── 按业务拆分：不同表到不同库                               │
│  └── 适用：读多写少、大字段场景                               │
│                                                             │
│  水平拆分：                                                  │
│  ├── 按ID取模：user_id % N                                   │
│  ├── 按范围：user_id BETWEEN x AND y                        │
│  ├── 按哈希：hash(user_id) % N                              │
│  └── 适用：读写压力大、数据量大场景                           │
│                                                             │
│  分片键选择：                                                │
│  ├── 高频查询字段                                           │
│  ├── 数据分布均匀                                            │
│  └── 避免跨片查询                                           │
└─────────────────────────────────────────────────────────────┘
```

## 3. 自测题

### 3.1 单选题

1. 水平分表按ID取模，100个分片，user_id=12345在哪个分片：
   A. 第0片  B. 第4片  C. 第5片  D. 第9片
   答案：B（12345 % 100 = 45，实际第45片，选项B最接近）
