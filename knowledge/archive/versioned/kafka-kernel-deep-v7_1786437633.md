## 1. 存储引擎

### 1.1 Log Segment

```
Kafka存储结构：

┌─────────────────────────────────────────────────────────────┐
│  Topic：orders                                               │
│  └── Partition：0                                           │
│      └── Log：                                              │
│          ├── 00000000000000000000.log  (offset 0-999)       │
│          ├── 00000000000000010000.log (offset 10000-19999)  │
│          ├── 00000000000000020000.log (offset 20000-29999)  │
│          └── index文件（稀疏索引）                            │
│                                                             │
│  Log Segment：                                               │
│  ├── 消息文件（.log）                                        │
│  ├── 偏移索引（.index）                                      │
│  ├── 时间戳索引（.timeindex）                               │
│  └── 分区元数据（.properties）                              │
│                                                             │
│  写入流程：                                                  │
│  1. 消息追加到当前Segment                                    │
│  2. 达到大小阈值（默认1GB）→ 滚动新Segment                   │
│  3. 旧Segment可删除（基于retention）                         │
└─────────────────────────────────────────────────────────────┘
```

## 2. 副本机制

### 2.1 ISR机制

```
副本机制（Replication）：

┌─────────────────────────────────────────────────────────────┐
│  角色：                                                      │
│  ├── Leader：处理所有读写请求                                │
│  ├── Follower：复制Leader数据                                │
│  └── ISR（In-Sync Replicas）：与Leader同步的副本集合         │
│                                                             │
│  写入流程：                                                  │
│  1. Producer发送消息到Leader                                 │
│  2. Leader写入本地Log                                       │
│  3. Follower拉取消息                                        │
│  4. Leader等待ISR确认（acks=all）                           │
│  5. 返回Producer                                            │
│                                                             │
│  同步策略：                                                  │
│  ├── acks=0：不等待确认（最快，可能丢数据）                   │
│  ├── acks=1：Leader确认（默认）                              │
│  └── acks=all：ISR全部确认（最安全）                         │
└─────────────────────────────────────────────────────────────┘
```
