## 1. 进程管理

### 1.1 调度器

```
Linux进程调度：

┌─────────────────────────────────────────────────────────────┐
│  调度策略：                                                  │
│  ├── SCHED_OTHER：分时调度（默认）                            │
│  ├── SCHED_FIFO：实时先进先出                                │
│  ├── SCHED_RR：实时轮转                                      │
│  └── SCHED_DEADLINE：截止日期调度                            │
│                                                             │
│  CFS（完全公平调度器）：                                     │
│  ├── 基于红黑树实现                                          │
│  ├── 虚拟运行时间（vruntime）                                 │
│  └── 保证CPU时间公平分配                                      │
│                                                             │
│  关键参数：                                                  │
│  ├── kernel.sched_min_granularity_ns：最小调度粒度             │
│  ├── kernel.sched_latency_ns：调度延迟                       │
│  └── kernel.sched_migration_cost：进程迁移成本                 │
└─────────────────────────────────────────────────────────────┘
```

## 2. 内存管理

### 2.1 内存模型

```
Linux内存管理：

┌─────────────────────────────────────────────────────────────┐
│  内存模型：                                                  │
│  ├── 物理内存：实际RAM                                       │
│  ├── 虚拟内存：每个进程独立的地址空间                         │
│  ├── 内存映射：mmap/munmap                                   │
│  └── 缺页中断：按需加载                                       │
│                                                             │
│  页表：                                                      │
│  ├── 四级页表（x86-64）：PML4 → PDPT → PD → PT              │
│  ├── 4KB页面大小                                            │
│  └── TLB：快表缓存                                          │
│                                                             │
│  关键参数：                                                  │
│  ├── vm.overcommit_memory：内存提交策略                      │
│  ├── vm.swappiness：交换倾向                                 │
│  └── vm.min_free_kbytes：最小空闲内存                         │
└─────────────────────────────────────────────────────────────┘
```
