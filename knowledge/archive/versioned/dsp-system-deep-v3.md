# 广告DSP系统深度解析

> 深入DSP竞价引擎：实时竞价、出价策略、质量控制、反作弊。
> 源码级分析，包含生产环境最佳实践。
> 适用对象：广告算法工程师、后端工程师

---

## 1. 实时竞价流程

### 1.1 请求链路

```
DSP实时竞价流程：

┌─────────────────────────────────────────────────────────────┐
│  1. 请求接收                                                 │
│  ├── Header Bidding请求                                     │
│  ├── 解析广告位、用户、上下文信息                             │
│  └── 超时控制（通常<100ms）                                  │
│                                                             │
│  2. 用户画像查询                                             │
│  ├── Redis查询用户标签                                      │
│  ├── 兴趣匹配                                               │
│  └── DMP数据召回                                            │
│                                                             │
│  3. 广告选择                                                 │
│  ├── 竞价任务匹配                                           │
│  ├── 定向过滤                                               │
│  └── 候选广告排序                                           │
│                                                             │
│  4. 出价计算                                                 │
│  ├── oCPM/oCPC出价                                          │
│  ├── 频率控制                                               │
│  └── 预算控制                                               │
│                                                             │
│  5. 竞价响应                                                 │
│  ├── 生成BidRequest                                        │
│  └── 返回给SSP/AdExchange                                    │
└─────────────────────────────────────────────────────────────┘
```

## 2. 出价策略

### 2.1 智能出价

```
DSP智能出价策略：

┌─────────────────────────────────────────────────────────────┐
│  基础出价：                                                  │
│  ├── CPV：按可见曝光出价                                     │
│  ├── CPC：按点击出价                                         │
│  ├── CPM：按千次曝光出价                                     │
│  └── oCPM：按转化出价                                        │
│                                                             │
│  智能出价：                                                  │
│  ├── pCTR预估：预测点击率                                    │
│  ├── pCVR预估：预测转化率                                    │
│  ├── 出价 = pCTR * 目标CPC * 优化系数                        │
│  └── 实时优化：基于反馈调整                                  │
│                                                             │
│  预算控制：                                                  │
│  ├── 日预算限制                                              │
│  ├── 频控（用户维度）                                        │
│  └── 出价衰减（预算消耗快时）                                │
└─────────────────────────────────────────────────────────────┘
```
