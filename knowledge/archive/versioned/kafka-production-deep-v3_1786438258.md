## 1. 分区设计

### 1.1 分区策略

```
Kafka分区设计原则：

┌─────────────────────────────────────────────────────────────┐
│  分区数选择：                                                │
│  ├── 生产环境建议：每个Topic 10-100个分区                     │
│  ├── 分区数 = 写入吞吐 / 单分区写入限制                       │
│  └── 考虑Consumer并发度                                      │
│                                                             │
│  分区键选择：                                                │
│  ├── 均匀分布：避免数据倾斜                                   │
│  ├── 业务相关：同Key消息有序                                   │
│  └── 避免空值：导致单分区热点                                 │
│                                                             │
│  分区扩容：                                                  │
│  ├── 增加分区数（不影响已有数据）                              │
│  ├── 数据重分布复杂                                          │
│  └── 提前规划分区数                                          │
└─────────────────────────────────────────────────────────────┘
```

## 2. 性能调优

### 2.1 关键参数

```
Kafka性能调优参数：

┌─────────────────────────────────────────────────────────────┐
│  Producer配置：                                              │
│  ├── batch.size：批次大小（默认16KB）                        │
│  ├── linger.ms：等待时间（默认0ms）                          │
│  ├── buffer.memory：缓冲区大小（默认32MB）                    │
│  ├── compression.type：压缩算法（lz4/snappy）                │
│  └── retries：重试次数（默认Int.MAX）                        │
│                                                             │
│  Consumer配置：                                              │
│  ├── fetch.min.bytes：最小拉取量（默认1字节）                  │
│  ├── fetch.max.wait.ms：最大等待时间（默认500ms）             │
│  ├── max.poll.records：单次拉取数（默认500）                  │
│  └── auto.offset.reset：偏移策略                             │
│                                                             │
│  Broker配置：                                                │
│  ├── num.io.threads：IO线程数                                 │
│  ├── num.network.threads：网络线程数                           │
│  ├── log.segment.bytes：段文件大小（默认1GB）                 │
│  └── replica.fetch.max.bytes：副本拉取大小                    │
└─────────────────────────────────────────────────────────────┘
```
