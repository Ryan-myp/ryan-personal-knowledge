# 消息队列内核深度解析

> 源码级分析，包含生产环境最佳实践。
> 适用对象：消息队列工程师、后端工程师

---

## 1. RabbitMQ架构

### 1.1 AMQP模型

```
RabbitMQ核心概念：

┌─────────────────────────────────────────────────────────────┐
│  Producer：消息生产者                                        │
│  ├── 连接到Broker                                          │
│  └── 发布消息到Exchange                                     │
│                                                             │
│  Exchange：消息交换机                                        │
│  ├── direct：根据routing_key精确匹配                         │
│  ├── fanout：广播到所有Queue                                 │
│  ├── topic：通配符匹配                                       │
│  └── headers：根据消息头匹配                                  │
│                                                             │
│  Queue：消息队列                                             │
│  ├── 存储消息                                                │
│  ├── 持久化/临时                                            │
│  └── 消费者订阅                                              │
│                                                             │
│  Consumer：消息消费者                                        │
│  ├── 订阅Queue                                              │
│  ├── 接收消息处理                                            │
│  └── ACK确认                                                 │
└─────────────────────────────────────────────────────────────┘
```

## 2. RocketMQ架构

### 2.1 消息流转

```
RocketMQ核心组件：

┌─────────────────────────────────────────────────────────────┐
│  NameServer：                                                │
│  ├── 服务发现（轻量级注册中心）                               │
│  └── Broker注册/注销                                         │
│                                                             │
│  Broker：                                                    │
│  ├── 存储消息（顺序写盘）                                     │
│  ├── 消息查询                                                │
│  └── 推送消费                                                │
│                                                             │
│  Producer：                                                  │
│  ├── 发送消息                                                │
│  ├── 消息重试                                                │
│  └── 事务消息                                                │
│                                                             │
│  Consumer：                                                  │
│  ├── 拉取/推送消费模式                                        │
│  ├── 集群/广播消费                                           │
│  └── 顺序消费                                                │
└─────────────────────────────────────────────────────────────┘
```
