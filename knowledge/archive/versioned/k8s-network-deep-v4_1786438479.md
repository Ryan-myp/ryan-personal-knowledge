## 1. Pod网络模型

### 1.1 CNI架构

```
K8s Pod网络模型：

┌─────────────────────────────────────────────────────────────┐
│  Pod网络模型：                                               │
│  ├── 每个Pod拥有独立IP                                       │
│  ├── Pod间直接通信（无需NAT）                                │
│  ├── 容器共享Network Namespace                                │
│  └── veth pair连接容器与网络                                  │
│                                                             │
│  CNI（Container Network Interface）：                        │
│  ├── 插件化网络架构                                          │
│  ├── 加载时调用配置                                          │
│  └── 卸载时释放资源                                          │
│                                                             │
│  网络插件对比：                                              │
│  ├── Calico：BGP路由，IPIP隧道                               │
│  ├── Flannel：VXLAN，简单部署                                │
│  └── Cilium：eBPF，高性能网络                                │
└─────────────────────────────────────────────────────────────┘
```

## 2. Service类型

### 2.1 服务发现

```
K8s Service类型：

┌─────────────────────────────────────────────────────────────┐
│  ClusterIP：                                                 │
│  ├── 集群内访问                                               │
│  ├── 默认类型                                                │
│  └── 内部负载均衡                                             │
│                                                             │
│  NodePort：                                                  │
│  ├── 节点端口暴露                                             │
│  ├── 每个节点开放一个端口                                     │
│  └── 可通过NodeIP:NodePort访问                                │
│                                                             │
│  LoadBalancer：                                              │
│  ├── 云服务商LB                                               │
│  ├── 自动创建外部LB                                          │
│  └── 适合云上生产环境                                        │
│                                                             │
│  ExternalName：                                              │
│  ├── 映射外部服务                                             │
│  ├── CNAME记录                                                │
│  └── 不创建Proxy                                             │
│                                                             │
│  Headless Service（clusterIP: None）：                       │
│  ├── 直接返回Pod IP                                          │
│  └── 适合StatefulSet                                         │
└─────────────────────────────────────────────────────────────┘
```
