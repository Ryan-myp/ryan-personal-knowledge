## 1. 数据结构

### 1.1 SDS

```
Simple Dynamic String (SDS) 结构：

┌─────────────────────────────────────────────────────────────┐
│  struct sdshdr {                                             │
│      int len;      // 已使用字节数                            │
│      int free;     // 剩余可用字节数                          │
│      char buf[];   // 数据数组                                │
│  };                                                          │
│                                                             │
│  特性：                                                       │
│  ├── O(1)获取字符串长度                                       │
│  ├── 惰性空间释放（不立即收回内存）                            │
│  ├── 预分配空间（减少内存重新分配）                            │
│  └── 二进制安全                                              │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 字典

```
Redis 字典结构：

┌─────────────────────────────────────────────────────────────┐
│  struct dict {                                               │
│      dictType *type;    // 类型特定函数                       │
│      void *privdata;    // 私有数据                           │
│      dictht ht[2];      // 两个哈希表                          │
│      long rehashidx;  // 扩容标记                             │
│  };                                                          │
│                                                             │
│  dictht {                                                    │
│      dictEntry **table; // 哈希表数组                         │
│      unsigned long size;    // 大小                          │
│      unsigned long sizemask; // 掩码                         │
│      unsigned long used;    // 节点数                         │
│  };                                                          │
│                                                             │
│  渐进式Rehash：                                               │
│  ├── 扩容时不一次性迁移，分多次进行                            │
│  ├── 每次增删改查操作时迁移一部分                              │
│  └── rehashidx记录当前迁移进度                                │
└─────────────────────────────────────────────────────────────┘
```

## 2. 持久化

### 2.1 RDB

```
RDB 持久化：

┌─────────────────────────────────────────────────────────────┐
│  触发条件：                                                  │
│  ├── save命令（同步）                                        │
│  ├── bgsave命令（异步）                                      │
│  ├── 配置auto-save规则                                       │
│  └── 服务器关闭                                              │
│                                                             │
│  优点：                                                       │
│  ├── 文件紧凑，恢复快                                        │
│  └── 适合备份                                                │
│                                                             │
│  缺点：                                                       │
│  └── 可能丢失最后一次备份的数据                                │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 AOF

```
AOF 持久化：

┌─────────────────────────────────────────────────────────────┐
│  策略：                                                       │
│  ├── everysec：每秒同步（推荐）                               │
│  ├── always：每次写入同步                                    │
│  └── no：OS控制同步                                          │
│                                                             │
│  重写机制：                                                   │
│  ├── 触发条件：AOF文件大小超过阈值                            │
│  ├── fork子进程重写                                         │
│  └── 旧文件先写，新命令追加，最后替换                          │
└─────────────────────────────────────────────────────────────┘
```
