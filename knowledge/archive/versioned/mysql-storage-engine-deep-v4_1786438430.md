## 1. InnoDB架构

### 1.1 核心组件

```
InnoDB存储引擎架构：

┌─────────────────────────────────────────────────────────────┐
│  缓冲池（Buffer Pool）：                                     │
│  ├── 数据页缓存                                             │
│  ├── 索引页缓存                                             │
│  ├── 锁信息缓存                                             │
│  └── 自适应哈希索引                                          │
│                                                             │
│  日志文件（Redo Log）：                                      │
│  ├── 事务日志                                               │
│  ├── 崩溃恢复                                               │
│  └── 预写式日志（WAL）                                      │
│                                                             │
│  日志文件（Undo Log）：                                      │
│  ├── 事务回滚                                               │
│  ├── MVCC实现                                               │
│  └── 一致性读                                                │
│                                                             │
│  表空间（Tablespace）：                                      │
│  ├── 系统表空间（ibdata1）                                   │
│  ├── 独立表空间（.ibd）                                     │
│  └── 临时表空间                                             │
└─────────────────────────────────────────────────────────────┘
```

## 2. 索引结构

### 2.1 B+树详解

```
InnoDB B+树索引结构：

┌─────────────────────────────────────────────────────────────┐
│  主键索引（聚簇索引）：                                       │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  叶子节点：存储完整行数据                               │   │
│  │  ├── 行数据                                          │   │
│  │  ├── 隐藏列：db_trx_id（事务ID）                      │   │
│  │  ├── 隐藏列：db_roll_ptr（回滚指针）                   │   │
│  │  └──  next_record指针（链表）                        │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  二级索引（非聚簇索引）：                                     │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  叶子节点：存储索引列 + 主键值                          │   │
│  │  ├── 索引列值                                        │   │
│  │  └── 主键值（用于回表）                                │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  回表查询：                                                  │
│  1. 二级索引找到主键值                                      │
│  2. 根据主键值在主键索引中查找完整行数据                      │
└─────────────────────────────────────────────────────────────┘
```
