# 机器学习系统架构深度解析

> 深入ML系统架构：特征工程、模型训练、在线推理、模型服务。
> 源码级分析，包含生产环境最佳实践。
> 适用对象：ML工程师、算法工程师

---

## 1. ML系统架构

### 1.1 整体架构

```
机器学习系统架构：

┌─────────────────────────────────────────────────────────────┐
│  数据层                                                     │
│  ├── 原始数据（日志/数据库/外部数据）                         │
│  ├── 特征存储（Feature Store）                               │
│  └── 标签数据                                               │
│                           ↓                                │
│  训练层                                                     │
│  ├── 特征工程（ETL/特征转换）                                │
│  ├── 模型训练（离线/在线）                                   │
│  ├── 模型评估（A/B测试/离线指标）                            │
│  └── 模型版本管理                                            │
│                           ↓                                │
│  服务层                                                     │
│  ├── 模型部署（Serving）                                    │
│  ├── 在线推理（Real-time Inference）                         │
│  ├── 特征实时计算                                           │
│  └── API网关                                               │
│                           ↓                                │
│  应用层                                                     │
│  ├── 广告推荐                                               │
│  ├── 搜索排序                                               │
│  └── 风控决策                                               │
└─────────────────────────────────────────────────────────────┘
```

## 2. 特征工程

### 2.1 特征体系

```
特征体系设计：

┌─────────────────────────────────────────────────────────────┐
│  特征类型：                                                  │
│  ├── 用户特征： demographics, behavior, preferences           │
│  ├── 商品特征： attributes, price, category                  │
│  ├── 上下文特征： time, location, device                     │
│  └── 交叉特征： user×item, user×context                     │
│                                                             │
│  特征存储：                                                  │
│  ├── 离线特征：Hive/Spark（T+1）                            │
│  ├── 实时特征：Flink/Kafka（毫秒级）                         │
│  └── 特征复用：Feature Store（在线/离线一致性）               │
│                                                             │
│  特征计算链路：                                              │
│  1. 原始数据 → 2. 特征计算 → 3. 特征存储 → 4. 模型训练      │
│                                                             │
│  常见问题：                                                  │
│  ├── 特征穿越：用未来数据预测过去                             │
│  ├── 特征漂移：数据分布变化                                   │
│  └── 特征缺失：稀疏特征处理                                   │
└─────────────────────────────────────────────────────────────┘
```

## 3. 模型服务

### 3.1 推理服务架构

```
在线推理服务架构：

┌─────────────────────────────────────────────────────────────┐
│  请求入口：                                                  │
│  ├── REST API（高延迟，简单）                                │
│  ├── gRPC（低延迟，高性能）                                  │
│  └── WebSocket（实时推送）                                   │
│                           ↓                                │
│  负载均衡：                                                  │
│  ├── 服务网格（Istio/Envoy）                                │
│  └── Nginx/LVS                                              │
│                           ↓                                │
│  推理服务：                                                  │
│  ├── 模型加载（TF-Serving/Seldon/Triton）                   │
│  ├── 特征预处理                                             │
│  ├── 模型推理                                               │
│  └── 后处理                                                 │
│                           ↓                                │
│  结果返回：                                                  │
│  └── 分数/标签/排名                                         │
└─────────────────────────────────────────────────────────────┘
```
