# Go内存模型深度解析

> 深入Go内存模型：堆栈分配、逃逸分析、GC调优、内存对齐。
> 源码级分析，包含生产环境最佳实践。
> 适用对象：Go工程师、系统工程师

---

## 1. 堆栈分配

### 1.1 分配策略

```
Go内存分配策略：

┌─────────────────────────────────────────────────────────────┐
│  栈分配（Stack）：                                           │
│  ├── 函数调用时自动分配                                       │
│  ├── 生命周期随函数结束                                       │
│  ├── 分配/释放极快                                           │
│  └── 适合：小对象、局部变量                                   │
│                                                             │
│  堆分配（Heap）：                                            │
│  ├── 通过new/make显式分配                                     │
│  ├── 生命周期由GC管理                                        │
│  ├── 需要GC扫描                                              │
│  └── 适合：大对象、逃逸到堆的变量                              │
│                                                             │
│  逃逸分析（Escape Analysis）：                               │
│  ├── 编译器静态分析变量生命周期                               │
│  ├── 无法确定生命周期的变量逃逸到堆                            │
│  ├── 常见逃逸场景：接口传递、闭包引用、返回局部变量指针        │
│  └── go build -gcflags="-m" 查看逃逸分析结果                  │
└─────────────────────────────────────────────────────────────┘
```

## 2. GC调优

### 2.1 关键参数

```
Go GC调优参数：

┌─────────────────────────────────────────────────────────────┐
│  GOGC：                                                     │
│  ├── 默认100（GC触发阈值）                                   │
│  ├── 降低→更频繁GC，更低延迟                                 │
│  └── 提高→更少GC，更高吞吐                                   │
│                                                             │
│  GOMEMLIMIT：                                               │
│  ├── Go 1.19+ 引入                                          │
│  ├── 限制内存使用量                                          │
│  └── GC会主动控制在限制内                                     │
│                                                             │
│  GODEBUG：                                                  │
│  ├── gctrace=1 打印GC日志                                    │
│  └── asclean=1 启动时清理内存                                │
│                                                             │
│  runtime/debug.SetGCPercent()：                             │
│  └── 运行时动态调整GOGC                                      │
└─────────────────────────────────────────────────────────────┘
```
