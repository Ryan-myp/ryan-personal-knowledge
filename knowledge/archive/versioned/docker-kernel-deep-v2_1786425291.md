## 1. 容器核心技术

### 1.1 命名空间 (Namespaces)

```
Linux 命名空间提供进程隔离：

┌─────────────────────────────────────────────────────────────┐
│                    命名空间类型                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  PID (进程)                                                  │
│  ├── 隔离进程 ID 空间                                        │
│  └── 容器内进程看不到宿主机进程                               │
│                                                             │
│  NET (网络)                                                  │
│  ├── 隔离网络设备、IP 地址、端口                              │
│  └── 每个容器有独立网络栈                                    │
│                                                             │
│  MNT (挂载)                                                  │
│  ├── 隔离文件系统挂载点                                      │
│  └── 容器有独立的根文件系统                                  │
│                                                             │
│  UTS (主机名)                                                │
│  ├── 隔离主机名和域名                                        │
│  └── 容器可以有独立的主机名                                  │
│                                                             │
│  IPC (信号量)                                                │
│  ├── 隔离进程间通信                                          │
│  └── 容器间不能直接共享内存                                  │
│                                                             │
│  USER (用户)                                                 │
│  ├── 隔离用户和组 ID                                         │
│  └── 容器内可以有不同的用户权限                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 控制组 (cgroups)

```
cgroups 提供资源限制：

┌─────────────────────────────────────────────────────────────┐
│                  cgroups 子系统                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  cpu                                                        │
│  ├── 限制 CPU 使用率                                         │
│  ├── 设置 CPU 份额                                           │
│  └── 隔离 CPU 时间片                                         │
│                                                             │
│  memory                                                      │
│  ├── 限制内存使用量                                          │
│  ├── 设置 swap 限制                                          │
│  └── 控制 OOM 行为                                          │
│                                                             │
│  blkio                                                       │
│  ├── 限制磁盘 I/O                                            │
│  └── 控制读写带宽                                             │
│                                                             │
│  devices                                                     │
│  ├── 控制设备访问                                            │
│  └── 限制容器可访问的设备                                     │
│                                                             │
│  freezer                                                     │
│  ├── 挂起/恢复进程组                                         │
│  └── 用于容器快照                                            │
│                                                             │
│  net_cls                                                     │
│  ├── 标记网络包                                              │
│  └── 用于流量控制                                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 2. 镜像系统

### 2.1 UnionFS

```
UnionFS 合并多个层：

┌─────────────────────────────────────────────────────────────┐
│                    UnionFS 结构                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Layer 3 (最上层 - 读写)                                     │
│  ├── 容器运行时修改的文件                                     │
│  └── 仅包含与下层不同的文件                                   │
│  ─────────────────────────────────────────────                │
│  Layer 2                                                     │
│  ├── 应用层文件                                               │
│  └── 只读                                                    │
│  ─────────────────────────────────────────────                │
│  Layer 1 (最底层)                                            │
│  ├── 基础镜像                                                 │
│  └── 只读                                                    │
│  ─────────────────────────────────────────────                │
│  合并视图 (Container View)                                    │
│  ├── 对容器可见的完整文件系统                                 │
│  └── 只读层 + 读写层                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 镜像分层

```dockerfile
# Dockerfile 示例

# 每层都是一个只读的镜像层
FROM ubuntu:20.04          # Layer 1: 基础系统
RUN apt-get update         # Layer 2: 包管理
RUN apt-get install -y nginx # Layer 3: 安装 Nginx
COPY . /app                # Layer 4: 复制代码
CMD ["nginx", "-g", "daemon off;"]  # Layer 5: 启动命令
```

## 3. 网络模型

### 3.1 网络模式

```
┌─────────────────────────────────────────────────────────────┐
│                  Docker 网络模式                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  bridge (默认)                                               │
│  ├── 容器通过虚拟网桥连接                                    │
│  ├── NAT 网络地址转换                                        │
│  └── 容器间可通信                                            │
│                                                             │
│  host                                                          │
│  ├── 容器直接使用宿主机网络                                   │
│  ├── 无网络隔离                                              │
│  └── 性能最好                                                │
│                                                             │
│  none                                                          │
│  ├── 无网络连接                                              │
│  └── 完全隔离                                                │
│                                                             │
│  container                                                    │
│  ├── 共享另一个容器的网络                                     │
│  └── 用于特定场景                                            │
│                                                             │
│  overlay (Swarm/K8s)                                        │
│  ├── 跨主机容器通信                                          │
│  └── 多主机网络                                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 网络实现

```
Docker 网络实现原理：

1. veth pair
   ├── 成对的虚拟网卡
   └── 一端在容器，一端在宿主机

2. bridge
   ├── Linux bridge (docker0)
   └── 连接多个 veth

3. NAT
   ├── iptables MASQUERADE
   └── 容器访问外网
```

## 5. 生产优化

### 5.1 资源限制

```yaml
# docker-compose.yml

version: '3.8'
services:
  app:
    image: myapp:latest
    deploy:
      resources:
        limits:
          cpus: '2'
          memory: 4G
        reservations:
          cpus: '1'
          memory: 2G
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "3"
```

### 5.2 安全最佳实践

```dockerfile
# 最佳实践 Dockerfile

# 使用精简基础镜像
FROM alpine:3.18

# 非 root 用户运行
RUN addgroup -S appgroup && adduser -S appuser -G appgroup
USER appuser

# 只读文件系统
RUN apk add --no-cache nginx

# 最小化镜像
COPY --chown=appuser:appgroup . /app
WORKDIR /app

# 健康检查
HEALTHCHECK --interval=30s --timeout=3s \
  CMD wget -qO- http://localhost:80/health || exit 1
```

## 6. 故障排查

### 6.1 常见问题

| 问题 | 症状 | 排查命令 | 解决方案 |
|------|------|----------|----------|
| 容器无法启动 | 启动失败 | `docker logs` | 检查日志 |
| 网络不通 | 无法访问 | `docker network ls` | 检查网络配置 |
| 磁盘满 | 写入失败 | `docker system df` | 清理无用数据 |
| 性能差 | 响应慢 | `docker stats` | 调整资源限制 |

### 6.2 排查命令

```bash
# 查看容器日志
docker logs <container>

# 查看容器资源使用
docker stats

# 查看容器详情
docker inspect <container>

# 查看网络
docker network ls
docker network inspect <network>

# 清理无用数据
docker system prune -a
```
