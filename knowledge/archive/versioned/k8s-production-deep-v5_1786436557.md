# Kubernetes 生产环境深度实战

> 深入K8s生产实践：集群架构、网络插件、存储、调度、故障处理。
> 基于《Kubernetes快速入门（第2版）》（奈吉尔·波尔顿著）蒸馏。
> 适用对象：K8s工程师、DevOps工程师

---

## 1. 集群架构

### 1.1 控制平面

```
Kubernetes 控制平面组件：

┌─────────────────────────────────────────────────────────────┐
│  API Server（API服务器）                                     │
│  ├── 集群统一入口                                            │
│  ├── 处理REST请求                                            │
│  ├── 验证请求                                                │
│  └── 更新etcd                                                │
│                                                             │
│  etcd（键值存储）                                            │
│  ├── 存储集群状态                                            │
│  ├── 保证强一致性                                            │
│  └── 使用Raft协议                                            │
│                                                             │
│  Scheduler（调度器）                                         │
│  ├── 监听新Pod                                              │
│  ├── 计算最优节点                                           │
│  └── 绑定Pod到节点                                          │
│                                                             │
│  Controller Manager（控制器管理器）                            │
│  ├── Node Controller：节点管理                               │
│  ├── Replication Controller：副本管理                        │
│  ├── Endpoint Controller：端点管理                           │
│  └── Service Account Controller：服务账户管理                 │
│                                                             │
│  Cloud Controller Manager（云控制器管理器）                    │
│  ├── 管理云服务商的负载均衡器                                │
│  └── 管理云磁盘                                              │
└─────────────────────────────────────────────────────────────┘
```

## 2. 网络插件

### 2.1 主流网络插件对比

```
K8s 网络插件对比：

┌─────────────────────────────────────────────────────────────┐
│  插件          │ 实现方式     │ 性能    │ 功能    │ 社区   │
│ ──────────────┼─────────────┼────────┼────────┼────────│
│ Calico         │ BGP路由     │ 高      │ 网络策略 │ 大     │
│ Flannel        │ Overlay     │ 中      │ 基础网络 │ 大     │
│ Cilium         │ eBPF        │ 极高    │ 网络策略 │ 大     │
│ Weave          │ Overlay     │ 中      │ 加密通信 │ 中     │
│ Canal          │ Flannel+Calico│ 中    │ 混合    │ 中     │
│ Multus         │ 多网卡      │ 高      │ 多网络   │ 中     │
└─────────────────────────────────────────────────────────────┘

推荐选择：
  ├── 大规模集群：Cilium（高性能、eBPF）
  ├── 中等规模：Calico（稳定、功能全）
  └── 小型集群：Flannel（简单）
```

## 3. 存储

### 3.1 PVC与PV

```
K8s 存储架构：

┌─────────────────────────────────────────────────────────────┐
│  PVC (PersistentVolumeClaim) - 存储请求                       │
│  ├── 用户声明的存储需求                                       │
│  └── 绑定到PV                                               │
│                                                             │
│  PV (PersistentVolume) - 物理存储                             │
│  ├── 集群中的存储资源                                         │
│  └── 可以是NFS、iSCSI、云盘等                               │
│                                                             │
│  StorageClass - 动态 Provisioning                             │
│  ├── 自动创建PV                                             │
│  └── 支持不同存储类型                                        │
│                                                             │
│  生命周期：                                                  │
│  1. 用户创建PVC                                             │
│  2. 存储控制器绑定PVC到PV                                   │
│  3. Pod挂载PV使用                                           │
│  4. 用户删除Pod（PV保留）                                   │
│  5. 用户删除PVC（释放PV）                                   │
└─────────────────────────────────────────────────────────────┘
```
