# 广告SSP系统深度解析

> 深入SSP系统：广告位管理、竞价接入、流量分发、收益优化。
> 源码级分析，包含生产环境最佳实践。
> 适用对象：广告系统工程师、后端工程师

---

## 1. SSP核心架构

### 1.1 系统组成

```
SSP系统架构：

┌─────────────────────────────────────────────────────────────┐
│  Publisher接入层：                                           │
│  ├── 广告位管理（Ad Unit）                                   │
│  ├── 媒体配置                                               │
│  └── 流量验证                                               │
│                           ↓                                │
│  竞价接入层：                                                │
│  ├── Header Bidding（头部竞价）                             │
│  ├── 多DSP竞价接入                                          │
│  ├── 竞价超时控制（<100ms）                                  │
│  └── 竞价结果聚合                                           │
│                           ↓                                │
│  流量分发层：                                                │
│  ├── 流量路由                                               │
│  ├── 优先级调度                                             │
│  └── 降级处理                                               │
│                           ↓                                │
│  数据上报层：                                                │
│  ├── 曝光日志                                               │
│  ├── 点击日志                                               │
│  └── 收益统计                                               │
└─────────────────────────────────────────────────────────────┘
```

## 2. Header Bidding

### 2.1 工作流程

```
Header Bidding流程：

┌─────────────────────────────────────────────────────────────┐
│  1. 页面加载                                                 │
│     └── 执行Prebid.js                                       │
│                                                             │
│  2. 竞价请求分发                                             │
│     ├── 并行请求所有Bidder                                   │
│     ├── 设置超时（通常800ms）                                │
│     └── 收集所有Bidder响应                                   │
│                                                             │
│  3. 竞价结果处理                                             │
│     ├── 排序（最高价优先）                                   │
│     ├── 选择Winner                                          │
│     └── 返回广告位                                          │
│                                                             │
│  4. 广告投放                                               │
│     └── 渲染广告创意                                         │
└─────────────────────────────────────────────────────────────┘
```
