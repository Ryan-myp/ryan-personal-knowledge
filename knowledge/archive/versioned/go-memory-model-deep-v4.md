# Go内存模型深度解析

> 深入Go内存模型：堆栈分配、逃逸分析、内存对齐、GC调优。
> 源码级分析，包含性能调优实践。
> 适用对象：Go工程师、系统工程师

---

## 1. 堆栈分配

### 1.1 分配策略

```
Go内存分配策略：

┌─────────────────────────────────────────────────────────────┐
│  Stack（栈）：                                               │
│  ├── 每个Goroutine独立栈                                     │
│  ├── 起始2KB，动态扩容                                       │
│  ├── 线程局部存储（TLS）访问快                                 │
│  └── 生命周期随Goroutine结束                                  │
│                                                             │
│  Heap（堆）：                                                │
│  ├── 所有Goroutine共享                                       │
│  ├── 大对象直接分配堆内存                                     │
│  ├── 逃逸分析决定分配位置                                     │
│  └── 生命周期由GC管理                                       │
│                                                             │
│  MCache（每线程缓存）：                                      │
│  ├── 每个M（OS线程）独立缓存                                 │
│  ├── 减少锁竞争                                             │
│  └── 对象先分配到MCache，定期flush到MCentral                │
│                                                             │
│  MCentral（全局缓存）：                                      │
│  ├── 管理大小对象（<32KB）                                   │
│  ├── 按大小分class管理                                      │
│  └── 从Span分配给MCache                                     │
│                                                             │
│  Span（内存块）：                                            │
│  ├── 大块内存分配（≥32KB直接分配）                           │
│  ├── 由MSpan管理                                            │
│  └── 定期回收释放                                           │
└─────────────────────────────────────────────────────────────┘
```

## 2. 逃逸分析

### 2.1 分析规则

```
Go逃逸分析规则：

┌─────────────────────────────────────────────────────────────┐
│  以下情况会发生逃逸到堆：                                     │
│                                                             │
│  1. 变量地址被取出                                           │
│     func foo() *int {                                        │
│         x := 1                                               │
│         return &x  // x逃逸到堆                               │
│     }                                                        │
│                                                             │
│  2. 变量大小在运行时确定                                     │
│     func foo() []int {                                       │
│         n := getInput()  // 运行时确定                        │
│         return make([]int, n)  // 逃逸                        │
│     }                                                        │
│                                                             │
│  3. 闭包引用外部变量                                         │
│     func foo() func() {                                      │
│         x := 1                                               │
│         return func() { return x }  // x逃逸                 │
│     }                                                        │
│                                                             │
│  4. 接口赋值                                                 │
│     func foo() {                                             │
│         x := 1                                               │
│         var i interface{} = x  // x逃逸                       │
│     }                                                        │
│                                                             │
│  优化技巧：                                                  │
│  ├── 使用指针接收器避免复制                                   │
│  ├── 预分配切片容量                                          │
│  ├── 减少不必要的接口转换                                    │
│  └── 使用sync.Pool复用对象                                   │
└─────────────────────────────────────────────────────────────┘
```
