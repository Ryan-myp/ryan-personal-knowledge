## 1. 路由系统

### 1.1 核心机制

```
Gin路由机制：

┌─────────────────────────────────────────────────────────────┐
│  路由树：                                                    │
│  ├── Radix Tree（基数树）                                     │
│  ├── 支持GET/POST/PUT/DELETE等                                │
│  ├── 路径参数：:param                                        │
│  └── 通配符：*wildcard                                       │
│                                                             │
│  路由组：                                                    │
│  ├── v1 := r.Group("/api/v1")                                │
│  ├── 中间件分组                                              │
│  └── 嵌套路由组                                              │
│                                                             │
│  中间件链：                                                  │
│  ├── 全局中间件：Use()                                       │
│  ├── 路由级中间件：Group.Use()                               │
│  └── 组级中间件                                              │
│                                                             │
│  示例：                                                      │
│  router.GET("/users/:id", func(c *gin.Context) {            │
│      id := c.Param("id")                                     │
│      c.JSON(200, gin.H{"id": id})                           │
│  })                                                          │
└─────────────────────────────────────────────────────────────┘
```

## 2. 中间件

### 2.1 编写模式

```
Gin中间件模式：

┌─────────────────────────────────────────────────────────────┐
│  中间件签名：                                                │
│  func Middleware() gin.HandlerFunc {                         │
│      return func(c *gin.Context) {                          │
│          // 请求前处理                                        │
│          start := time.Now()                                 │
│          c.Next()  // 调用后续中间件或处理器                    │
│          // 请求后处理                                        │
│          cost := time.Since(start)                           │
│          log.Printf("Cost: %v", cost)                        │
│      }                                                       │
│  }                                                           │
│                                                             │
│  常用中间件：                                                │
│  ├── gin.Recovery()：panic恢复                               │
│  ├── gin.Logger()：请求日志                                  │
│  ├── gin.BodyDump()：请求体转储                               │
│  └── gin.Timeout()：请求超时                                 │
│                                                             │
│  注意事项：                                                  │
│  ├── c.Next()必须调用，否则后续中间件不执行                   │
│  ├── c.Abort()终止处理链                                     │
│  └── 中间件执行顺序：先注册先执行（洋葱模型）                   │
└─────────────────────────────────────────────────────────────┘
```
