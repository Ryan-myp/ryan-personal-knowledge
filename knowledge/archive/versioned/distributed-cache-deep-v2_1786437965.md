## 1. 缓存一致性Hash

### 1.1 算法原理

```
一致性Hash算法：

┌─────────────────────────────────────────────────────────────┐
│  Hash环（32位）：                                            │
│  ┌─────────────────────────────────────────────────────┐  │
│  │              0 (2^32-1)                             │  │
│  │           ↗                       ↘                │  │
│  │      Server_A                  Server_B            │  │
│  │         \                       /                  │  │
│  │          ↘                     ↙                   │  │
│  │              2^31                                │  │
│  └─────────────────────────────────────────────────────┘  │
│                                                             │
│  节点分布：                                                  │
│  ├── 节点均匀分布在Hash环上                                   │
│  └── 每个节点负责的区间                                        │
│                                                             │
│  数据映射：                                                  │
│  ├── Hash(Key) → 顺时针找到最近节点                          │
│  └── 节点增加/减少时，只有部分数据迁移                         │
│                                                             │
│  虚拟节点：                                                  │
│  ├── 解决数据倾斜问题                                         │
│  ├── 每个物理节点对应多个虚拟节点                              │
│  └── 通常100-200个虚拟节点/物理节点                            │
└─────────────────────────────────────────────────────────────┘
```

## 2. 缓存三大问题

### 2.1 问题与解决方案

```
缓存穿透：                                                     │
│  ├── 问题：查询不存在的数据                                   │
│  ├── 场景：恶意攻击                                           │
│  └── 解决：布隆过滤器、缓存空值                               │
│                                                             │
│ 缓存击穿：                                                     │
│ ├── 问题：热点Key过期，大量请求打到DB                           │
│ ├── 场景：大V账号、热点新闻                                    │
│ └── 解决：永不过期、互斥锁、二级缓存                            │
│                                                             │
│ 缓存雪崩：                                                     │
│ ├── 问题：大量Key同时过期                                     │
│ ├── 场景：缓存预热不足                                        │
│ └── 解决：过期时间加随机值、集群部署、限流降级                  │
└─────────────────────────────────────────────────────────────┘
```
