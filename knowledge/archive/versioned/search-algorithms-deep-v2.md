## 1. 倒排索引

### 1.1 数据结构

```
倒排索引结构：

┌─────────────────────────────────────────────────────────────┐
│  词典（Term Dictionary）：                                   │
│  ├── 所有唯一词项有序存储                                    │
│  ├── 支持前缀匹配                                            │
│  └── 使用FST（有限状态转换器）优化                           │
│                                                             │
│  倒排列表（Posting List）：                                  │
│  ├── 包含该词项的文档ID列表                                  │
│  ├── 词频（TF）                                              │
│  ├── 位置信息（Position）                                   │
│  └── 偏移量（Offset）                                       │
│                                                             │
│  查询优化：                                                  │
│  ├── 文档频率过滤（DF < min）                                │
│  ├── 短语查询优化                                           │
│  ├── 模糊查询（Levenshtein距离）                             │
│  └── 自动补全（Trie树）                                     │
└─────────────────────────────────────────────────────────────┘
```

## 2. 向量检索

### 2.1 算法对比

```
向量检索算法对比：

┌─────────────────────────────────────────────────────────────┐
│   brute-force：                                              │
│  ├── 暴力计算所有距离                                        │
│  ├── 精度100%                                                │
│  └── 速度慢，适合小规模数据                                   │
│                                                             │
│  IVF（倒排文件）：                                           │
│  ├── 先聚类，再在对应簇中搜索                                  │
│  ├── 平衡速度与精度                                          │
│  └── 适合中等规模数据                                         │
│                                                             │
│  HNSW（分层小世界图）：                                      │
│  ├── 图遍历，速度快                                          │
│  ├── 精度高                                                  │
│  └── 适合大规模数据                                           │
│                                                             │
│  SQ（标量量化）：                                            │
│  ├── 压缩向量，节省内存                                      │
│  ├── 牺牲少量精度                                            │
│  └── 适合内存受限场景                                         │
└─────────────────────────────────────────────────────────────┘
```
