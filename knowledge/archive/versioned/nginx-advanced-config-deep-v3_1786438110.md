## 1. 负载均衡策略

### 1.1 算法对比

```
Nginx负载均衡策略：

┌─────────────────────────────────────────────────────────────┐
│  轮询（Round Robin）：                                      │
│  ├── 默认策略                                               │
│  ├── 请求均匀分配                                           │
│  └── 适合：各节点性能相近                                    │
│                                                             │
│  加权轮询（Weight）：                                       │
│  ├── 可指定权重                                             │
│  ├── 性能强的节点分配更多请求                                │
│  └── 适合：节点性能不均衡                                    │
│                                                             │
│  IP Hash：                                                  │
│  ├── 按客户端IP哈希分配                                      │
│  ├── 同一IP固定到同一节点                                    │
│  └── 适合：需要会话保持                                      │
│                                                             │
│  最少连接（Least Conn）：                                    │
│  ├── 分配给当前连接最少的节点                                 │
│  └── 适合：请求处理时间差异大                                 │
│                                                             │
│  配置示例：                                                  │
│  upstream backend {                                          │
│    server 10.0.0.1:8080 weight=3;                           │
│    server 10.0.0.2:8080 weight=1;                           │
│    keepalive 32;                                             │
│  }                                                           │
└─────────────────────────────────────────────────────────────┘
```

## 2. 缓存配置

### 2.1 缓存策略

```
Nginx缓存配置：

┌─────────────────────────────────────────────────────────────┐
│  proxy_cache_path：                                         │
│  ├── 缓存路径                                                │
│  ├── keys_zone：共享内存区域                                 │
│  ├── max_size：最大缓存大小                                   │
│  ├── inactive：非活跃时间                                     │
│  └── use_temp_path：临时文件路径                              │
│                                                             │
│  proxy_cache：                                               │
│  ├── 启用缓存                                               │
│  ├── cache_key：缓存键                                       │
│  ├── cache_valid：缓存有效期                                  │
│  └── cache_bypass：跳过缓存条件                               │
│                                                             │
│  缓存失效：                                                  │
│  ├── expires：设置过期头                                      │
│  ├── Cache-Control：控制缓存                                  │
│  └── proxy_cache_valid：按需缓存                              │
└─────────────────────────────────────────────────────────────┘
```
