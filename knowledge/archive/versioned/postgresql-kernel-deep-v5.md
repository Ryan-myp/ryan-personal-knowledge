## 1. MVCC实现

### 1.1 事务可见性

```
PostgreSQL MVCC机制：

┌─────────────────────────────────────────────────────────────┐
│  行版本（Tuple）：                                           │
│  ├── t_xmin：创建事务ID                                      │
│  ├── t_xmax：删除事务ID                                      │
│  └── t_ctid：指向最新版本的指针                              │
│                                                             │
│  可见性判断：                                                │
│  ├── t_xmin <= 当前事务ID AND (t_xmax = 0 OR t_xmax > 当前) │
│  └── 当前事务能看到自己提交的数据                            │
│                                                             │
│  快照（Snapshot）：                                          │
│  ├── 事务开始时的可见性快照                                  │
│  ├── 保证可重复读                                            │
│  └── 避免幻读                                                │
│                                                             │
│  HOT更新：                                                   │
│  ├── 不修改索引列的更新                                      │
│  ├── 原地更新，不创建新版本                                   │
│  └── 优化写入性能                                            │
└─────────────────────────────────────────────────────────────┘
```

## 2. WAL日志

### 2.1 写入流程

```
WAL（Write-Ahead Logging）：

┌─────────────────────────────────────────────────────────────┐
│  写入流程：                                                  │
│  1. 修改数据页（内存）                                       │
│  2. 生成WAL记录                                              │
│  3. 顺序写入WAL日志（磁盘）                                  │
│  4. 定期刷新数据页到磁盘                                     │
│                                                             │
│  优势：                                                      │
│  ├── 顺序写性能好                                            │
│  ├── 崩溃恢复快                                              │
│  └── 支持时间点恢复（PITR）                                  │
│                                                             │
│  检查点（Checkpoint）：                                      │
│  ├── 定期将脏页刷新到磁盘                                    │
│  ├── 生成检查点记录                                          │
│  └── 控制WAL大小                                            │
└─────────────────────────────────────────────────────────────┘
```
