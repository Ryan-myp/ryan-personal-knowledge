# 搜索引擎架构深度解析

> 深入搜索引擎：倒排索引、分词、排序、召回策略。
> 源码级分析，包含生产环境调优。
> 适用对象：搜索工程师、推荐系统工程师

---

## 1. 倒排索引

### 1.1 索引结构

```
倒排索引结构：

┌─────────────────────────────────────────────────────────────┐
│  词典 (Term Dictionary)                                     │
│  ├── 存储所有唯一词项                                        │
│  ├── 按字典序排列                                           │
│  └── 用于查询时词项查找                                     │
│                                                             │
│  倒排列表 (Posting List)                                     │
│  ├── 存储包含该词项的文档ID列表                               │
│  ├── 可包含词频、位置信息等                                   │
│  └── 支持压缩存储                                           │
│                                                             │
│  示例：                                                      │
│                                                             │
│  词典          倒排列表                                      │
│  ├── 大数据 → [1,3,5,7,9]                                  │
│  ├── 搜索引擎 → [2,4,6,8]                                  │
│  └── 推荐系统 → [1,2,5,8,9]                                │
└─────────────────────────────────────────────────────────────┘
```

## 2. 分词器

### 2.1 主流分词器

```
搜索引擎分词器对比：

┌─────────────────────────────────────────────────────────────┐
│  分词器              │ 语言支持    │ 特点                   │
│ ────────────────────┼───────────┼─────────────────────────│
│ IK Analyzer          │ 中文        │ 智能分词，支持自定义词库  │
│ Jieba                │ 中文        │ 支持三种模式            │
│ HanLP                │ 多语言      │ NLP功能丰富             │
│ Standard             │ 多语言      │ 内置，简单高效           │
│ Whitespace           │ 多语言      │ 按空格分词              │
│ NGram                │ 多语言      │ 生成n-gram              │
└─────────────────────────────────────────────────────────────┘

中文分词策略：
  ├── 细粒度：分得更细，召回率高，准确率低
  ├── 粗粒度：分得粗，召回率低，准确率高
  └── 智能模式：自动选择粒度
```

## 3. 查询执行

### 3.1 查询处理流程

```
搜索引擎查询处理流程：

┌─────────────────────────────────────────────────────────────┐
│  1. 查询解析                                                 │
│     ├── 解析查询语句                                         │
│     ├── 识别查询类型（term/query）                           │
│     └── 构建查询树                                          │
│                                                             │
│  2. 词项查询                                                 │
│     ├── 在词典中查找词项                                     │
│     └── 获取倒排列表                                        │
│                                                             │
│  3. 布尔运算                                                 │
│     ├── AND：交集                                          │
│     ├── OR：并集                                            │
│     └── NOT：差集                                          │
│                                                             │
│  4. 评分排序                                                 │
│     ├── TF-IDF                                             │
│     ├── BM25                                               │
│     └── 向量相似度                                          │
│                                                             │
│  5. 结果返回                                                 │
│     ├── 排序                                               │
│     └── 返回Top-K                                           │
└─────────────────────────────────────────────────────────────┘
```
