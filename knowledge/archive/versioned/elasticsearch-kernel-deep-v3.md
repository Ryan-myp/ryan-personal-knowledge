## 1. 倒排索引

### 1.1 数据结构

```
Elasticsearch倒排索引：

┌─────────────────────────────────────────────────────────────┐
│  词典（Term Dictionary）：                                   │
│  ├── 存储所有唯一词项                                        │
│  ├── 有序排列（FST有限状态转换器）                            │
│  └── 用于快速查找词项                                        │
│                                                             │
│  倒排列表（Posting List）：                                  │
│  ├── 包含该词项的文档ID列表                                  │
│  ├── 词频（TF）                                              │
│  ├── 位置信息（Position）                                   │
│  └── 偏移量（Offset）                                       │
│                                                             │
│  示例：                                                      │
│  ┌─────────────┬──────────────────────────────────────┐   │
│  │ 文档ID      │ 词频 │ 位置列表                        │   │
│  ├─────────────┼──────┼───────────────────────────────┤   │
│  │ doc_1       │  2   │ [0, 5]                        │   │
│  │ doc_3       │  1   │ [2]                           │   │
│  └─────────────┴──────┴───────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

## 2. 查询执行

### 2.1 查询流程

```
ES查询执行流程：

┌─────────────────────────────────────────────────────────────┐
│  1. 路由计算                                                 │
│     └── 根据index + type + id计算shard位置                   │
│                                                             │
│  2. 分发查询                                                 │
│     ├── 协调节点接收请求                                     │
│     ├── 转发到相关shard                                      │
│     └── 并发执行                                             │
│                                                             │
│  3. 局部搜索                                                 │
│     ├── 倒排索引查找                                         │
│     ├── 分数计算（TF-IDF/BM25）                             │
│     └── 返回Top-K                                            │
│                                                             │
│  4. 结果合并                                                 │
│     ├── 全局排序                                             │
│     ├── 分页处理                                             │
│     └── 返回结果                                             │
└─────────────────────────────────────────────────────────────┘
```
