## 2. 网络插件

### 2.1 CNI对比

```
主流CNI插件对比：

┌─────────────────────────────────────────────────────────────┐
│  Calico：                                                    │
│  ├── IPIP隧道/VXLAN                                         │
│  ├── 网络策略（NetworkPolicy）                               │
│  └── 适合大规模集群                                          │
│                                                             │
│  Flannel：                                                   │
│  ├── 简单部署                                               │
│  ├── VXLAN/Host-GW模式                                      │
│  └── 适合中小规模集群                                        │
│                                                             │
│  Cilium：                                                    │
│  ├── eBPF加速                                               │
│  ├── 网络策略                                               │
│  └── 适合高性能场景                                          │
│                                                             │
│ 选择建议：                                                   │
│ ├── 简单场景：Flannel                                       │
│ ├── 大规模：Calico                                          │
│ └── 高性能：Cilium                                          │
└─────────────────────────────────────────────────────────────┘
```
