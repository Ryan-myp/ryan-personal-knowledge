## 1. 事件模型

### 1.1 工作模式

```
Nginx事件模型：

┌─────────────────────────────────────────────────────────────┐
│  工作模式：                                                  │
│  ├── select：POSIX标准，连接数限制                           │
│  ├── poll：POSIX标准，性能一般                               │
│  ├── epoll：Linux专属，高性能                                │
│  └── kqueue：BSD/macOS专属                                  │
│                                                             │
│  连接处理：                                                  │
│  ├── 单进程：适合低并发场景                                  │
│  ├── 多进程：Master+Worker模式                              │
│  ├── 多线程：适合CPU密集型                                   │
│  └── 混合模型：事件+线程                                     │
│                                                             │
│  配置优化：                                                  │
│  ├── worker_processes：CPU核数                              │
│  ├── worker_connections：每进程最大连接数                     │
│  └── use epoll：指定事件模型                                 │
└─────────────────────────────────────────────────────────────┘
```

## 2. 负载均衡

### 2.1 策略配置

```
Nginx负载均衡策略：

┌─────────────────────────────────────────────────────────────┐
│  1. 轮询（默认）                                             │
│     └── upstream backend { server 10.0.0.1; server 10.0.0.2; }│
│                                                             │
│  2. 加权轮询                                                │
│     └── weight参数：server 10.0.0.1 weight=3;               │
│                                                             │
│  3. IP哈希                                                    │
│     └── ip_hash;（保证同一客户端请求同一服务器）              │
│                                                             │
│  4. 最少连接                                                 │
│     └── least_conn;                                         │
│                                                             │
│  5. 自定义路由                                               │
│     └── 基于URL/Header路由                                   │
└─────────────────────────────────────────────────────────────┘
```
