## 1. 微服务架构模式

### 1.1 服务模式

```
微服务架构模式：

┌─────────────────────────────────────────────────────────────┐
│  服务模式：                                                  │
│  ├── API网关：统一入口，路由转发                              │
│  ├── 服务注册发现：Consul/etcd/Nacos                          │
│  ├── 服务治理：熔断、限流、降级                               │
│  └── 配置中心：动态配置管理                                   │
│                                                             │
│  通信模式：                                                  │
│  ├── 同步：REST/gRPC                                        │
│  ├── 异步：消息队列（Kafka/RabbitMQ）                        │
│  └── 事件：事件驱动架构                                       │
│                                                             │
│  数据管理：                                                  │
│  ├── 数据库 per Service：每个服务独立数据库                   │
│  ├── CQRS：读写分离                                          │
│  └── Saga：分布式事务                                        │
└─────────────────────────────────────────────────────────────┘
```

## 2. CQRS模式

### 2.1 读写分离

```
CQRS（Command Query Responsibility Segregation）：

┌─────────────────────────────────────────────────────────────┐
│  命令侧（Command）：                                         │
│  ├── 负责写操作                                               │
│  ├── 产生事件                                                │
│  └── 更新写模型                                               │
│                                                             │
│  查询侧（Query）：                                           │
│  ├── 负责读操作                                               │
│  ├── 订阅事件                                                │
│  └── 更新读模型（投影）                                       │
│                                                             │
│  优势：                                                      │
│  ├── 读写性能独立优化                                        │
│  ├── 数据模型灵活                                            │
│  └── 支持事件溯源                                            │
│                                                             │
│  挑战：                                                      │
│  ├── 最终一致性                                              │
│  └── 复杂度增加                                              │
└─────────────────────────────────────────────────────────────┘
```
