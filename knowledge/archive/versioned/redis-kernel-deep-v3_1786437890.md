## 1. 数据结构

### 1.1 SDS与ListPack

```
Redis核心数据结构：

┌─────────────────────────────────────────────────────────────┐
│  SDS（Simple Dynamic String）：                              │
│  ├── 字符串对象基础                                           │
│  ├── 前置长度属性                                            │
│  ├── 懒性空间释放                                            │
│  └── 二进制安全                                              │
│                                                             │
│  ListPack（列表包）：                                        │
│  ├── Redis 4.0+ Ziplist的替代品                              │
│  ├── 紧凑内存布局                                            │
│  ├── 连续内存分配                                            │
│  └── 适用：Small Key场景                                     │
│                                                             │
│  QuickList（快速列表）：                                     │
│  ├── Linked List + ListPack                                  │
│  ├── 链表节点使用ListPack存储                                 │
│  └── 适用：List类型大数据场景                                 │
│                                                             │
│  ZipMap（压缩映射）：                                        │
│  └── Hash类型小数据场景                                       │
└─────────────────────────────────────────────────────────────┘
```

## 2. 持久化机制

### 2.1 RDB vs AOF

```
Redis持久化对比：

┌─────────────────────────────────────────────────────────────┐
│  RDB（快照）：                                               │
│  ├── 定期全量快照                                            │
│  ├── 文件紧凑，恢复快                                        │
│  ├── 可能丢失最后一次快照的数据                                │
│  └── 适用：灾难恢复                                          │
│                                                             │
│  AOF（追加日志）：                                           │
│  ├── 记录每个写操作                                          │
│  ├── 数据更安全                                              │
│  ├── 文件较大，恢复慢                                        │
│  └── 适用：数据安全性要求高                                    │
│                                                             │
│  混合持久化（Redis 4.0+）：                                  │
│  ├── AOF重写时使用RDB格式                                    │
│  ├── AOF追加时使用AOF格式                                    │
│  └── 兼顾速度与安全性                                        │
└─────────────────────────────────────────────────────────────┘
```
