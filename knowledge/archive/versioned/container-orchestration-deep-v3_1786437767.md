## 1. K8s核心概念

### 1.1 资源对象

```
Kubernetes资源对象：

┌─────────────────────────────────────────────────────────────┐
│  Pod：最小部署单元                                           │
│  ├── 容器组（可多个容器）                                    │
│  ├── 共享网络命名空间                                       │
│  ├── 共享存储卷                                              │
│  └── 生命周期由Controller管理                               │
│                                                             │
│  Deployment：无状态应用管理                                  │
│  ├── 副本集控制                                              │
│  ├── 滚动更新                                                │
│  ├── 回滚支持                                                │
│  └── 自愈能力                                                │
│                                                             │
│  Service：服务发现与负载均衡                                  │
│  ├── ClusterIP：集群内访问                                   │
│  ├── NodePort：节点端口暴露                                  │
│  ├── LoadBalancer：云服务商LB                                │
│  └── ExternalName：外部服务映射                              │
│                                                             │
│  ConfigMap/Secret：配置管理                                  │
│  ├── ConfigMap：普通配置                                     │
│  └── Secret：敏感信息（Base64编码）                         │
└─────────────────────────────────────────────────────────────┘
```

## 2. 网络插件

### 2.1 CNI对比

```
主流CNI插件对比：

┌─────────────────────────────────────────────────────────────┐
│  Calico：                                                    │
│  ├── IPIP隧道/VXLAN                                         │
│  ├── BGP路由                                                 │
│  ├── 网络策略（NetworkPolicy）                               │
│  └── 适合大规模生产环境                                      │
│                                                             │
│  Flannel：                                                   │
│  ├── VXLAN/Host-GW模式                                      │
│  ├── 简单部署                                               │
│  └── 适合中小型集群                                          │
│                                                             │
│  Cilium：                                                    │
│  ├── eBPF加速                                               │
│  ├── 网络策略                                               │
│  ├── 可观测性                                                │
│  └── 适合高性能场景                                          │
│                                                             │
│  选择建议：                                                  │
│  ├── 简单快速：Flannel                                       │
│  ├── 大规模稳定：Calico                                     │
│  └── 高性能进阶：Cilium                                     │
└─────────────────────────────────────────────────────────────┘
```
