## 1. 进程管理

### 1.1 调度器

```
Linux进程调度：

┌─────────────────────────────────────────────────────────────┐
│  调度策略：                                                  │
│  ├── SCHED_OTHER：默认分时调度                               │
│  ├── SCHED_FIFO：实时先进先出                               │
│  ├── SCHED_RR：实时轮转                                     │
│  └── SCHED_DEADLINE：截止日期调度                           │
│                                                             │
│  CFS（完全公平调度器）：                                     │
│  ├── 红黑树管理进程                                          │
│  ├── vruntime虚拟运行时间                                    │
│  └── 保证每个进程获得公平CPU时间                              │
│                                                             │
│  优先级：                                                   │
│  ├── 静态优先级：100-139（实时）                             │
│  └── 动态优先级：0-139（普通）                               │
└─────────────────────────────────────────────────────────────┘
```

## 2. 内存管理

### 2.1 内存模型

```
Linux内存模型：

┌─────────────────────────────────────────────────────────────┐
│  内核空间：                                                  │
│  ├── 页表                                                   │
│  ├── 内核栈                                                 │
│  └── 内核堆                                                 │
│                                                             │
│  用户空间：                                                  │
│  ├── 代码段（.text）                                        │
│  ├── 数据段（.data）                                        │
│  ├── BSS段（未初始化数据）                                    │
│  ├── 堆（malloc/new）                                       │
│  └── 栈（局部变量、函数调用）                                │
│                                                             │
│  虚拟内存：                                                  │
│  ├── 页表映射                                               │
│  ├── 缺页中断                                               │
│  └── 写时复制（COW）                                       │
└─────────────────────────────────────────────────────────────┘
```
