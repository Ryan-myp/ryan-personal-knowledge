# 广告竞价策略深度解析

> 深入广告竞价策略：oCPM、oCPC、智能出价、预算优化。
> 源码级分析，包含生产环境最佳实践。
> 适用对象：广告算法工程师、后端工程师

---

## 1. 智能出价

### 1.1 出价策略

```
智能出价策略：

┌─────────────────────────────────────────────────────────────┐
│  出价目标：                                                  │
│  ├── oCPM：按转化出价，系统优化CPM                           │
│  ├── oCPC：按点击出价，系统优化CPC                           │
│  ├── oCPV：按可见曝光出价                                    │
│  └── tCPA：目标CPA，控制单次转化成本                          │
│                                                             │
│  出价公式：                                                  │
│  ├── 基础出价 = 目标CPA × pCVR                              │
│  ├── pCVR：点击转化率预估                                    │
│  └── 实时调整 = 基础出价 × 优化系数                          │
│                                                             │
│  优化策略：                                                  │
│  ├── 学习期：新广告需要数据积累                               │
│  ├── 探索与利用：平衡新机会和已知收益                         │
│  └── 阈值控制：出价上限/下限                                  │
└─────────────────────────────────────────────────────────────┘
```

## 2. 预算优化

### 2.1 策略

```
预算优化策略：

┌─────────────────────────────────────────────────────────────┐
│  日预算：                                                    │
│  ├── 控制每日总花费                                          │
│  ├── 避免超支                                                │
│  └── 系统自动平滑投放                                        │
│                                                             │
│  预算分配：                                                  │
│  ├── 按广告组分配                                            │
│  ├── 按时段分配                                              │
│  └── 按人群分配                                              │
│                                                             │
│  出价调整：                                                  │
│  ├── 预算消耗快→降低出价                                      │
│  ├── 预算消耗慢→提高出价                                      │
│  └── 预期ROI调整                                             │
└─────────────────────────────────────────────────────────────┘
```
