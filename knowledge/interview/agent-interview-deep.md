## 一、Agent 架构

**Q1: Agent和传统Chatbot的核心区别？**

```
答案:
• Agent有工具调用能力，可以执行动作
• Agent有记忆系统，保持上下文
• Agent可以自主规划和决策
• Chatbot只是对话系统
```

**Q2: ReAct模式的工作原理？**

```
ReAct = Reasoning + Acting

循环:
Thought: 分析问题，制定计划
Action: 调用工具获取信息
Observation: 观察工具返回结果
(repeat until answer)
Answer: 给出最终答案
```

## 二、记忆系统

**Q3: 三层记忆架构的设计原则？**

```
• L1短期: 快速访问，会话级生命周期
• L2向量: 语义搜索，长期持久化
• L3图谱: 结构化知识，关系推理
```

**Q4: 如何实现记忆遗忘？**

```
• 时间衰减: 艾宾浩斯曲线
• 价值衰减: 低价值信息自动清理
• 冲突更新: 新信息覆盖旧信息
```

## 三、工具调用

**Q5: 工具注册的发现模式？**

```
• 静态注册: 启动时加载
• 动态发现: 运行时注册/注销
• 服务发现: 基于Consul/Nacos
```

**Q6: 工具调用超时如何处理？**

```
• Context超时传播
• 熔断器模式
• 降级策略 (返回缓存/默认值)
```

## 四、安全与评估

**Q7: Jailbreak攻击的主要类型？**

```
• 角色扮演覆盖
• 编码绕过 (Base64/Hex)
• 多语言混合
• 指令注入
• 边界case试探
```

**Q8: Agent评估的四维度？**

```
• Correctness: 答案正确性
• Safety: 安全性
• Efficiency: 效率 (延迟/成本)
• Satisfaction: 用户满意度
```

## 五、系统设计

**Q9: 如何设计一个电商客服Agent？**

```
架构:
1. 意图识别 → 分类器
2. 记忆检索 → 用户历史订单
3. 工具调用 → 订单查询/退换货
4. 安全护栏 → PII过滤/敏感操作确认
5. 输出合成 → 自然语言回复
```

**Q10: 如何实现Agent的长期运行？**

```
方案:
• 断点续传: 状态持久化
• 心跳机制: 保活检测
• 任务队列: 异步执行
• 失败重试: 指数退避
```
