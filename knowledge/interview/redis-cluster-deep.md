## 二、槽位分配

```go
// 16384个槽位
const totalSlots = 16384

// 槽位计算
slot := crc16(key) % totalSlots

// Go语言实现
func getSlot(key string) int {
    hash := crc16.Checksum([]byte(key), crc16.MakeTable(crc16.CRC16))
    return int(hash % totalSlots)
}
```

## 三、故障转移

```
1. 节点失败 → 标记为PFAIL
2. 超过半数标记 → 标记为FAIL
3. 从节点发现主节点失败
4. 触发故障转移选举
5. 当选从节点升级为一道主节点
6. 接管槽位
```

## 四、面试高频题

### Q1: Redis集群如何扩容？

```
A: 添加新节点，迁移部分槽位。
```

### Q2: 什么是槽位？

```
A: 16384个哈希槽，用于数据分片。
```
