## 二、核心组件

### 1. 质量扫描器 (`scripts/knowledge-optimizer.sh`)

**功能**:
- 扫描所有 `-deep.md` 文档
- 计算代码密度、质量评分
- 识别问题文档（低质量/无代码/无QA）
- 生成质量报告

**评分标准**:

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| 文件大小 | 25% | ≥15KB: 25分, ≥10KB: 20分, ≥5KB: 15分, ≥2KB: 10分, <2KB: 5分 |
| 代码密度 | 30% | ≥35%: 30分, ≥25%: 25分, ≥15%: 20分, ≥10%: 15分, <10%: 10分 |
| 结构完整性 | 25% | Frontmatter +5, 章节+5, 代码块+5, QA+5, 表格+5 |
| 实战价值 | 20% | 示例+7, 性能+7, 排障+6 |

**健康度评级**:
- 90-100: ⭐★★★★★ 专家级
- 80-89:  ⭐★★★★☆ 优秀
- 70-79:  ⭐★★★☆☆ 良好
- 60-69:  ⭐★★☆☆☆ 及格
- <60:    ⭐★☆☆☆☆ 待提升

### 2. 内容生成器 (AI驱动)

**自动生成流程**:

```
问题识别 → 主题选择 → 内容生成 → 质量检查 → Git提交
```

**生成规则**:
- 新文档必须≥5KB
- 代码密度≥25%
- 包含≥3道自测题
- 包含对比表格或架构图

### 3. 自动提交 (Git Hook)

**post-commit钩子**:
- 触发Wiki同步
- 更新质量报告
- 发送通知（可选）

## 三、定时任务

### Cron配置

```bash

0 2 * * 0 cd /Users/yanping.ma/ryan-personal-knowledge && bash scripts/weekly-optimize.sh

# 每天 06:00 执行快速扫描
0 6 * * * cd /Users/yanping.ma/ryan-personal-knowledge && bash scripts/knowledge-optimizer.sh --quick
```

### 执行流程

**每日快速扫描**:
1. 扫描质量变化
2. 更新统计面板
3. 检测新增低质文档

**每周完整优化**:
1. 全量质量扫描
2. 清理低质文档
3. 识别增强需求
4. 生成本周任务
5. 提交优化报告
