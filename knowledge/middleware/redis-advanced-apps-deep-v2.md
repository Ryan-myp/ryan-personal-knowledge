## 1. 缓存设计

### 1.1 经典问题

```
Redis缓存经典问题：

┌─────────────────────────────────────────────────────────────┐
│  缓存穿透：                                                  │
│  ├── 问题：查询不存在的数据                                   │
│  ├── 解决：布隆过滤器 / 缓存空值                              │
│  └── 空值TTL设置（5-10分钟）                                  │
│                                                             │
│  缓存击穿：                                                  │
│  ├── 问题：热点Key过期，大量请求打到DB                       │
│  ├── 解决：互斥锁 / 永不过期 / 二级缓存                       │
│  └── 互斥锁实现（SET NX EX）                                  │
│                                                             │
│  缓存雪崩：                                                  │
│  ├── 问题：大量Key同时过期                                   │
│  ├── 解决：TTL加随机值 / 集群部署 / 限流降级                  │
│  └── 随机TTL：base + random(0, expire/2)                    │
│                                                             │
│  缓存一致性：                                                │
│  ├── Cache-Aside：先删缓存，再更新DB                         │
│  ├── 延迟双删：先删->更新->延迟删                             │
│  └── Canal监听Binlog异步更新                                  │
└─────────────────────────────────────────────────────────────┘
```
