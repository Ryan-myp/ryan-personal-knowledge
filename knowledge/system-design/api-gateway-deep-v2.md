## 2. Kong架构

### 2.1 核心组件

```
Kong架构：

┌─────────────────────────────────────────────────────────────┐
│  Kong Gateway：                                              │
│  ├── Nginx核心                                               │
│  ├── OpenResty（Lua扩展）                                   │
│  ├── 插件系统                                                │
│  └── Dashboard（管理界面）                                   │
│                                                             │
│  DB层：                                                      │
│  ├── Postgres/Cassandra（存储配置）                         │
│  └── 可选：不使用DB（纯Kong）                               │
│                                                             │
│  Kong Manager：                                              │
│  ├── 可视化配置                                              │
│  ├── 监控报表                                                │
│  └── 用户管理                                                │
│                                                             │
│  Plugin开发：                                                │
│  ├── init_by_lua：初始化                                     │
│  ├── access_by_lua：请求处理                                 │
│  ├── header_filter_by_lua：响应头处理                        │
│  └── log_by_lua：日志处理                                    │
└─────────────────────────────────────────────────────────────┘
```
