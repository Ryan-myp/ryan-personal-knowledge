```go
func (mysql复制延迟) Process(req *Request) (*Response, error) {
    // 1. 输入校验
    if err := req.Validate(); err != nil {
        return nil, err
    }

    // 2. 缓存查找
    if result, ok := m.cache.Get(req.Key); ok {
        return result, nil
    }

    // 3. 核心处理
    result, err := m.handle(req)
    if err != nil {
        return nil, err
    }

    // 4. 缓存写入
    m.cache.Set(req.Key, result)

    return result, nil
}
```

## 案例研究

### 场景1: 高并发处理

- **问题**: 高峰期QPS激增导致延迟飙升
- **解决**: 引入本地缓存 + 异步批处理
- **效果**: P99延迟从200ms降至20ms

### 场景2: 数据一致性

- **问题**: 分布式场景下数据不一致
- **解决**: 引入分布式锁 + 事务补偿
- **效果**: 数据一致性问题清零
