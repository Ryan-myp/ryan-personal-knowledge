# Kibana 仪表盘设计指南

> 深入 Kibana 可视化、告警配置、Dashboard 设计。

---

## 1. Dashboard 设计原则

```
┌─────────────────────────────────────────────────────────────┐
│                    系统监控大盘                              │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐         │
│  │   QPS 趋势  │  │  错误率     │  │  P99 延迟   │         │
│  │   (Line)    │  │  (Gauge)    │  │  (Bar)      │         │
│  └─────────────┘  └─────────────┘  └─────────────┘         │
│  ┌─────────────────────────────────────────────────────┐   │
│  │                    错误日志分布                      │   │
│  │                    (Pie Chart)                      │   │
│  └─────────────────────────────────────────────────────┘   │
│  ┌─────────────┐  ┌─────────────┐                         │
│  │   Top API   │  │  服务器状态  │                         │
│  │   (Table)   │  │ (Heatmap)   │                         │
│  └─────────────┘  └─────────────┘                         │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 常用可视化类型

| 类型 | 用途 | 配置要点 |
|------|------|----------|
| Line | 趋势分析 | 分组字段、聚合方式 |
| Pie | 占比分析 | 限制切片数量 |
| Table | 详细数据 | 列排序、分页 |
| Heatmap | 流量图 | 分桶大小 |
| Gauge | 阈值监控 | 颜色区间 |

---

## 3. 告警配置

```json
{
  "rule": {
    "type": "query",
    "index": "logs-*",
    "query": {
      "lang": "kuery",
      "query": "status: >= 500"
    },
    "bucket_path": {
      "avg_cpu": "_bucket_1>avg_cpu{avg=AVG}._value"
    },
    "conditions": [{
      "check": "avg_cpu >",
      "threshold": [80]
    }]
  }
}
```
