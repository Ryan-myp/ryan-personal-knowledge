# 知识蒸馏工作流

> 如何从微信读书中提取知识并融入专家知识库

## 蒸馏流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     知识蒸馏流程                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 阅读                                                          │
│     ├── 在微信读书中阅读目标书籍                                  │
│     ├── 标记重点划线和想法                                        │
│     └── 记录阅读进度                                              │
│            ↓                                                      │
│  2. 整理                                                          │
│     ├── 导出划线和想法                                            │
│     ├── 提炼核心概念和框架                                        │
│     └── 识别可实践的应用场景                                      │
│            ↓                                                      │
│  3. 蒸馏                                                          │
│     ├── 使用 BOOK-NOTE-TEMPLATE.md 模板                           │
│     ├── 转换为 ASCII 图表和代码示例                               │
│     └── 关联到现有 knowledge/skills                               │
│            ↓                                                      │
│  4. 入库                                                          │
│     ├── 保存为 weread-{book-name}-deep.md                        │
│     ├── 更新对应 skill 的引用                                     │
│     └── 同步到 knowledge-search 索引                              │
│            ↓                                                      │
│  5. 应用                                                          │
│     ├── 实践验证                                                  │
│     ├── 收集 feedback                                             │
│     └── 迭代优化                                                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 蒸馏标准

### 合格标准（必须全部满足）

| 要素 | 说明 | 检查项 |
|------|------|--------|
| **核心框架** | 用 ASCII 图展示关键概念 | ✅ 有架构图/流程图 |
| **代码示例** | 提供可运行的代码片段 | ✅ 有 Go/Python 示例 |
| **对比表格** | 与相关方案对比 | ✅ 有对比表 |
| **应用场景** | 至少 2 个实际应用 | ✅ 有场景说明 |
| **自测题** | 至少 3 个问题 | ✅ 有自测题 |
| **知识关联** | 链接到现有文档 | ✅ 有关联表 |

### 不合格情况

❌ 只摘录原文不做提炼
❌ 没有实际应用场景
❌ 没有代码示例或图表
❌ 超过 2000 行的冗长笔记
❌ 没有关联到现有知识库

## 书籍分类与目标 Skill

| 书籍类型 | 目标 Skill | 蒸馏重点 |
|---------|-----------|---------|
| Agent/AI 类 | agent-* | 架构模式、实现细节 |
| 广告业务类 | ad-* | 系统架构、算法原理 |
| 全栈技术类 | go/mysql/redis/es-* | 源码解析、调优方案 |
| 管理成长类 | tech-leadership/team-* | 方法论、实践案例 |
| 设计架构类 | architecture/* | 设计模式、决策框架 |

## 快速蒸馏检查清单

在阅读完成后，确认以下问题：

- [ ] 这本书的核心框架是什么？（能用一张图说清楚）
- [ ] 有哪些可以立即应用的代码/方法？
- [ ] 与已有知识有什么关系？（关联表格）
- [ ] 有哪些自测题可以检验理解？
- [ ] 如何更新对应的 expert skill？

## 批量蒸馏策略

### 单本书蒸馏（推荐）

适用于：核心专业书籍
步骤：
1. 阅读全书（1-2 周）
2. 导出所有划线和想法
3. 按主题分组提炼
4. 创建完整笔记文件
5. 更新相关 skill

### 快速概览（辅助）

适用于：扩展阅读
步骤：
1. 阅读目录和简介
2. 找出核心章节
3. 提炼关键框架
4. 创建简明笔记（500-800 行）
5. 只关联到最相关的 skill

## 与知识搜索集成

蒸馏完成后：

```bash
cd knowledge-search
python3 query_knowledge.py "关键词" --rebuild

python3 query_knowledge.py "书中核心概念" --verbose

# 编辑对应的 SKILL.md，添加新的知识库引用
```
