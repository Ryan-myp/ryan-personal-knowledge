# 微信读书蒸馏笔记方法

> 深入知识提炼方法：划线筛选、笔记整理、知识关联、输出转化。
> 适用对象：终身学习者、知识工作者

---

## 1. 阅读三遍法

```
第一遍：快速浏览
  ├── 了解书籍结构
  ├── 标记感兴趣章节
  └── 不做详细笔记

第二遍：深度阅读
  ├── 逐章精读
  ├── 划出关键内容
  └── 写下初步感想

第三遍：提炼输出
  ├── 整理划线内容
  ├── 提炼核心观点
  └── 转化为行动清单
```

---

## 2. 笔记整理框架

| 类型 | 说明 | 示例 |
|------|------|------|
| 原文摘录 | 书中原话 | "技术债务像信用卡..." |
| 个人理解 | 用自己的话解释 | 这句话的意思是... |
| 行动清单 | 可执行的动作 | 下周开始做... |
| 知识关联 | 与其他知识的联系 | 这让我想起... |
| 疑问思考 | 未解决的问题 | 如何平衡... |

---

```
┌─────────────────────────────────────────────────────────────────┐
│                     知识网络构建                                │

│                                                                 │

```
