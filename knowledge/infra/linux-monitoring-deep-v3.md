## 2. 内存监控

### 2.1 核心指标

```
Linux内存监控：

┌─────────────────────────────────────────────────────────────┐
│  free：                                                      │
│  ├── 内存使用情况                                            │
│  ├── 可用内存（available）                                    │
│  └── 缓冲/缓存（buff/cache）                                  │
│                                                             │
│  vmstat：                                                    │
│  ├── si/so：swap in/out                                      │
│  ├── free：空闲内存                                          │
│  └── buff/cache：缓冲缓存                                    │
│                                                             │
│  /proc/meminfo：                                             │
│  ├── MemTotal：总内存                                        │
│  ├── MemFree：空闲内存                                       │
│  ├── MemAvailable：可用内存                                   │
│  ├── Buffers：缓冲                                           │
│  └── Cached：缓存                                            │
│                                                             │
│  关键指标：                                                  │
│  ├── 内存不足：si/so持续非零                                  │
│  ├── OOM风险：MemAvailable过低                                │
│  └── 缓存占用：Cached高是正常的                               │
└─────────────────────────────────────────────────────────────┘
```

## 3. 自测题

### 3.1 单选题

1. Linux中，查看内存可用量（而非空闲量）的命令是：
   A. free -m  B. cat /proc/meminfo  C. vmstat  D. top
   答案：B（MemAvailable字段）
