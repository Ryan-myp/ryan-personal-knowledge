## 1. 列式存储

### 1.1 存储原理

```
ClickHouse列式存储：

┌─────────────────────────────────────────────────────────────┐
│  行式存储 vs 列式存储：                                      │
│                                                             │
│  行式（MySQL）：                                             │
│  ┌──────────┬──────────┬──────────┐                       │
│  │ row_id   │ name     │ age      │                       │
│  ├──────────┼──────────┼──────────┤                       │
│  │ 1        │ Alice    │ 25       │                       │
│  │ 2        │ Bob      │ 30       │                       │
│  └──────────┴──────────┴──────────┘                       │
│                                                             │
│  列式（ClickHouse）：                                       │
│  ┌──────────┬──────────┬──────────┐                       │
│  │ row_id   │          │          │                       │
│  ├──────────┼──────────┼──────────┤                       │
│  │ 1        │ Alice    │ 25       │                       │
│  │ 2        │ Bob      │ 30       │                       │
│  └──────────┴──────────┴──────────┘                       │
│  每个列独立存储，连续内存                                    │
│                                                             │
│  优势：                                                      │
│  ├── 列裁剪：只读取需要的列                                   │
│  ├── 向量化执行：SIMD指令加速                                │
│  ├── 数据压缩：同类型数据压缩率高                             │
│  └── 适合OLAP分析场景                                       │
└─────────────────────────────────────────────────────────────┘
```

## 2. 数据压缩

### 2.1 压缩算法

```
ClickHouse压缩算法：

┌─────────────────────────────────────────────────────────────┐
│  压缩算法选择：                                              │
│  ├── Null：空值快速压缩                                      │
│  ├── Delta：差分编码（整数列）                               │
│  ├── DoubleDelta：双重差分                                   │
│  ├── Gorilla：浮点数压缩                                     │
│  ├── LZ4：速度快，压缩率中等                                  │
│  ├── ZSTD：压缩率高，速度慢                                  │
│  └── ZLIB：标准压缩                                          │
│                                                             │
│  默认压缩：LZ4（写入性能优先）                               │
│  可选压缩：ZSTD（存储优先）                                  │
│                                                             │
│  压缩效果：                                                  │
│  ├── 整数：压缩比10-100x                                    │
│  ├── 字符串：压缩比5-20x                                    │
│  └── 日期时间：压缩比极高                                    │
└─────────────────────────────────────────────────────────────┘
```
