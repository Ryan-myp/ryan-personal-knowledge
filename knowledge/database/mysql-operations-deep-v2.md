## 1. 监控指标

### 1.1 核心指标

```
MySQL核心监控指标：

┌─────────────────────────────────────────────────────────────┐
│  连接相关：                                                  │
│  ├── Threads_connected：当前连接数                            │
│  ├── Threads_running：活跃连接数                              │
│  ├── Max_used_connections：历史最大连接数                      │
│  └── Aborted_connects：连接失败数                            │
│                                                             │
│  查询相关：                                                  │
│  ├── QPS：每秒查询数                                         │
│  ├── TPS：每秒事务数                                         │
│  ├── Slow_queries：慢查询数                                   │
│  └── Questions：总查询数                                     │
│                                                             │
│  缓冲池相关：                                                │
│  ├── Innodb_buffer_pool_pages_free：空闲页数                  │
│  ├── Innodb_buffer_pool_read_requests：读请求数               │
│  └── Innodb_buffer_pool_reads：物理读数                      │
│                                                             │
│  复制相关：                                                  │
│  ├── Seconds_Behind_Master：主从延迟                          │
│  ├── Slave_IO_Running：IO线程状态                             │
│  └── Slave_SQL_Running：SQL线程状态                           │
└─────────────────────────────────────────────────────────────┘
```

## 2. 备份策略

### 2.1 备份方案

```
MySQL备份方案：

┌─────────────────────────────────────────────────────────────┐
│  全量备份：                                                  │
│  ├── mysqldump：逻辑备份，适合小数据量                        │
│  ├── XtraBackup：物理备份，支持热备                          │
│  └── Percona Toolkit：备份管理工具                           │
│                                                             │
│  增量备份：                                                  │
│  ├── Binlog：二进制日志                                     │
│  ├── Point-in-Time Recovery：时间点恢复                      │
│  └── 结合全量+增量恢复                                       │
│                                                             │
│  备份策略：                                                  │
│  ├── 每日全量备份（低峰期）                                   │
│  ├── 实时Binlog备份                                          │
│  ├── 备份文件异地存储                                         │
│  └── 定期恢复演练                                            │
└─────────────────────────────────────────────────────────────┘
```
