# ClickHouse内核深度解析

> 深入ClickHouse内核：列式存储、MergeTree、向量化执行。
> 源码级分析，包含生产环境最佳实践。
> 适用对象：数据工程师、DBA

---

## 1. MergeTree引擎

### 1.1 数据组成

```
MergeTree数据组成：

┌─────────────────────────────────────────────────────────────┐
│  数据文件：                                                  │
│  ├── .bin：列数据文件（每列一个文件）                         │
│  ├── .mrk：标记文件（索引.bin文件偏移）                       │
│  └── .dim：维度文件（稀疏索引）                              │
│                                                             │
│  索引文件：                                                  │
│  ├── primary.idx：主键索引（sparse granule index）            │
│  └── minmax_*.idx：各列最小最大值索引                          │
│                                                             │
│  分区（Partition）：                                         │
│  ├── 物理隔离                                                 │
│  ├── 按日期/业务字段划分                                      │
│  └── ALTER TABLE DELETE INSERT支持                           │
│                                                             │
│  粒度（Granule）：                                           │
│  ├── 默认8192行                                              │
│  ├── 查询的最小读取单元                                       │
│  └── 主键索引针对granule而非行                                 │
└─────────────────────────────────────────────────────────────┘
```

## 2. 向量化执行

### 2.1 执行原理

```
向量化执行流程：

┌─────────────────────────────────────────────────────────────┐
│  传统行式执行：                                              │
│  └── 逐行处理：读取一行 → 过滤 → 聚合 → 写入一行              │
│                                                             │
│  向量化执行：                                                │
│  └── 逐列处理：读取一列数据（Native Vector）                  │
│      ├── SIMD指令加速                                        │
│      ├── 减少分支预测失败                                    │
│      └── CPU缓存友好                                         │
│                                                             │
│  执行优化：                                                  │
│  ├── 列裁剪：只读取需要的列                                   │
│  ├── 谓词下推：在存储层过滤                                   │
│  ├── 并行扫描：多Core并行处理                                │
│  └── 增量聚合：实时更新中间结果                               │
└─────────────────────────────────────────────────────────────┘
```
