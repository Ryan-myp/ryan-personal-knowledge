# ClickHouse 内核深度解析

> 深入ClickHouse内核：列式存储、MergeTree、向量化执行。
> 基于《ClickHouse原理解析与应用实践》（朱凯著）蒸馏。
> 适用对象：数据工程师、DBA

---

## 1. 列式存储

### 1.1 存储结构

```
ClickHouse 列式存储：

┌─────────────────────────────────────────────────────────────┐
│  表 = 分区 (Partition) + 数据部分 (Parts)                   │
│                                                             │
│  每个Part：                                                 │
│  ├── 主键索引 (.mrk2文件)                                   │
│  ├── 列数据 (.bin文件)                                      │
│  └── 标记文件 (.mrk)                                        │
│                                                             │
│  列编码：                                                   │
│  ├── Delta：差值编码                                        │
│  ├── RT trie：重复值压缩                                    │
│  ├── LZ4：通用压缩                                          │
│  └── ZSTD：高压缩比                                         │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. MergeTree引擎

### 2.1 数据合并

```
MergeTree 合并机制：

┌─────────────────────────────────────────────────────────────┐
│  后台合并：                                                 │
│  ├── 插入新数据 → 创建新Part                                 │
│  ├── 定期后台合并：选择相邻Part合并                           │
│  └── 最终形成一个大Part                                      │
│                                                             │
│  主键：                                                     │
│  ├── 稀疏索引，每8192行一个索引点                             │
│  └── 只用于跳过不满足条件的数据块                             │
│                                                             │
│  分区键：                                                   │
│  └── 数据按分区键物理分离，查询时可跳过无关分区               │
└─────────────────────────────────────────────────────────────┘
```
