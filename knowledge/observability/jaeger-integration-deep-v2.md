## 1. OpenTelemetry集成

### 1.1 自动埋桩

```
OpenTelemetry自动埋桩：

┌─────────────────────────────────────────────────────────────┐
│  HTTP自动埋桩：                                              │
│  ├── 自动记录请求/响应                                       │
│  ├── 自动提取Trace Context                                   │
│  └── 自动添加Span                                            │
│                                                             │
│  数据库自动埋桩：                                            │
│  ├── SQL语句记录                                             │
│  ├── 执行时间统计                                            │
│  └── 错误信息                                                │
│                                                             │
│  gRPC自动埋桩：                                              │
│  ├── 服务端自动记录                                          │
│  ├── 客户端自动记录                                          │
│  └── 上下文传播                                              │
│                                                             │
│  配置：                                                      │
│  ├── OTEL_SERVICE_NAME：服务名                               │
│  ├── OTEL_TRACES_SAMPLER：采样器                             │
│  └── OTEL_EXPORTER_OTLP_ENDPOINT：导出端点                   │
└─────────────────────────────────────────────────────────────┘
```

## 2. Jaeger集成

### 2.1 架构部署

```
Jaeger架构：

┌─────────────────────────────────────────────────────────────┐
│  Collector：                                                 │
│  ├── 接收Span数据                                            │
│  ├── 批量写入Storage                                         │
│  └── HTTP/gRPC接口                                          │
│                                                             │
│  Storage：                                                   │
│  ├── Elasticsearch：生产推荐                                  │
│  ├── Cassandra：大规模场景                                    │
│  └── Memory：测试开发                                        │
│                                                             │
│  Query Service：                                             │
│  ├── 查询接口                                                │
│  └── 返回Trace信息                                           │
│                                                             │
│  UI：                                                        │
│  ├── Trace可视化                                             │
│  ├── 依赖图                                                  │
│  └── 性能分析                                                │
│                                                             │
│  部署模式：                                                  │
│  ├── All-in-One：开发测试                                    │
│  └── Production：分离部署                                    │
└─────────────────────────────────────────────────────────────┘
```
