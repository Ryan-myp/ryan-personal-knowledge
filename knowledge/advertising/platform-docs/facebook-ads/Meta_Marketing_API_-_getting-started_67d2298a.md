开始使用营销 API 更新时间 : 2026年6月16日 为 LLM 复制 作为 Markdown 查看 WhatsApp 动态广告可通过市场营销 API 获取。 详细了解 WhatsApp 动态中的广告。 要使用市场营销 API,你必须遵循一些关键步骤来设置你的环境并获得 API 功能的访问权限。本部分概述了开始使用此 API 的必要前提条件。 广告帐户要求 如要通过市场营销 API 管理广告，您必须拥有 活跃广告账户 ⁠ ，才能投放广告系列和管理账单。广告账户可以让你追踪广告费用,监控表现,优化广告系列。 寻找你的广告账号 在 Meta 广告管理工具 ⁠ 中查找您的广告账户编号。 登录 Facebook： 先登录与您的公司关联的 Facebook 账户。 访问广告管理工具： 在 Facebook 首页或业务公共主页右上角的下拉菜单中找到广告管理工具。 找到广告账户： 在广告管理工具中，点击屏幕左下方菜单中的广告账户“设置”。 查看广告账户信息： 在“设置”屏幕中，您的广告账户编号显示在“账户概览”部分，其他详细信息也会显示，例如账单信息和花费限额。 Meta 开发者账户 详情请参阅 注册成为 Meta 开发者 。 创建应用 参阅 创建应用 ，详细了解如何在应用面板中设置应用以及应用类型和用例。 授权和认证 请参见 Authorization 了解更多关于验证将访问市场营销 API并授予他们权限的用户和应用程序的信息。 参见 Authentication 了解更多关于使用营销 API获取、扩展和更新访问口令的信息。 继续学习 创建广告系列 管理广告系列 优化广告系列
