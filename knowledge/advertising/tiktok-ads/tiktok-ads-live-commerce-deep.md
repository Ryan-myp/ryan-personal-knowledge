### 2.2 Spark Ads 直播切片

```
Spark Ads 直播切片工作流程：

1. 达人授权
   ├── 达人在 TikTok 创作者市场授权品牌使用其直播内容
   ├── 选择授权的直播视频片段（最长 60 秒）
   └── 设置授权期限和使用范围

2. 素材选择
   ├── 从直播中选取高光时刻（产品演示、试用、互动）
   ├── 保留原生互动数据（点赞、评论、分享数）
   └── 添加品牌元素（Logo、CTA）

3. 广告投放
   ├── 作为标准 In-Feed 广告或 Spark Ads 投放
   ├──  targeting 设置与常规广告相同
   └── 追踪直播专属转化（Live Shopping events）

4. 效果追踪
   ├── 直播观看量 → Spark Ads 播放量
   ├── 直播间互动 → Spark Ads 互动
   └── 直播转化 → Spark Ads 转化
```

## 三、直播带货投放策略

### 3.1 直播前准备

```
直播前 48 小时准备清单：

□ 达人签约
  □ 确认达人档期和直播主题
  □ 确认商品清单和价格
  □ 确认佣金比例和结算方式
  □ 签署 MCN/达人协议

□ 商品准备
  □ 商品详情页优化（图片、描述、价格）
  □ 库存确认（避免超卖）
  □ 物流配置（发货时效承诺）
  □ 优惠券/促销活动设置

□ 广告投放准备
  □ 创建广告账户和 Pixel
  □ 准备直播预告素材
  □ 设置转化追踪（Live Shopping events）
  □ 预设投放预算和出价策略

□ 内容准备
  □ 直播脚本（Product intro → Demo → Q&A → CTA）
  □ 样品准备和测试
  □ 互动话术准备
  □ 应急预案（网络/设备故障）
```

### 4.2 达人筛选标准

```
达人筛选评估模型：

1. 粉丝质量 (权重 30%)
   ├── 粉丝数: 10K-500K (KOC 到 KOL 区间)
   ├── 粉丝活跃度: 互动率 > 3%
   ├── 粉丝画像: 年龄/地域/兴趣匹配目标用户
   └── 粉丝增长趋势: 近 30 天增长 > 5%

2. 内容质量 (权重 25%)
   ├── 内容垂直度: 与品类相关度 > 70%
   ├── 内容频率: 每周 ≥ 3 条
   ├── 内容风格: 与品牌调性匹配
   └── 历史带货表现: 平均 GMV per live

3. 带货能力 (权重 30%)
   ├── 直播频率: 每周 ≥ 2 场
   ├── 场均观看: > 1000
   ├── 转化率: > 2%
   └── 客单价匹配度

4. 合作成本 (权重 15%)
   ├── 佣金比例: 行业基准范围内
   ├── 预付费用: 在预算内
   └── ROI 预期: 预计 > 2.0x
```

## 五、自测题

### Q1: Spark Ads 直播切片相比原生广告有什么优势？

<details>
<summary>点击查看答案</summary>

Spark Ads 直播切片的独特优势：

1. **原生感强**: 内容来自真实直播，不是硬广，用户接受度高
2. **社交证明**: 保留了原始直播的互动数据（点赞、评论数），增强信任
3. **低成本**: 无需专门拍摄素材，复用直播内容
4. **可追投**: 表现好的直播切片可以持续投放，延长生命周期
5. **达人背书**: 如果达人有一定影响力，其内容自带信任

适用场景：
- 达人直播的精彩片段推广
- 已验证的带货内容二次传播
- 低预算场景下的高效素材获取
</details>

### Q2: 直播带货的 ROI 通常比短视频广告高还是低？为什么？

<details>
<summary>点击查看答案</summary>

通常情况下，直播带货的 ROI 高于短视频广告，原因：

1. **实时互动**: 主播可以即时回答疑问，消除购买障碍
2. **紧迫感**: 限时优惠、库存告急等话术推动快速决策
3. **信任建立**: 长期直播积累的粉丝信任度高
4. **多商品展示**: 一场直播可以推多个商品，提高客单价
5. **数据反馈快**: 实时看到转化数据，可以快速调整策略

但也要注意：
- 直播带货的启动成本高（达人费用、设备、团队）
- 对达人的依赖度高
- 需要持续投入才能维持效果
- 适合有稳定供应链和复购产品的品牌
</details>
