## 3. 核心实现

```go
// 货币映射 核心实现
func main() {
    engine := NewEngine()
    engine.Start()
    defer engine.Stop()

    for req := range engine.chan {
        result := engine.Process(req)
        engine.Respond(result)
    }
}
```
