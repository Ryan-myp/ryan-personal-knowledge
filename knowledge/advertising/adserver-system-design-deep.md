# AdServer系统架构深度解析

> 深入AdServer：请求处理、广告选择、频次控制、效果追踪。
> 源码级分析，包含生产环境最佳实践。
> 适用对象：广告系统架构师、后端工程师

---

## 1. AdServer核心流程

### 1.1 请求处理

```
AdServer请求处理流程：

┌─────────────────────────────────────────────────────────────┐
│  1. 请求接入                                                 │
│     ├── 解析请求参数（广告位ID、用户ID、设备信息等）         │
│     ├── 用户画像查询                                         │
│     └── 上下文信息获取                                       │
│                                                             │
│  2. 广告选择                                                 │
│     ├── 候选广告筛选                                        │
│     ├── 定向匹配（人群、地域、时间等）                       │
│     ├── 频次控制                                            │
│     └── 创意选择                                            │
│                                                             │
│  3. 竞价决策                                                 │
│     ├── 底价判断                                            │
│     ├── 出价计算                                            │
│     └── 胜出判断                                            │
│                                                             │
│  4. 广告返回                                                 │
│     ├── 生成创意HTML/JSON                                   │
│     ├── 嵌入追踪像素                                        │
│     └── 返回Publisher                                        │
└─────────────────────────────────────────────────────────────┘
```

## 2. 频次控制

### 2.1 控制策略

```
频次控制策略：

┌─────────────────────────────────────────────────────────────┐
│  控制维度：                                                  │
│  ├── 用户维度：同一用户N次                                  │
│  ├── 设备维度：同一设备N次                                  │
│  ├── 广告位维度：同一广告位N次                              │
│  └── 创意维度：同一创意N次                                  │
│                                                             │
│  时间窗口：                                                  │
│  ├── 日频次：每天最多N次                                    │
│  ├── 周频次：每周最多N次                                    │
│  └── 总频次：总共最多N次                                    │
│                                                             │
│  存储方案：                                                  │
│  ├── Redis：计数器模式                                       │
│  ├── Bloom Filter：概率去重                                 │
│  └── 本地缓存：热点数据                                     │
└─────────────────────────────────────────────────────────────┘
```
