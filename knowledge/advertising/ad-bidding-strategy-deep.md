# 广告竞价策略深度解析

> 深入广告竞价策略：oCPM、oCPC、智能出价、预算优化。
> 基于《智能营销与计算广告》（陈韵博著）蒸馏。
> 适用对象：广告算法工程师、优化师

---

## 1. 竞价类型

### 1.1 主要竞价模式

```
广告竞价模式：

┌─────────────────────────────────────────────────────────────┐
│  1. CPM (Cost Per Mille) - 按千次展示付费                    │
│     ├── 按固定价格竞价                                       │
│     ├── 适合品牌曝光                                         │
│     └── 出价 = CPM价格                                      │
│                                                             │
│  2. CPC (Cost Per Click) - 按点击付费                        │
│     ├── 按点击出价                                           │
│     ├── 适合效果广告                                         │
│     └── 出价 = CPC价格                                      │
│                                                             │
│  3. oCPM (Optimized CPM) - 智能出价                          │
│     ├── 目标转化成本出价                                     │
│     ├── 系统自动优化                                         │
│     └── 出价 = 目标成本 × pCTV                               │
│                                                             │
│  4. oCPC (Optimized CPC) - 智能点击出价                      │
│     ├── 第一阶段：学习期（收集转化数据）                       │
│     ├── 第二阶段：优化期（系统自动出价）                       │
│     └── 出价 = 目标成本 × pCTR × CVR_rate                    │
│                                                             │
│  5. CPA (Cost Per Action) - 按转化付费                         │
│     ├── 按实际转化出价                                       │
│     ├── 风险最高                                             │
│     └── 适合APP下载、注册等                                 │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 智能出价

### 2.1 oCPM 原理

```
oCPM 智能出价原理：

┌─────────────────────────────────────────────────────────────┐
│  公式：Bid = Target_CPA × pCVR × pCTR                       │
│                                                             │
│  其中：                                                     │
│  ├── Target_CPA：广告主设定的目标转化成本                      │
│  ├── pCVR：转化概率预估                                      │
│  └── pCTR：点击概率预估                                      │
│                                                             │
│  学习期：                                                    │
│  ├── 前N次曝光：按历史平均转化率出价                           │
│  ├── 收集转化数据                                            │
│  └── 模型训练优化                                            │
│                                                             │
│  优化期：                                                    │
│  ├── 实时调整出价                                            │
│  ├── 根据转化反馈学习                                        │
│  └── 平衡消耗与成本                                          │
└─────────────────────────────────────────────────────────────┘
```
