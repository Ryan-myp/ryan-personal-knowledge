# 广告推荐系统深度解析

> 深入广告推荐系统：召回、排序、重排、反馈学习。
> 源码级分析，包含生产环境最佳实践。
> 适用对象：推荐算法工程师、广告算法工程师

---

## 1. 推荐系统架构

### 1.1 经典推荐流程

```
广告推荐系统流程：

┌─────────────────────────────────────────────────────────────┐
│  用户请求                                                   │
│       ↓                                                     │
│  ┌─────────┐                                                │
│  │ 召回层  │ ← 从百万级候选中筛选千级                        │
│  │ (Recall)│   候选集                                       │
│  └────┬────┘                                                │
│       ↓                                                     │
│  ┌─────────┐                                                │
│  │ 粗排层  │ ← 快速排序，筛选百级                            │
│  │ (Pre-rank)│                                              │
│  └────┬────┘                                                │
│       ↓                                                     │
│  ┌─────────┐                                                │
│  │ 精排层  │ ← 精确排序，选出TOP-K                           │
│  │ (Rank)  │   广告                                         │
│  └────┬────┘                                                │
│       ↓                                                     │
│  ┌─────────┐                                                │
│  │ 重排层  │ ← 策略调整（频控/多样性/商业化）                │
│  │ (Re-rank)│                                                │
│  └────┬────┘                                                │
│       ↓                                                     │
│  ┌─────────┐                                                │
│  │ 曝光    │ ← 记录反馈数据                                 │
│  └─────────┘                                                │
└─────────────────────────────────────────────────────────────┘
```

## 2. 召回策略

### 2.1 多路召回

```
多路召回策略：

┌─────────────────────────────────────────────────────────────┐
│  1. 向量召回 (Embedding)                                     │
│     ├── DSSM、Double Tower                                 │
│     └── 用户画像 → 广告向量匹配                             │
│                                                             │
│  2. 协同过滤召回                                             │
│     ├── UserCF：相似用户喜欢的广告                          │
│     ├── ItemCF：相似广告                                    │
│     └── Matrix Factorization                               │
│                                                             │
│  3. 规则召回                                                 │
│     ├── 热门广告                                           │
│     ├── 新用户冷启动                                        │
│     └── 定向条件匹配                                        │
│                                                             │
│  4. 实时召回                                                 │
│     ├── 用户行为序列                                        │
│     ├── 上下文感知                                        │
│     └── 实时兴趣更新                                       │
└─────────────────────────────────────────────────────────────┘
```
