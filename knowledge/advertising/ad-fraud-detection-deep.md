# 广告反欺诈深度解析

> 深入广告反欺诈：作弊识别、风控策略、特征工程。
> 基于《广告数据定量分析》（齐云涧著）蒸馏。
> 适用对象：风控工程师、广告算法工程师

---

## 1. 欺诈类型

### 1.1 主要欺诈类型

```
广告欺诈类型：

┌─────────────────────────────────────────────────────────────┐
│  1. 点击欺诈 (Click Fraud)                                  │
│     ├── 点击农场：人工或自动化点击                            │
│     ├── 恶意点击：竞争对手恶意点击                            │
│     └── 激励点击：给用户利益诱导点击                          │
│                                                             │
│  2. 展示欺诈 (Impression Fraud)                             │
│     ├── 隐形展示：广告不可见                                   │
│     ├── 机器人流量：非人类流量                                │
│     └── 像素 stuffing：同一页面多次展示                        │
│                                                             │
│  3. 转化欺诈 (Conversion Fraud)                              │
│     ├── 虚假注册：机器人注册                                  │
│     ├── 刷单：虚假购买行为                                   │
│     └── 归因劫持：劫持他人转化                                │
│                                                             │
│  4. 设备欺诈 (Device Fraud)                                 │
│     ├── 模拟器：Android模拟器                                 │
│     ├── 设备农场：批量设备                                    │
│     └── ID伪造：伪造设备ID                                   │
└─────────────────────────────────────────────────────────────┘
```

## 2. 风控策略

### 2.1 实时风控流程

```
实时风控流程：

┌─────────────────────────────────────────────────────────────┐
│  1. 数据接入                                                 │
│     ├── 设备指纹                                            │
│     ├── IP地址                                              │
│     ├── 行为数据                                            │
│     └── 上下文信息                                          │
│                                                             │
│  2. 规则引擎                                                 │
│     ├── IP黑名单                                           │
│     ├── 设备黑名单                                          │
│     ├── 频率限制                                           │
│     └── 地域限制                                           │
│                                                             │
│  3. 模型评分                                                 │
│     ├── 机器学习模型（XGBoost/LightGBM）                    │
│     ├── 深度学习模型（DNN/GRU）                              │
│     └──  ensemble 融合                                      │
│                                                             │
│  4. 决策输出                                                 │
│     ├── 通过：正常竞价                                       │
│     ├── 降权：降低出价                                       │
│     └── 拒绝：过滤广告                                       │
└─────────────────────────────────────────────────────────────┘
```
