# 广告平台架构深度解析

> 深入广告平台架构：DSP、SSP、AdExchange、AdServer。
> 基于《在线广告：互联网广告系统的架构及算法》（张亚东著）蒸馏。
> 适用对象：广告系统架构师、后端工程师

---

## 1. 广告平台核心组件

### 1.1 广告交易链路

```
广告交易链路：

┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  用户请求网页/App                                           │
│       ↓                                                     │
│  ┌─────────┐                                                │
│  │ Publisher│ ← 网站/App所有者，提供广告位                    │
│  └────┬────┘                                                │
│       ↓                                                     │
│  ┌─────────┐                                                │
│  │  SSP    │ ← Supply-Side Platform，代理Publisher竞价        │
│  └────┬────┘                                                │
│       ↓                                                     │
│  ┌─────────┐                                                │
│  │ADX     │ ← Ad Exchange，广告交易市场                       │
│  └────┬────┘                                                │
│       ↓                                                     │
│  ┌─────────┐                                                │
│  │  DSP    │ ← Demand-Side Platform，代理Advertiser竞价       │
│  └────┬────┘                                                │
│       ↓                                                     │
│  ┌─────────┐                                                │
│  │Advertiser│ ← 广告主，投放广告                               │
│  └─────────┘                                                │
│                                                             │
│  数据流：                                                    │
│  请求 → 竞价 → 出价 → 中标 → 展示 → 点击 → 转化              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

```
DSP 核心架构：

┌─────────────────────────────────────────────────────────────┐
│  ┌─────────────────────────────────────────────────────┐  │
│  │              API 接入层                              │  │

│  └─────────────────────────────────────────────────────┘  │
│                           ↓                                │
│  ┌─────────────────────────────────────────────────────┐  │
│  │              竞价决策引擎                           │  │
│  │  ┌─────────┐ ┌─────────┐ ┌─────────┐               │  │
│  │  │ 出价模型 │ │ 频控    │ │ 定向    │               │  │
│  │  └─────────┘ └─────────┘ └─────────┘               │  │
│  │  - pCTR预估 | - 频控策略 | - 人群定向                  │  │
│  │  - pCVR预估 | - 预算控制 | - 地域定向                  │  │
│  │  - 出价策略 |         | - 时间定向                    │  │
│  └─────────────────────────────────────────────────────┘  │
│                           ↓                                │
│  ┌─────────────────────────────────────────────────────┐  │
│  │              数据引擎                                │  │
│  │  - 实时数据 | - 离线数据 | - 特征工程                 │  │
│  └─────────────────────────────────────────────────────┘  │
│                           ↓                                │
│  ┌─────────────────────────────────────────────────────┐  │
│  │              监控系统                                │  │
│  │  - 预算监控 | - 效果监控 | - 异常告警                 │  │
│  └─────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

## 3. SSP 架构

### 3.1 核心功能

```
SSP 核心功能：

┌─────────────────────────────────────────────────────────────┐
│  1. 广告位管理                                               │
│     ├── 广告位注册/管理                                      │
│     ├── 广告位类型（banner/video/native）                     │
│     └── 广告位库存管理                                       │
│                                                             │
│  2. 请求转发                                                 │
│     ├── 接收Publisher请求                                    │
│     ├── 封装为OpenRTB格式                                    │
│     └── 转发给ADX/多个DSP                                    │
│                                                             │
│  3. 竞价聚合                                                 │
│     ├── 收集多个DSP出价                                      │
│     ├── 选择最高出价                                         │
│     └── 返回中标方                                           │
│                                                             │
│  4. 数据上报                                                 │
│     ├── 曝光数据                                             │
│     ├── 点击数据                                             │
│     └── 转化数据                                             │
└─────────────────────────────────────────────────────────────┘
```

## 4. AdX 架构

### 4.1 核心流程

```
AdX 竞价流程：

┌─────────────────────────────────────────────────────────────┐
│  1. 接收请求 (SSP)                                         │
│     ├── 解析请求参数                                        │
│     ├── 用户画像查询                                        │
│     └── 上下文信息获取                                      │
│                                                             │
│  2. 分发请求 (DSP)                                          │
│     ├── 筛选符合条件的DSP                                   │
│     ├── 并发分发请求                                        │
│     └── 设置超时（通常100ms）                                │
│                                                             │
│  3. 聚合出价                                               │
│     ├── 收集所有DSP出价                                     │
│     ├── 处理超时/异常                                       │
│     └── 选择中标方                                          │
│                                                             │
│  4. 返回结果                                               │
│     ├── 返回中标广告                                        │
│     ├── 返回追踪URL                                         │
│     └── 开始计费                                            │
└─────────────────────────────────────────────────────────────┘
```
