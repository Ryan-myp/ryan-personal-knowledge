# 广告欺诈检测深度解析

> 深入广告欺诈检测：点击欺诈、展示欺诈、归因欺诈、反作弊策略。
> 源码级分析，包含生产环境最佳实践。
> 适用对象：广告算法工程师、风控工程师

---

## 1. 欺诈类型

### 1.1 主要欺诈行为

```
广告欺诈类型：

┌─────────────────────────────────────────────────────────────┐
│  点击欺诈：                                                  │
│  ├── 点击农场：大量虚假点击                                  │
│  ├── 点击膨胀：夸大点击量                                    │
│  ├── 竞品点击：恶意点击竞争对手广告                           │
│  └── 机器点击：自动化工具点击                                 │
│                                                             │
│  展示欺诈：                                                  │
│  ├── 隐形展示：不可见位置曝光                                 │
│  ├── 屏外展示：屏幕外曝光                                    │
│  └── 机器人展示：非真实用户曝光                               │
│                                                             │
│  归因欺诈：                                                  │
│  ├── 归因劫持：窃取他人转化归因                               │
│  ├── 虚假转化：伪造转化数据                                  │
│  └── 归因篡改：修改归因模型                                   │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 检测策略

### 2.1 多层防御

```
广告反作弊策略：

┌─────────────────────────────────────────────────────────────┐
│  第一层：规则过滤                                            │
│  ├── IP黑名单                                               │
│  ├── Device ID黑名单                                        │
│  ├── 频率限制                                               │
│  └── 行为规则                                               │
│                                                             │
│  第二层：行为分析                                            │
│  ├── 点击序列分析                                           │
│  ├── 用户行为建模                                           │
│  ├── 异常检测（Isolation Forest）                            │
│  └── 时序分析                                               │
│                                                             │
│  第三层：机器学习                                            │
│  ├── 特征工程（设备指纹、行为特征）                          │
│  ├── 分类模型（XGBoost/LightGBM）                           │
│  └── 实时推理                                               │
│                                                             │
│  第四层：归因验证                                            │
│  ├── 归因模型校验                                           │
│  └── 转化真实性验证                                         │
└─────────────────────────────────────────────────────────────┘
```
