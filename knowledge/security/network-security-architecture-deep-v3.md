> 适用对象：安全工程师、架构师

## 1. 零信任架构

### 1.1 核心原则

```
零信任架构原则：

┌─────────────────────────────────────────────────────────────┐
│  "从不信任，始终验证"：                                      │
│                                                             │
│  核心原则：                                                  │
│  ├── 不信任任何网络位置（内网/外网）                          │
│  ├── 每次访问都需要验证身份                                   │
│  ├── 最小权限访问                                            │
│  ├── 持续监控和验证                                          │
│  └── 假设已被入侵，横向移动                                  │
│                                                             │
│  关键组件：                                                  │
│  ├── 身份认证（MFA）                                        │
│  ├── 设备认证                                                │
│  ├── 微隔离                                                  │
│  └── 持续评估                                                │
└─────────────────────────────────────────────────────────────┘
```

## 2. WAF防护

### 2.1 防护策略

```
WAF（Web应用防火墙）策略：

┌─────────────────────────────────────────────────────────────┐
│  OWASP Top 10防护：                                          │
│  ├── SQL注入：参数化查询、输入过滤                           │
│  ├── XSS：输入转义、CSP头部                                  │
│  ├── CSRF：Token验证、SameSite Cookie                        │
│  ├── 文件上传：类型校验、路径遍历防护                         │
│  └── 敏感信息泄露：日志脱敏、响应过滤                         │
│                                                             │
│  防护模式：                                                  │
│  ├── 阻断模式：直接拒绝攻击请求                               │
│  ├── 监控模式：记录但不阻断                                   │
│  └── 学习模式：自动学习正常请求                               │
│                                                             │
│  规则管理：                                                  │
│  ├── 白名单：允许的请求                                       │
│  ├── 黑名单：拒绝的请求                                       │
│  └── 速率限制：防刷防攻击                                     │
└─────────────────────────────────────────────────────────────┘
```
