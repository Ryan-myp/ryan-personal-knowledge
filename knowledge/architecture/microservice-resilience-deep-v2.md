# 微服务容错与弹性设计深度解析

> 深入微服务容错：熔断、降级、限流、重试、舱壁隔离。
> 源码级分析，包含生产环境最佳实践。
> 适用对象：架构师、后端工程师

---

## 1. 容错模式

### 1.1 熔断器模式

```
熔断器三态机：

┌─────────────────────────────────────────────────────────────┐
│                                                             │
│    ┌─────────┐    异常比例    ┌─────────┐                  │
│    │ 关闭    │──────────────→│  半开   │                  │
│    │ Closed │               │ Half-Open│                  │
│    └────┬────┘               └────┬────┘                  │
│         │                         │                       │
│         │    快速失败             │    部分成功            │
│         └─────────────────────────┘                       │
│                  ↓                                        │
│              ┌─────────┐                                  │
│              │  打开   │ ← 异常比例超过阈值                │
│              │ Open   │                                  │
│              └─────────┘                                  │
│                                                             │
│  参数配置：                                                  │
│  ├── 错误率阈值：50%（超过则熔断）                          │
│  ├── 熔断时长：30秒（打开状态持续时间）                      │
│  ├── 半开探测：1次（半开状态测试请求数）                      │
│  └── 最小请求数：10（低于此值不熔断）                        │
└─────────────────────────────────────────────────────────────┘
```

## 2. 舱壁隔离

### 2.1 线程池隔离

```
舱壁隔离模式：

┌─────────────────────────────────────────────────────────────┐
│  业务服务                                                    │
│  ├── 线程池A：用户服务（10线程）                             │
│  ├── 线程池B：订单服务（20线程）                             │
│  ├── 线程池C：支付服务（10线程）                             │
│  └── 线程池D：推荐服务（5线程）                              │
│                                                             │
│  故障隔离：                                                  │
│  ├── 推荐服务超时 → 仅影响线程池D                           │
│  ├── 用户服务正常 → 线程池A不受影响                          │
│  └── 防止级联故障                                           │
│                                                             │
│  实现方式：                                                  │
│  ├── 线程池隔离（Hystrix/Sentinel）                         │
│  ├── 进程隔离（轻量级容器）                                  │
│  └── 语言级隔离（Go协程池）                                  │
└─────────────────────────────────────────────────────────────┘
```
