## 2. CQRS模式

### 2.1 读写分离

```
CQRS架构：

┌─────────────────────────────────────────────────────────────┐
│  Command（写操作）                                           │
│  ├── 处理命令                                               │
│  ├── 验证业务规则                                           │
│  └── 更新写模型                                              │
│           ↓                                                 │
│  ┌──────────────────────────────────────────────────────┐  │
│  │              Event Sourcing                          │  │
│  │  - 事件日志（immutable）                             │  │
│  │  - 事件重放                                          │  │
│  │  - 状态重建                                          │  │
│  └──────────────────────────────────────────────────────┘  │
│           ↓                                                 │
│  Query（读操作）                                             │
│  ├── 查询投影                                               │
│  ├── 读取优化                                               │
│  └── 缓存友好                                               │
└─────────────────────────────────────────────────────────────┘
```

## 3. Saga模式

### 3.1 分布式事务

```
Saga模式：

┌─────────────────────────────────────────────────────────────┐
│  步骤：                                                      │
│  1. 执行本地事务T1                                           │
│  2. 调用服务S2，执行本地事务T2                               │
│  3. ...                                                     │
│  N. 执行本地事务TN                                           │
│                                                             │
│  补偿：                                                      │
│  ├── 如果Ti失败，执行T1-T(i-1)的补偿操作                     │
│  ├── 补偿操作是可逆的                                       │
│  └── 最终一致性                                             │
│                                                             │
│  编排 vs 编排：                                              │
│  ├── 编排式：中心化控制器协调                                │
│  └── 参与式：各服务自行处理补偿                              │
└─────────────────────────────────────────────────────────────┘
```
