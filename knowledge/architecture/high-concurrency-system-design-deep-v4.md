> 源码级分析，包含生产环境最佳实践。

---

## 1. 限流策略

### 1.1 限流算法

```
限流算法对比：

┌─────────────────────────────────────────────────────────────┐
│  计数器算法：                                                │
│  ├── 固定窗口：时间窗口内计数                                 │
│  ├── 滑动窗口：改进固定窗口，减少边界问题                     │
│  └── 缺点：临界突发流量                                      │
│                                                             │
│  令牌桶算法：                                                │
│  ├── 固定速率产生令牌                                         │
│  ├── 请求消耗令牌                                             │
│  ├── 允许一定程度的突发                                       │
│  └── 适用：需要控制平均速率                                    │
│                                                             │
│  漏桶算法：                                                  │
│  ├── 固定速率流出                                             │
│  ├── 突发流量进入队列                                        │
│  ├── 队列满则拒绝                                            │
│  └── 适用：需要平滑流量                                       │
│                                                             │
│  实现：                                                     │
│  ├── Guava RateLimiter                                      │
│  ├── Sentinel                                               │
│  └── Redis + Lua脚本                                        │
└─────────────────────────────────────────────────────────────┘
```

## 2. 缓存架构

### 2.1 缓存策略

```
多级缓存架构：

┌─────────────────────────────────────────────────────────────┐
│  L1缓存（本地缓存）：                                        │
│  ├── Caffeine/Guava Cache                                   │
│  ├── 毫秒级响应                                              │
│  ├── 单机容量有限                                            │
│  └── 适用：热点数据                                         │
│                                                             │
│  L2缓存（分布式缓存）：                                      │
│  ├── Redis/Memcached                                        │
│  ├── 网络访问（微秒级）                                      │
│  ├── 容量大，可横向扩展                                      │
│  └── 适用：共享数据                                         │
│                                                             │
│  L3缓存（数据库）：                                          │
│  ├── MySQL/PostgreSQL                                       │
│  └── 持久化存储，最后防线                                    │
│                                                             │
│  缓存一致性：                                                │
│  ├── Cache-Aside：先删缓存，再更新DB                         │
│  ├── Read-Through：缓存自动加载                              │
│  ├── Write-Through：缓存自动更新                             │
│  └── Write-Behind：缓存异步写DB                              │
└─────────────────────────────────────────────────────────────┘
```
