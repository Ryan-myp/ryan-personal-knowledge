## 1. 服务治理核心组件

### 1.1 服务注册与发现

```
服务注册发现架构：

┌─────────────────────────────────────────────────────────────┐
│  服务注册中心（Consul/Nacos/Eureka）                         │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 服务目录                                               │  │
│  │ ├── 服务A: 192.168.1.1:8080 (健康)                    │  │
│  │ ├── 服务A: 192.168.1.2:8080 (健康)                    │  │
│  │ ├── 服务B: 192.168.1.3:8081 (健康)                    │  │
│  │ └── 服务C: 192.168.1.4:8082 (健康)                    │  │
│  └──────────────────────────────────────────────────────┘  │
│                           ↓                                │
│  客户端缓存 → 定期拉取服务列表 → 本地负载均衡                 │
└─────────────────────────────────────────────────────────────┘

注册模式：
  ├── 客户端注册：服务自己注册到注册中心
  ├── 服务端注册：注册中心主动发现服务
  └── 混合模式：Nacos支持两种方式

健康检查：
  ├── 主动检查：注册中心定期调用健康接口
  ├── 被动检查：服务心跳上报
  └── 检查策略：TCP/HTTP/gRPC
```

## 2. 熔断降级

### 2.1 熔断器模式

```
熔断器三态机：

┌─────────────────────────────────────────────────────────────┐
│                                                             │
│    ┌─────────┐    异常比例    ┌─────────┐                  │
│    │ 关闭    │──────────────→│  半开   │                  │
│    │ Closed │               │ Half-Open│                  │
│    └────┬────┘               └────┬────┘                  │
│         │                         │                       │
│         │    快速失败             │    部分成功            │
│         └─────────────────────────┘                       │
│                  ↓                                        │
│              ┌─────────┐                                  │
│              │  打开   │ ← 异常比例超过阈值                │
│              │ Open   │                                  │
│              └─────────┘                                  │
│                                                             │
│  参数配置：                                                  │
│  ├── 错误率阈值：50%（超过则熔断）                          │
│  ├── 熔断时长：30秒（打开状态持续时间）                      │
│  ├── 半开探测：1次（半开状态测试请求数）                      │
│  └── 最小请求数：10（低于此值不熔断）                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 降级策略

```
降级策略：

┌─────────────────────────────────────────────────────────────┐
│  1. 返回默认值                                               │
│     ├── 缓存兜底                                             │
│     └── 默认值返回                                           │
│                                                             │
│  2. 快速失败                                               │
│     ├── 抛出异常                                             │
│     └── 返回错误码                                           │
│                                                             │
│  3. 队列等待                                               │
│     ├── 异步处理                                             │
│     └── 消息队列积压                                         │
│                                                             │
│  4. 服务降级                                               │
│     ├── 非核心服务降级                                       │
│     └── 降级后返回简化结果                                    │
└─────────────────────────────────────────────────────────────┘
```

## 3. 配置中心

### 3.1 配置管理

```
配置中心架构（Nacos/Apollo）：

┌─────────────────────────────────────────────────────────────┐
│  配置中心服务端                                               │
│  ├── 配置存储（MySQL）                                       │
│  ├── 配置推送（长轮询/WebSocket）                            │
│  └── 配置版本管理                                            │
│                           ↓                                │
│  客户端SDK                                                   │
│  ├── 本地缓存                                               │
│  ├── 长轮询监听变更                                          │
│  └── 热加载配置                                              │
│                           ↓                                │
│  应用服务                                                    │
│  ├── 启动时拉取配置                                          │
│  ├── 运行时监听变更                                          │
│  └── 动态刷新配置                                             │
└─────────────────────────────────────────────────────────────┘

配置发布流程：
  1. 开发者在控制台修改配置
  2. 配置中心发布新版本
  3. 客户端长轮询检测到变更
  4. 拉取最新配置
  5. 本地缓存更新
  6. 应用热加载生效
```
