## 1. 排序算法

### 1.1 经典排序对比

```
排序算法性能对比：

┌─────────────────────────────────────────────────────────────┐
│  算法        │ 最好    │ 平均    │ 最坏    │ 空间    │ 稳定   │
│ ────────────┼─────────┼─────────┼─────────┼─────────┼───────│
│ 冒泡排序      │ O(n)    │ O(n²)   │ O(n²)   │ O(1)    │ ✅     │
│ 选择排序      │ O(n²)   │ O(n²)   │ O(n²)   │ O(1)    │ ❌     │
│ 插入排序      │ O(n)    │ O(n²)   │ O(n²)   │ O(1)    │ ✅     │
│ 快速排序      │ O(nlogn)│ O(nlogn)│ O(n²)   │ O(logn) │ ❌     │
│ 归并排序      │ O(nlogn)│ O(nlogn)│ O(nlogn)│ O(n)    │ ✅     │
│ 堆排序        │ O(nlogn)│ O(nlogn)│ O(nlogn)│ O(1)    │ ❌     │
│ 计数排序      │ O(n+k)  │ O(n+k)  │ O(n+k)  │ O(k)    │ ✅     │
│ 桶排序        │ O(n+k)  │ O(n+k)  │ O(n²)   │ O(n+k)  │ ✅     │
│ 基数排序      │ O(d(n+k))│O(d(n+k))│O(d(n+k))│O(n+k)   │ ✅     │
└─────────────────────────────────────────────────────────────┘

选择策略：
  ├── 小数据量：插入排序（简单高效）
  ├── 通用场景：快速排序（平均性能好）
  ├── 需要稳定：归并排序（稳定，O(nlogn)）
  ├── 内存受限：堆排序（原地排序）
  └── 特定范围：计数/基数排序（线性时间）
```

## 3. 动态规划

### 3.1 解题思路

```
动态规划解题框架：

┌─────────────────────────────────────────────────────────────┐
│  1. 定义状态：dp[i]表示什么？                                │
│  2. 状态转移方程：如何从子问题推导？                         │
│  3. 初始条件：边界情况如何处理？                              │
│  4. 计算顺序：自顶向下（记忆化）vs 自底向上                  │
│  5. 空间优化：能否降维？                                     │
│                                                             │
│  经典问题：                                                  │
│  ├── 斐波那契数列：dp[i] = dp[i-1] + dp[i-2]               │
│  ├── 背包问题：0/1背包、完全背包                             │
│  ├── 最长公共子序列：dp[i][j]                               │
│  ├── 编辑距离：dp[i][j]                                     │
│  └── 最长递增子序列：O(nlogn)解法                           │
└─────────────────────────────────────────────────────────────┘
```
