## 1. Goroutine调度

### 1.1 GMP模型

```
Go调度器GMP模型：

┌─────────────────────────────────────────────────────────────┐
│  G（Goroutine）：                                           │
│  ├── 调度所需的元数据                                        │
│  ├── stack指针（初始2KB，动态扩容）                          │
│  ├── pc（程序计数器）                                       │
│  └── 状态：running/runnable/generator/gcscan                 │
│                                                             │
│  M（Machine/OS Thread）：                                   │
│  ├── 执行Goroutine的OS线程                                   │
│  ├── P的引用                                                 │
│  └── 工作队列                                               │
│                                                             │
│  P（Processor）：                                           │
│  ├── 本地运行队列（最多256个G）                               │
│  ├── GOMAXPROCS个P（默认CPU核数）                           │
│  └── 全局队列窃取                                           │
│                                                             │
│  调度流程：                                                  │
│  1. G从本地队列执行                                          │
│  2. 本地队列空 → 从全局队列获取                               │
│  3. 全局队列空 → 从其他P窃取一半                             │
│  4. 阻塞/IO → 切换G，M被占或空闲                              │
└─────────────────────────────────────────────────────────────┘
```

## 2. Channel实现

### 2.1 数据结构

```
Channel实现原理：

┌─────────────────────────────────────────────────────────────┐
│  hchan结构体：                                               │
│  ├── buf：环形缓冲区（无缓冲channel为nil）                   │
│  ├── elemsize：元素大小                                      │
│  ├── closed：是否关闭                                       │
│  ├── elemtype：元素类型                                      │
│  ├── sendx：发送索引                                        │
│  ├── recvx：接收索引                                        │
│  ├── recvq：等待接收的G队列（sudog链表）                     │
│  └── sendq：等待发送的G队列（sudog链表）                     │
│                                                             │
│  无缓冲Channel：                                             │
│  ├── 发送：直接传递给接收者，无缓冲区                        │
│  └── 必须一对一配对                                         │
│                                                             │
│  有缓冲Channel：                                             │
│  ├── 发送：放入缓冲区，缓冲区满则阻塞                        │
│  ├── 接收：从缓冲区取出，缓冲区空则阻塞                      │
│  └── 解耦发送和接收速度                                      │
└─────────────────────────────────────────────────────────────┘
```
