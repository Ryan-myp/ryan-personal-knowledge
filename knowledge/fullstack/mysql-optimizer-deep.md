## 一、优化器流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                     MySQL 查询优化流程                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  SQL 输入                                                                    │
│      │                                                                      │
│      ▼                                                                      │
│  ┌─────────────┐                                                          │
│  │  Parser     │ ← 词法分析 + 语法分析                                      │
│  └──────┬──────┘                                                          │
│         ▼                                                                  │
│  ┌─────────────┐                                                          │
│  │ Preprocessor│ ← 语法检查 + 权限验证                                      │
│  └──────┬──────┘                                                          │
│         ▼                                                                  │
│  ┌─────────────┐                                                          │
│  │ Optimizer   │ ← 重写查询 + 选择执行计划                                   │
│  │  ├─ 查询重写 │                                                             │
│  │  ├─ 索引选择 │                                                             │
│  │  └─ 连接顺序 │                                                             │
│  └──────┬──────┘                                                          │
│         ▼                                                                  │
│  ┌─────────────┐                                                          │
│  │ Executor    │ ← 执行查询 + 返回结果                                      │

│                                                                             │
```
