## 一、拦截器模式

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                     gRPC 拦截器链                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Client                                                                   │
│  ┌─────────────┐                                                          │
│  │ UnaryClient │                                                          │
│  │  Interceptor│                                                          │
│  └──────┬──────┘                                                          │
│         ▼                                                                  │
│  ┌─────────────┐                                                          │
│  │   Metadata  │  ← 请求头处理                                             │
│  │  Interceptor│                                                          │
│  └──────┬──────┘                                                          │
│         ▼                                                                  │
│  ┌─────────────┐                                                          │
│  │   Logging   │  ← 请求日志记录                                            │
│  │  Interceptor│                                                          │
│  └──────┬──────┘                                                          │
│         ▼                                                                  │
│  ┌─────────────┐                                                          │
│  │   Retry     │  ← 失败重试                                                │
│  │  Interceptor│                                                          │
│  └──────┬──────┘                                                          │
│         ▼                                                                  │
│  ┌─────────────┐                                                          │
│  │   Timeout   │  ← 超时控制                                                │
│  │  Interceptor│                                                          │
│  └──────┬──────┘                                                          │
│         ▼                                                                  │
│  ┌─────────────┐                                                          │
│  │  gRPC Core  │  ← 实际 RPC 调用                                           │
│  └─────────────┘                                                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
