## 1. 事务隔离级别

### 1.1 四级隔离

```
MySQL事务隔离级别：

┌─────────────────────────────────────────────────────────────┐
│  级别        │ 脏读  │ 不可重复读 │ 幻读  │ 性能影响          │
│ ────────────┼───────┼───────────┼───────┼─────────────────│
│ 读未提交      │ ✅   │ ✅         │ ✅   │ 最低              │
│ 读已提交      │ ❌   │ ✅         │ ✅   │ 低                │
│ 可重复读（默认）│ ❌  │ ❌         │ ✅   │ 中                │
│ 串行化        │ ❌   │ ❌         │ ❌   │ 高                │
└─────────────────────────────────────────────────────────────┘

InnoDB默认隔离级别：可重复读（REPEATABLE READ）
```

## 2. MVCC实现

### 2.1 版本链

```
MVCC（多版本并发控制）：

┌─────────────────────────────────────────────────────────────┐
│  隐藏列：                                                    │
│  ├── db_trx_id：事务ID                                      │
│  ├── db_roll_ptr：回滚指针                                   │
│  └── row_id：隐藏主键                                        │
│                                                             │
│  Undo Log版本链：                                            │
│  ┌─────────────────────────────────────────────────────┐  │
│  │  当前版本 → 版本2 → 版本1 → 版本0                    │  │
│  └─────────────────────────────────────────────────────┘  │
│                                                             │
│  Read View（读视图）：                                       │
│  ├── 创建时刻活跃事务列表                                    │
│  ├── 判断当前版本是否可见                                     │
│  └── 实现可重复读的核心                                      │
│                                                             │
│  可见性判断：                                                │
│  ├── trx_id < 读视图最小事务ID → 可见                      │
│  ├── trx_id > 读视图最大事务ID → 不可见                     │
│  └── 在活跃事务列表中 → 不可见                               │
└─────────────────────────────────────────────────────────────┘
```
