## 1. EXPLAIN分析

### 1.1 关键字段

```
EXPLAIN输出关键字段：

┌─────────────────────────────────────────────────────────────┐
│  id：查询标识符                                              │
│  ├── 相同id：并行执行                                         │
│  └── 不同id：嵌套查询，id越大优先级越高                       │
│                                                             │
│  select_type：查询类型                                        │
│  ├── SIMPLE：简单查询                                         │
│  ├── PRIMARY：外层查询                                        │
│  ├── SUBQUERY：子查询                                         │
│  └── DERIVED：派生表                                        │
│                                                             │
│  table：表名                                                 │
│                                                             │
│  type：访问类型（从优到差）                                    │
│  ├── system：表只有一行                                      │
│  ├── const：常量查询                                         │
│  ├── eq_ref：唯一索引                                         │
│  ├── ref：非唯一索引                                         │
│  ├── range：索引范围扫描                                      │
│  ├── index：全索引扫描                                       │
│  └── ALL：全表扫描（最差）                                   │
│                                                             │
│  possible_keys：可能的索引                                    │
│  key：实际使用的索引                                          │
│  keys_len：索引长度                                          │
│  ref：索引关联的列                                            │
│  rows：扫描行数                                               │
│  Extra：额外信息                                             │
│  ├── Using filesort：文件排序                                │
│  ├── Using temporary：临时表                                 │
│  ├── Using index：覆盖索引                                   │
│  └── Using where：使用WHERE过滤                              │
└─────────────────────────────────────────────────────────────┘
```

## 2. 优化策略

### 2.1 常见优化

```
执行计划优化策略：

┌─────────────────────────────────────────────────────────────┐
│  1. 索引优化                                                 │
│     ├── 最左前缀原则                                         │
│     ├── 覆盖索引避免回表                                      │
│     └── 区分度高的列优先建索引                                 │
│                                                             │
│  2. 查询优化                                                 │
│     ├── 避免SELECT *                                        │
│     ├── 合理使用LIMIT                                        │
│     └── 分页优化（游标法）                                   │
│                                                             │
│  3. JOIN优化                                                 │
│     ├── 小表驱动大表                                         │
│     ├── 关联字段建索引                                        │
│     └── 避免过多JOIN                                         │
│                                                             │
│  4. 排序优化                                                 │
│     ├── 避免Using filesort                                  │
│     ├── 利用索引排序                                         │
│     └── 减少ORDER BY                                        │
└─────────────────────────────────────────────────────────────┘
```
