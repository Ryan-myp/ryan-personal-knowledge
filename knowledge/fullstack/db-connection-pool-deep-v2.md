# 数据库连接池深度解析

> 深入数据库连接池：HikariCP、Druid、连接泄漏、性能调优。
> 源码级分析，包含生产环境最佳实践。
> 适用对象：后端工程师、DBA

---

## 1. 连接池架构

### 1.1 核心组件

```
数据库连接池架构：

┌─────────────────────────────────────────────────────────────┐
│  连接池核心组件：                                             │
│  ├── 连接工厂（ConnectionFactory）                           │
│  ├── 连接池（ConnectionPool）                                │
│  ├── 空闲连接（Idle Connection）                             │
│  ├── 活跃连接（Active Connection）                           │
│  └── 等待队列（Wait Queue）                                  │
│                                                             │
│  连接生命周期：                                              │
│  获取连接 → 使用 → 归还 → 空闲 → 验证 → 销毁                 │
│                                                             │
│  关键参数：                                                  │
│  ├── maxPoolSize：最大连接数                                  │
│  ├── minIdle：最小空闲连接                                    │
│  ├── maxLifetime：连接最大生命周期                            │
│  ├── idleTimeout：空闲超时                                    │
│  └── connectionTimeout：获取连接超时                          │
└─────────────────────────────────────────────────────────────┘
```

## 2. 主流连接池对比

### 2.1 选型建议

```
主流连接池对比：

┌─────────────────────────────────────────────────────────────┐
│  HikariCP：                                                  │
│  ├── Spring Boot默认                                        │
│  ├── 性能最优（无锁设计）                                    │
│  ├── 轻量级（~100KB）                                       │
│  └── 推荐生产使用                                            │
│                                                             │
│  Druid：                                                     │
│  ├── 阿里巴巴开源                                            │
│  ├── 监控功能强大                                            │
│  ├── SQL防火墙                                               │
│  └── 适合需要监控的场景                                      │
│                                                             │
│  C3P0：                                                      │
│  ├── 老牌连接池                                              │
│  ├── 性能一般                                                │
│  └── 不推荐新项目使用                                        │
│                                                             │
│  选择建议：                                                  │
│  ├── 通用场景：HikariCP                                      │
│  └── 需要监控：Druid                                         │
└─────────────────────────────────────────────────────────────┘
```
