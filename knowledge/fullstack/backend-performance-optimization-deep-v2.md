## 1. 缓存优化

### 1.1 缓存策略

```
缓存架构设计：

┌─────────────────────────────────────────────────────────────┐
│  L1缓存（本地缓存）：                                        │
│  ├── Caffeine/Guava Cache                                   │
│  ├── 响应最快，单进程内访问                                   │
│  ├── 容量有限，存在内存压力                                   │
│  └── 适用：热点数据、配置信息                                 │
│                                                             │
│  L2缓存（分布式缓存）：                                      │
│  ├── Redis/Memcached                                        │
│  ├── 网络访问，速度次之                                       │
│  ├── 容量大，可横向扩展                                       │
│  └── 适用：用户会话、实时数据                                 │
│                                                             │
│  L3缓存（数据库）：                                          │
│  ├── MySQL/PostgreSQL                                       │
│  └── 持久化存储，最后防线                                     │
│                                                             │
│  缓存穿透：查询不存在的数据                                    │
│  ├── 解决方案：布隆过滤器 / 缓存空值                          │
│                                                             │
│  缓存击穿：热点key过期                                        │
│  ├── 解决方案：互斥锁 / 永不过期                              │
│                                                             │
│  缓存雪崩：大量key同时过期                                     │
│  └── 解决方案：随机过期时间 / 集群部署                        │
└─────────────────────────────────────────────────────────────┘
```

## 2. 数据库优化

### 2.1 索引优化

```
索引优化策略：

┌─────────────────────────────────────────────────────────────┐
│  1. 最左前缀原则                                             │
│     └── 联合索引(a,b,c)，查询必须从a开始                      │
│                                                             │
│  2. 索引选择性                                               │
│     └── 区分度高的列优先建索引                               │
│                                                             │
│  3. 覆盖索引                                                 │
│     └── 查询字段都在索引中，避免回表                         │
│                                                             │
│  4. 索引失效场景                                             │
│     ├── 对索引列做计算                                       │
│     ├── 隐式类型转换                                         │
│     └── 前导通配符 LIKE '%abc'                              │
│                                                             │
│  5. 慢查询优化                                               │
│     ├── 开启慢查询日志                                       │
│     ├── EXPLAIN分析执行计划                                   │
│     └── 优化SQL或添加索引                                    │
└─────────────────────────────────────────────────────────────┘
```
