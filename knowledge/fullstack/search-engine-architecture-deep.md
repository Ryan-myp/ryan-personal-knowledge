## 3. 查询解析

### 3.1 查询类型

```
查询分类:

┌─────────────────────────────────────────────────────────────┐
│                    查询类型                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  词项查询 (Term Query)                                      │
│  ├── 精确匹配                                               │
│  ├── 范围查询                                               │
│  └── 前缀查询                                               │
│                                                             │
│  全文查询 (Full-text Query)                                 │
│  ├── match: 相关度排序                                       │
│  ├── multi_match: 多字段搜索                                 │
│  ├── query_string: 查询语法                                  │
│  └── simple_query_string: 简化语法                           │
│                                                             │
│  复合查询 (Compound Query)                                   │
│  ├── bool: 组合查询                                         │
│  │   ├── must: 必须匹配                                     │
│  │   ├── should: 可选匹配                                   │
│  │   ├── must_not: 必须不匹配                               │
│  │   └── filter: 过滤（不计分）                             │
│  ├── dis_max: 最差匹配                                      │
│  └── function_score: 自定义评分                             │
│                                                             │
│  聚合查询 (Aggregation)                                     │
│  ├── terms: 分组统计                                        │
│  ├── date_histogram: 时间统计                               │
│  ├── avg/min/max: 数值统计                                  │
│  └── nested: 嵌套聚合                                       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 查询执行流程

```
1. 查询解析 (Query Parser)
   └─► 解析查询字符串 → AST (抽象语法树)

2. 查询优化 (Query Optimizer)
   └─► 重写查询 → 优化执行计划

3. 查询执行 (Query Executor)
   ├─► 词项查询: 直接查倒排索引
   ├─► 全文查询: TF-IDF/BM25 计算
   └─► 复合查询: 组合子查询结果

4. 结果排序 (Result Ranking)
   └─► 相关度评分 → 排序 → 返回
```

## 4. 相关性排序

### 4.1 BM25 算法

```
BM25 公式:

Score(D,Q) = Σ IDF(qi) * (f(qi,D) * (k1+1)) / (f(qi,D) + k1*(1 - b + b*|D|/avgdl))

其中:
- qi: 查询词
- D: 文档
- f(qi,D): 词频
- IDF(qi): 逆文档频率
- k1, b: 调优参数
- |D|: 文档长度
- avgdl: 平均文档长度
```

### 4.2 排序参数调优

```json
{
  "query": {
    "match": {
      "content": {
        "query": "搜索引擎架构",
        "boost": 1.2
      }
    }
  },
  "sort": [
    { "_score": "desc" },
    { "created_at": "desc" }
  ]
}
```

## 5. 分布式检索

### 5.1 分片机制

```
┌─────────────────────────────────────────────────────────────┐
│                    分片架构                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Index: orders                                              │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐         │
│  │ Shard 0 │ │ Shard 1 │ │ Shard 2 │ │ Shard 3 │         │
│  │ Primary │ │ Primary │ │ Primary │ │ Primary │         │
│  └────┬────┘ └────┬────┘ └────┬────┘ └────┬────┘         │
│       │           │           │           │                │
│  ┌────▼────┐ ┌────▼────┐ ┌────▼────┐ ┌────▼────┐         │
│  │Replica  │ │Replica  │ │Replica  │ │Replica  │         │
│  │  (备份) │ │  (备份) │ │  (备份) │ │  (备份) │         │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘         │
│                                                             │
│  查询时: 广播到所有 shard → 合并结果 → 排序返回              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 查询路由

```
客户端请求 → Coordinator Node
                  │
                  ▼
          ┌───────┴───────┐
          │  广播查询      │
          ├───────┬───────┤
          ▼       ▼       ▼
       Shard0  Shard1  Shard2
          │       │       │
          └───────┴───────┘
                  │
                  ▼
          合并结果 → 排序 → 返回客户端
```
