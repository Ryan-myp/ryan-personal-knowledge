## 1. 依赖注入

### 1.1 实现模式

```
Go依赖注入模式：

┌─────────────────────────────────────────────────────────────┐
│  接口定义：                                                  │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  type Storage interface {                            │   │
│  │    Get(key string) (string, error)                  │   │
│  │    Set(key, value string) error                     │   │
│  │  }                                                    │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  注入方式：                                                  │
│  ├── 构造函数注入：                                        │
│  │   func NewService(s Storage) *Service {                 │
│  │       return &Service{storage: s}                       │
│  │   }                                                     │
│  │                                                         │
│  ├── 方法注入：                                             │
│  │   func (s *Service) SetStorage(st Storage) {            │
│  │       s.storage = st                                    │
│  │   }                                                     │
│  └── 接口注入（Setter）：                                   │
│      func (s *Service) Init(i Injection) {                 │
│          s.storage = i.GetStorage()                        │
│      }                                                     │
│                                                             │
│  优势：                                                      │
│  ├── 解耦                                                  │
│  ├── 可测试性                                               │
│  └── 灵活替换                                               │
└─────────────────────────────────────────────────────────────┘
```

## 2. 中间件模式

### 2.1 链式处理

```
Go中间件模式：

┌─────────────────────────────────────────────────────────────┐
│  中间件接口：                                                │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  type Middleware func(http.Handler) http.Handler     │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  中间件链：                                                  │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  Handler                                                │
│  │      ↑                                                  │
│  │  Middleware 3（日志）                                    │
│  │      ↑                                                  │
│  │  Middleware 2（认证）                                    │
│  │      ↑                                                  │
│  │  Middleware 1（限流）                                    │
│  │      ↑                                                  │
│  │  Handler                                                │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  实现：                                                      │
│  func Logger(next http.Handler) http.Handler {              │
│      return http.HandlerFunc(func(w http.ResponseWriter,   │
│                                  r *http.Request) {         │
│          start := time.Now()                                │
│          next.ServeHTTP(w, r)                               │
│          log.Printf("%s %s %v", r.Method, r.URL,           │
│                       time.Since(start))                    │
│      })                                                     │
│  }                                                           │
└─────────────────────────────────────────────────────────────┘
```
