## 一、Mutex 实现原理

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                     Go Mutex 内部结构                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  type Mutex struct {                                                        │
│      state  int32                    // 合并的状态字段                       │
│      sema   uint32                  // 信号量                               │
│  }                                                                        │
│                                                                             │
│  state 字段布局:                                                            │
│  ┌──────────┬──────────┬──────────┬──────────┐                           │
│  │  MutexDrained │ MutexStarving │  MutexWakeup │   MutexLocked    │       │
│  │   2 bits   │   1 bit   │   1 bit  │   29 bits   │                      │
│  └──────────┴──────────┴──────────┴──────────┘                           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
