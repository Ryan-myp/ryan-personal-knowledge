## 1. GC算法

### 1.1 三色标记法

```
Go GC三色标记：

┌─────────────────────────────────────────────────────────────┐
│  颜色定义：                                                  │
│  ├── 白色：未访问                                           │
│  ├── 灰色：已访问，子节点未全部扫描                           │
│  └── 黑色：已访问，子节点已扫描                               │
│                                                             │
│  标记阶段：                                                  │
│  ├── 从根对象出发（栈、全局变量）                            │
│  ├── 灰色对象扫描引用，将引用对象涂灰                        │
│  └── 灰色对象扫描完毕，涂黑                                   │
│                                                             │
│  问题：漏标（Black-White Rule Violation）                    │
│  └── 场景：黑色对象引用白色对象，但此引用被删除                │
│                                                             │
│  解决方案：写屏障（Write Barrier）                           │
│  └── 在对象引用修改时记录操作                                 │
└─────────────────────────────────────────────────────────────┘
```

## 2. 混合写屏障

### 2.1 实现原理

```
混合写屏障（Mixed Write Barrier）：

┌─────────────────────────────────────────────────────────────┐
│  写屏障类型：                                                │
│  ├── 黑-白屏障：黑色对象引用白色对象时记录                    │
│  ├── 白-黑屏障：白色对象引用黑色对象时记录                    │
│  └── 混合屏障：两者结合                                      │
│                                                             │
│  流程：                                                      │
│  1. 对象分配（白色）                                          │
│  2. 对象引用修改                                             │
│  3. 写屏障记录                                               │
│  4. 标记阶段                                                 │
│  5. 重标记（STW）                                            │
│  6. 扫描阶段                                                 │
│                                                             │
│  优势：                                                      │
│  ├── 减少STW时间                                             │
│  ├── 并发标记更高效                                          │
│  └── 内存开销可控                                            │
└─────────────────────────────────────────────────────────────┘
```
