## 1. reflect包核心

### 1.1 Type与Value

```
Go反射核心：

┌─────────────────────────────────────────────────────────────┐
│  reflect.Type：                                              │
│  ├── 获取类型信息                                             │
│  ├── Kind()：基础类型（int、string、struct等）                │
│  ├── Name()：类型名称                                        │
│  ├── NumField()：结构体字段数                                 │
│  └── Method()：方法信息                                      │
│                                                             │
│  reflect.Value：                                             │
│  ├── 获取值信息                                               │
│  ├── Interface()：转为interface{}                             │
│  ├── CanAddr()：是否可取地址                                  │
│  ├── CanSet()：是否可修改                                     │
│  └── Set()：设置值                                           │
│                                                             │
│  反射三定律：                                                  │
│  1. 反射可以将interface{}转换为reflect.Type                   │
│  2. 反射可以将reflect.Type转换为interface{}                   │
│  3. 要修改反射对象，值必须是settable                          │
└─────────────────────────────────────────────────────────────┘
```

## 2. 接口底层

### 2.1 接口结构

```
Go接口底层实现：

┌─────────────────────────────────────────────────────────────┐
│  接口值（interface{}）：                                      │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  类型指针（type）                                    │   │
│  │  ├── 类型信息                                        │   │
│  │  └── 类型描述                                        │   │
│  │                                                      │   │
│  │  数据指针（data）                                    │   │
│  │  └── 实际数据                                        │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  接口类型断言：                                              │
│  ├── 类型检查（运行时）                                      │
│  ├── 值提取                                                 │
│  └── 失败返回零值                                           │
│                                                             │
│  反射性能：                                                  │
│  ├── 反射比直接操作慢10-100倍                                │
│  ├── 谨慎使用，避免在热路径中使用                              │
│  └── 优先使用类型 switch                                      │
└─────────────────────────────────────────────────────────────┘
```
