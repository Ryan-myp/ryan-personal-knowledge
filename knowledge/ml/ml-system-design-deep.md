# ML 系统架构设计

> 深入机器学习系统：特征工程、模型训练、在线推理、模型监控。

---

## 1. 系统架构

```
数据层 ──▶ 特征存储 (Feature Store)
                │
训练层 ──▶ 特征工程 ──▶ 模型训练 ──▶ 模型注册
                │
服务层 ──▶ 模型服务 ──▶ A/B 测试 ──▶ 模型监控
```

---

## 2. 关键组件

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 特征存储 | Feast/Tecton | 离线+在线特征 |
| 模型训练 | PyTorch/TensorFlow | 分布式训练 |
| 模型服务 | TorchServe/Serving | 低延迟推理 |
| 模型监控 | Evidently/Prometheus | 漂移检测 |
