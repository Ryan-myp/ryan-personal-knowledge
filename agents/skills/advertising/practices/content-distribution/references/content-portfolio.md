# 内容组合与自然分发

## 主题组合记录

| 字段 | 记录要求 |
|---|---|
| 受众与阶段 | 谁在什么任务/决策阶段需要内容 |
| 需求证据 | 用户原声、搜索/站点报表、广告查询或内部假设；注明日期和范围 |
| 核心问题 | 用用户语言写具体问题，不把产品功能名当需求 |
| 独特贡献 | 可公开的经验、数据、方法或观点；没有就先补证据 |
| 内容形式 | 完整指南、比较材料、案例、短视频、图文等，说明形式为何适配任务 |
| 分发位置 | 搜索页面、自然社媒、邮件、合作方等；区分自有、付费和借用渠道 |
| 下一步行动 | 与当前内容目标相匹配的低摩擦行为，不强行插入销售 CTA |
| 维护责任 | 更新触发条件、事实核验负责人、素材授权和失效处理 |
| 衡量 | 触达、有效访问、目标动作、质量、辅助影响与维护成本 |

## 组合决策

优先排序可以综合需求证据、受众价值、独特性、达到信号所需时间、制作/维护成本和跨渠道复用性，但要保留决策理由。避免把搜索量、社交热度或单次曝光当作唯一优先级。内容主题组合应覆盖用户真实问题，不要求固定比例或追逐每个平台的趋势。

## 复用检查

复用前核对：

1. 是否保留了原内容中可验证的主张和适用条件？
2. 新渠道的读者是否需要不同的背景、时长、字幕、画幅或 CTA？
3. 是否具有原作者、音乐、图片、客户案例和品牌的渠道授权？
4. 是否避免把一次性观察改写成普遍承诺？
5. 是否记录源内容、改写版本、发布日期与测量窗口，以免把多份资产误认为独立实验？
