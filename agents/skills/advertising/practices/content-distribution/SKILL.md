# 内容策略与自然分发

本 Skill 将内容选题、制作和分发连接到具体受众任务与增长目标。SEO 技术与搜索表现进入 `seo-growth`，生成式搜索引用进入 `generative-search-visibility`，付费素材进入 `creative-strategy` / `ad-creative`；本 Skill 负责内容组合与自然分发计划，不重复这些专门流程。

## 规划流程

1. **明确受众与目标。** 定义目标用户、地区/语言、业务阶段和内容要支持的决策；区分品牌认知、问题教育、比较评估、转化、留存或用户教育。
2. **汇总可用需求证据。** 使用用户研究、销售/客服反馈、站点/搜索报表、广告搜索词和用户提供的资料。将实际观察、搜索假设、内部观点和未知标记清楚，不编造搜索量或客户声音。
3. **选择内容机会。** 按受众问题、独特证据/经验、意图阶段、竞争强度、生产成本、时效和可更新性筛选主题。区分适合被搜索发现的内容与适合被社交分享的内容；不要求每个主题同时服务两者。
4. **设计内容组合。** 用少量主题支柱连接核心页面、支持文章、案例/解释材料和短内容。记录每项内容的受众、核心问题、独特观点、证据、行动路径、负责人、更新触发条件和适配渠道。
5. **规划复用与分发。** 先定义一份有完整信息的源内容，再为网站、邮件、社媒、合作渠道分别改写开头、格式、长度和 CTA。复用不等于原样跨平台复制；标记需要的品牌/授权/事实核验。
6. **排定验证顺序。** 用小批量计划测试主题或格式。记录发布日期、分发动作、测量窗口、内容更新成本和下一轮决策；不固定套用通用日历比例或发布频率。
7. **评估业务结果。** 按可用数据观察曝光/触达、有效访问、参与、订阅/线索/购买、辅助转化和更新维护成本。最后点击、平台归因或单篇爆量不能单独证明内容带来增量。

按需加载 `references/content-portfolio.md`，建立主题、格式、渠道与衡量的组合表。

## 边界

- 没有已授权且实际返回的来源时，不声称完成搜索、社媒监听、站点审计或竞品内容采集；可以基于用户材料给出带假设的草案。
- 本 Skill 不自动发布或安排内容，不抓取登录/付费内容，不复制他人作品、品牌素材或未经许可的创作者内容。
- SEO/GEO 流量、平台可见度和内容归因受来源、延迟、算法和样本影响；不保证排名、AI 引用或转化提升。
- 对外事实、案例、客户结果和广告主张需有可核验来源与授权；对推测和示例明确标记。

## 输出

给出受众/业务目标、需求证据和缺口、优先主题组合、内容格式与自然分发路径、制作/复用要点、衡量指标及更新/停止规则。用事实、假设和待验证项区分结论。
