# 来源归属

这是一个针对本仓库的原创中文建议 Skill。它参考了 Corey Haines 的 `marketingskills` 集合中的 `paid-ads`、`ad-creative`、`copywriting` 和 `marketing-psychology` Skills，以及这些包的 Marketplace 描述，审阅日期为 2026-10-18。

该材料已针对本系统的 Google Ads、Meta 和 TikTok 范围进行了重写。它强调证据支持、授权来源、渠道架构验证、合乎道德的说服技巧以及单 Agent Tool 执行边界。不包含任何上游脚本、资产、连接器、账户数据或凭证。

上游仓库：[coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills)。上游许可证：MIT，如现有广告 Skill 归属文件中所述。
