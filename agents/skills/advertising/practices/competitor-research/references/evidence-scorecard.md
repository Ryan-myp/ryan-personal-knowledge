# 竞品证据记录表

每条会影响策略或对外主张的事实单独记一行，避免把来源质量不同的信息混在同一结论中。

| 字段 | 记录内容 |
|---|---|
| 对比项 | 产品能力、价格、目标客户、渠道、定位、主张或限制 |
| 竞品/实体 | 经核实的公司、产品或品牌，记录消歧依据 |
| 事实陈述 | 可被来源直接支持的短句，避免把结论写成证据 |
| 证据类型 | 官方资料 / 直接观察 / 可信第三方报道 / 推断 / 未知 |
| 来源 | URL、发布者、页面标题或资料名称 |
| 时间 | 页面标注日期（若有）及本次访问日期 |
| 范围 | 国家/地区、套餐、用户类型、平台、适用条件 |
| 反证/缺口 | 矛盾来源、未找到的信息或需要进一步验证之处 |
| 置信度 | 高 / 中 / 低，并说明依据 |
| 决策用途 | 此事实如何影响当前产品、内容或渠道决策 |

## 证据分级

- **官方明确说明**：产品文档、价格页、政策、正式发布公告。适合证明发布方公开承诺了什么；不必然证明所有账户/地区都已可用。
- **公开页面观察**：直接查看公开产品页、广告样本或公开帖子。只描述观察到的内容和时间；不能据此推断预算、效果或长期策略。
- **可信第三方报道**：记录记者/研究机构及其引用来源；独立报道与转述新闻稿应区分。
- **分析推断**：明确列出事实基础、推理步骤和替代解释；不得伪装成竞品自述。
- **未知**：没有足够证据或来源冲突。写明下一项可验证资料，而不是填补一个猜测。

价格和功能状态变化快，对外内容应设置复核日期和责任人。没有可访问证据时用“未能核实”，不要用“没有”或叉号代替。
