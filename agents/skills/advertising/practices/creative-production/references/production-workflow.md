# 创意制作工作流

## Brief 与事实依据

确认推广对象、受众、目标、渠道与版位、语言、品牌语气、产品事实和禁用表达。优先使用用户资料、附件、获准的只读 Tool 结果和广告知识库。区分已核实事实、用户假设与创意方向。没有产品参考资料时只表现抽象场景，不臆造包装、界面、商标或功能。

## 图片

1. 明确主体、受众、投放版位和核心视觉主张。
2. 写具体提示词，说明场景、构图、镜头、光线、风格、留白、比例和禁止元素。
3. 用户明确要求生成后调用 `creative_generate_image`；生成结果进入当前用户的私有素材库并在对话展示。
4. 检查主体清晰度、版位适配、文字可读性、商标和生成瑕疵。未经来源核实，不在图中要求出现产品包装细节、界面或性能承诺。

## 视频

1. 先明确一个 4–12 秒场景、主体动作、镜头运动、首尾状态、比例与风格。
2. 只使用已配置且标为免费（限时）的 Agnes Video Flash。免费状态无法确认时暂停调用，不替换成收费型号。
3. 调用 `creative_submit_video` 一次并记录 `asset_id`；稍后只用 `creative_check_video` 轮询。
4. 任务处理中要明确告知状态；完成后审核素材再交付，不把“已提交”说成“已完成”。

## 文案与审核

文案按不同用户动机形成有实质差异的角度，标出主标题、正文和 CTA，并按渠道 Tool/Skill 的规格检查字数。避免无依据的效果承诺、伪造证言、稀缺性或比较优势。交付时简要说明目标受众、主张、Hook、视觉表达、行动号召和仍需人工确认的事实。

## 上传边界

生成与上传是不同动作。只有用户明确要求时才调用对应渠道已注册的上传 Tool，并确认渠道、账户和素材；上传不等于素材已绑定到广告，也不代表 Campaign 已创建或投放已启用。只引用可信素材库中的 ready 素材，不接受或猜测服务器本地路径。

- Meta 和 TikTok 图片/MP4 上传必须经过现有权限、测试账户白名单、live 开关、确认、幂等和审计门禁。
- Google 图片素材可以使用平台素材 API；视频素材需引用已托管至 YouTube 的视频 ID，不能将本地 MP4 描述为已上传。
- 配置缺失、模型失败、格式不兼容或权限拒绝时，准确说明阻塞点；不绕过 Tool Registry，也不自动换账户或模型重试。
