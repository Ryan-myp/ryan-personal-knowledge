# 广告素材视觉方向与交付评审

素材权属和品牌事实先于风格：区分用户提供、获准只读来源核验、生成结果与仅供启发的参考。没有可验证的 logo、包装、产品界面、人物授权、字体或效果证据时，不凭空补造或把他人作品当作自有资产；需要展示真实品牌元素时先说明还缺什么。

## 何时探索方向

- 用户在做新概念或明确要求比较方案时，提出少量**策略不同**的方向：每个方向说明目标受众、核心信息、视觉主体、Hook/CTA、渠道版位、所需素材、来源与待验证主张。区别要来自传播假设，而不是换配色或照搬参考作品。
- 用户指定一张图片、一段视频、现有品牌规范或局部改动时，按要求直接制作或修改；**不强制三版**，不让用户为完成普通任务先经历额外审批。需要用户选择的仅是会显著改变结果且尚未明确的关键分歧。
- 可以描述创意方向，但“已出图”“已渲染”“已审核”必须有对应的 Tool 结果或实际可检查的交付物。不能把文字方案伪称成三张已生成素材。

## 交付前核对

1. **内容与权属**：产品/报价/效果主张有来源；商标、图片、人物、音乐和字体的使用范围适用于该渠道。竞品素材只能作为分析线索，不复制具体创意。
2. **视觉表达**：主体、品牌识别、信息层级和 CTA 与 brief 一致；删去无助于转化或理解的模板装饰。避免图像文字错字、裁切主体、遮挡 CTA、失真或生成瑕疵。
3. **版位可读性**：按当前渠道 Tool schema 或用户给定规格检查比例、格式、安全区域、字幕、首帧和小屏文本；无法核验的规格标为待确认，不编造通用像素或字数门槛。
4. **反馈与修订**：指出可观察的问题、影响和最小改动，再复查变更。只看过提示词或提交状态时不能打“视觉验收通过”；没有预览或自动检查能力时明确列出人工审核项。

本参考不调用网页、设计脚本、生成模型或 Provider API。生成、预览、上传和广告绑定各自走已注册 Tool 及相应授权；上传或生成成功不等于渠道审核通过。
