# 来源归属

这是本仓库的一个原创性咨询类 Skill。其图表选择、标签标注、无障碍性及误导性可视化检查受到
[`data-visualization`](https://github.com/anthropics/knowledge-work-plugins) 和 `validate-data` Skill 的启发，
这些 Skill 位于
[Anthropic 的 knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins) 中。
其证据到来源的映射以及显式的缺失处理受到了
[NousResearch 的 Hermes Agent](https://github.com/NousResearch/hermes-agent) 中
`grounded-citations` Skill 的启发。

仅提炼了高层级方法。未包含任何上游 Skill 的文本、脚本、连接器、来源账本、资产、凭据或可执行代码。
上游项目分别采用 Apache-2.0 和 MIT 许可证；请参见
它们的[许可证](https://github.com/anthropics/knowledge-work-plugins/blob/main/LICENSE)
和[许可证](https://github.com/NousResearch/hermes-agent/blob/main/LICENSE)。
