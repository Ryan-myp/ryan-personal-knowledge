# 生命周期测量与 cohort 口径

## 指标定义

每个指标必须注明对象、事件、分母、窗口、时区、来源、去重和成熟度。

| 指标 | 推荐定义要点 | 常见误读 |
|---|---|---|
| 激活率 | 在规定时间内完成预定义价值行为的合格新用户 ÷ 合格新用户 | 把注册、安装或打开 App 当作已激活 |
| Time to value | 从合格起点到首次完成价值行为的时间分布 | 只报告平均值而掩盖长尾或未激活者 |
| Cohort retention | 同一获客/首用 cohort 在固定周期内再次满足活跃定义的比例 | 把不同 cohort、日历窗口或活跃定义混为一谈 |
| 复购/续费 | 到期/可复购人群中，在规定宽限窗口内成功复购/续费的比例 | 把自动续订尝试、支付失败重试当作成功收入 |
| 贡献价值 | 同币种和一致成熟窗口下，收入扣除退货、变动成本、优惠和履约后的贡献 | 用广告平台收入或未成熟预测代替财务结果 |

## Cohort 设计

- 优先用获客/安装/注册/首购等可解释的 cohort 起点；按渠道、活动、地区、产品版本等维度比较前先检查定义一致性和样本规模。
- 固定观察窗并处理迟到数据、退款、订阅宽限期、跨时区和重复身份。窗口尚未成熟时标成暂定，不与成熟 cohort 直接比较。
- 保存自然流失、非活跃、支付失败、主动取消和无数据等不同状态，避免统称为 churn。
- 估算 LTV 时展示观察期、毛利口径、留存/续费假设、折现/成本和不确定性；不以预测结果覆盖已观测 cohort 事实。

## 触达评估

一次触达的评估至少包括适用人群、对照/留出、发送/展示资格、抑制条件、主结果指标、负向护栏、观察窗口和成本。打开率/点击率可作诊断指标，不能替代激活、留存、复购或增量贡献。没有对照时，只能报告前后变化或关联，不能归因于触达本身。
