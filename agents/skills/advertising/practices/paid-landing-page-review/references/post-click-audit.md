# 付费流量 Post-click 审查

## 广告到页面匹配表

| 维度 | 广告侧 | 页面侧 | 判断 |
|---|---|---|---|
| 受众 | 广告面向谁、基于什么情境 | 页面是否继续对这类人说话 | Match / mismatch / unknown |
| 问题与价值 | 广告提出的问题和主要收益 | 首屏是否快速回应同一需求 | Match / mismatch / unknown |
| 主张与证明 | 效果、功能、比较或社会证明 | 页面是否给出适用的证据和条件 | Verified / unsupported / unknown |
| 优惠与条件 | 价格、折扣、试用、资格或期限 | 页面是否兑现并解释条款 | Match / mismatch / unknown |
| CTA | 广告要求采取的动作 | 页面主要 CTA 和后续步骤 | Match / mismatch / unknown |
| 测量 | 点击、目标事件、归因口径 | 事件是否定义清楚且结果成熟 | Aligned / mismatch / unknown |

## 审查优先级

1. **承诺缺口**：广告明确承诺的优惠或结果在页面缺失、矛盾或带有未披露条件。
2. **行动缺口**：页面目的不清、CTA 冲突、表单/结账步骤不明，或材料显示存在真实错误。
3. **证据缺口**：重要效果主张缺少证明，或信任标志无法核实。
4. **相关性假设**：页面信息与受众情境存在可测试但尚未证明的匹配问题。
5. **测量缺口**：事件、来源、分母、窗口或设备划分不足以判断页面效果。

每条发现标注：

- **Observed**：在已提供或已授权读取的内容中直接看到的事实。
- **Inferred**：基于观察推导的解释，注明其他可能原因。
- **Unknown**：所需内容或数据不可用。

## 建议格式

| 优先级 | 观察/假设 | 证据 | 建议 | 验证方法 | 所需数据 |
|---|---|---|---|---|---|

没有基线或实验数据时，不量化转化率提升。广告文本和落地页同时改动时，不宣称能从结果判断哪一项造成变化。
