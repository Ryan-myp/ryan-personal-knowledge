# 创作者评估与合作检查表

## 筛选矩阵

| 维度 | 观察证据 | 待确认项 |
|---|---|---|
| 目标受众契合 | 内容主题、公开互动中的问题与受众自述 | 媒体包中的地域、年龄、客户画像及其统计口径 |
| 内容质量 | 真实性、清晰度、稳定性、品牌/产品表达能力 | 是否可按目标规格交付、是否需额外制作成本 |
| 互动质量 | 评论相关性、互动持续性、公开异常变化 | 平台后台触达、观看完成率、真实性审核结果 |
| 品牌安全 | 公开内容、争议、竞品合作及品类冲突 | 搜索范围、审核截止时间、紧急下架流程 |
| 商业适配 | 过往商业合作、内容形式、受众反馈 | 历史活动数据及是否可验证 |
| 成本与权益 | 报价、交付数量、使用授权范围 | 付费广告权、白名单、期限、地区、独家与续展费 |

不要把无公开数据当成负面事实。粉丝量、互动率和报价都要记录来源及日期；未经创作者或平台后台验证的指标标为自报或未知。

## 合作前检查

- [ ] 目标和主要 KPI 已定义，且不是只用曝光/点赞衡量销售效果。
- [ ] 交付物、平台、格式、发布时间、链接/代码及复审方式明确。
- [ ] 费用、佣金、赠品、税务/付款责任和取消条件明确。
- [ ] 版权归属、自然发布授权、付费广告授权、白名单权限、期限/地区/修改权逐项约定。
- [ ] 披露义务、事实主张证明、禁止表述和监管审查写入 Brief/协议。
- [ ] UTM/优惠码/落地页已在上线前测试；负责团队确认 CRM 或订单质量验证方式。
- [ ] 数据和素材只按约定目的、权限和保留期限处理。

## 复盘字段

记录目标、费用、交付完成情况、披露与授权状态、触达/观看（标明来源）、点击、GA4 聚合会话/事件、CRM 合格线索或订单、退订/退款、素材复用成本、样本和时间窗口。分别标记平台归因、优惠码、问卷自报和增量实验结果；不可把它们简单相加。
