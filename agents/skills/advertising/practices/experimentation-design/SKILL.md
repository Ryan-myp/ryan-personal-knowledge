# 广告实验设计

本 Skill 将广告和创意问题整理成可验证的实验方案。它补充 Wiki 的《广告实验设计、学习期与放量方法》与 `creative-strategy`，不替代平台实验功能、统计软件或账户报表。

## 设计流程

1. **明确决策。** 写清实验结果将改变什么业务决策，以及当前观察到的问题和证据来源。只有“想看看哪个更好”时，先补目标和当前状态。
2. **定义可检验假设。** 采用“基于什么观察，我们认为对什么对象做何种改变，会影响哪个结果”的形式；标明机制假设和可能的替代解释。
3. **锁定设计。** 指定实验单位、分配方式、对照、唯一主要变化、目标人群、主指标和业务护栏。广告实验特别检查受众重叠、预算/竞价耦合、素材轮播不均及跨组污染。
4. **事前规划。** 记录基线、业务上值得检测的最小差异、样本或预算规划方法、归因窗口、观察周期、重复查看/多重比较处理和停止规则。缺少必要数据时列出待补输入，不编造样本量或固定周期。
5. **按计划解释。** 一起报告效应量、不确定性、样本成熟度、护栏和数据质量。区别统计证据、业务价值与因果结论；把未达规划样本的结果标为初步或不确定。
6. **沉淀学习。** 记录结论适用的人群、渠道、时期和设计限制，并把下一步写成新的可证伪问题。

按需加载 `references/test-design.md`，用于实验设计卡、样本规划输入及结果解释。

## 结论边界

- 固定样本设计不得因中途领先而随意提前停止；只有事先设计的序贯方法或明确的安全停止规则例外。
- p 值不是“结果由随机造成的概率”，置信区间也不能脱离其统计设计解释为某个具体参数的后验概率。
- 未随机或未充分控制混杂时，应说明这是观察性或准实验分析，不能称为随机实验的因果结论。
- 当样本不足、数据未成熟或主指标/分组口径变更时，不能判断统计胜出；“不显著”也不自动等于两方案相同。
- 不为追求显著性而事后更换主指标、切分人群或拉长测试；探索性发现须标注并独立验证。

## 执行边界

- 只使用当前 Run 中可用且获准的证据；账户结果、分流状态和数据完整性未知时必须明确标记。
- 本 Skill 只生成实验方案、分析框架或复盘草案，不创建、修改或发布广告，也不自行启动平台实验。
- 需要查询或执行时只能使用当前已注册 Tool，并遵循其权限、账户范围、确认、幂等和审计规则；没有相应 Tool 就说明能力缺口。

## 输出要求

给出决策问题、证据与假设、实验单位和唯一变化、主指标/护栏、规划所需输入、分配与停止规则、成熟度和限制，以及结论后将采取的决策。清楚区分已知事实、设计假设和待补数据。
