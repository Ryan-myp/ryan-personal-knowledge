# 广告优惠与单位经济

本 Skill 判断优惠机制、价格呈现和广告主张是否与目标人群、转化路径及单位经济匹配。它补充 `ad-copywriting`、`paid-landing-page-review`、`ecommerce` 与 `measurement-attribution`。若问题是长期 SaaS 价格层级或价值计价，先转到产品定价策略；若主要是广告文案表达，使用文案 Skill。

## 分析流程

1. **确定业务模型与决策。** 确认产品、目标客户、新客/老客、国家/币种、获客或利润目标、促销窗口和用户要决定的是折扣、赠品、组合、价格锚点还是付款方式。
2. **收集基准经济数据。** 按产品/订单/订阅周期列出标价、净收入、商品/服务变动成本、履约/支付费用、退款退货、当前优惠、广告成本、复购/续费和数据窗口。字段不全时先标明情景假设，不填行业均值。
3. **拆解优惠机制。** 记录适用人群、触发条件、折扣/赠品/捆绑规则、最低消费、有效期、库存/容量、退款与叠加规则、排除对象和广告/落地页承诺。区分价格下降与价值/风险/时间成本改善。
4. **计算边际影响。** 在同币种和同口径下比较基线与优惠方案的净收入、贡献毛利、每单优惠成本、盈亏平衡 CAC/ROAS、回收期和所需转化提升。把折扣成本、自然购买被补贴、退货、履约及新客质量都纳入；显示公式、输入来源和敏感假设。
5. **核对客户与渠道匹配。** 检查优惠是否针对真实阻力，广告承诺与落地页条款是否一致，优惠是否吸引低质量或只在折扣时购买的用户。区分新客、存量客户、地区、产品和渠道，避免让不相关人群承担同一结论。
6. **设计小型验证。** 设定一个主变量、可比人群/留出、主指标、毛利/退款/续费等护栏、促销结束后的观察窗口和停止规则。转化率上升不能单独判定优惠成功。
7. **给出决策。** 比较不促销、轻优惠和目标优惠的情景；注明哪个数据会改变结论、最大可接受成本和复核责任。不得把预测写成已实现结果。

按需加载 `references/offer-unit-economics.md`，核对公式、折扣成本与实验护栏。

## 边界

- 只使用当前 Run 中可见的用户数据、授权 Tool 结果或清楚标记的假设；无成本/毛利信息时不能给出可靠的最大折扣或 break-even。
- 不虚构原价、稀缺、销量、客户评价、效果保证或“价值金额”；真实库存和期限才可用于稀缺表达。
- 本 Skill 不修改广告预算、商品价格、网站、优惠码或平台促销，不发布优惠；实际变更仍要由有权限的 Tool 和确认流程执行。
- 法律、税务、消费者保护、自动续费及地区促销规则需由业务与法务按当地要求复核。

## 输出

列出基准和方案假设、优惠机制、贡献毛利/盈亏平衡比较、对转化与用户质量的预期路径、证据与未知、测试设计及最大成本/停止规则。没有可靠输入时只给计算框架，不给伪精确答案。
