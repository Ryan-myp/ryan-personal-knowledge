# Hook 到业务结果的诊断

先定位有证据支持的漏斗断点，再决定是否重写整条广告。指标必须按当前平台报表的真实定义使用；并非每个平台/报表都提供视频阶段指标。

| 阶段 | 可用信号举例 | 首要问题 |
|---|---|---|
| 停留（stop） | 前段观看、thumb-stop、首帧互动 | 开场画面和主张是否吸引目标受众？ |
| 留存（stay） | 持续观看、hold rate、完播 | 正文有没有兑现 Hook 的开场承诺，还是突然转成产品推销？ |
| 点击（click） | CTR、有效外链互动 | 价值主张是否清楚可信，下一步是否相关？ |
| 转化（convert） | 落地页转化、合格线索、购买、App 事件 | 页面是否接住广告承诺，测量链路是否健康？ |
| 价值（value） | 毛利、留存、复购、下游线索质量 | 获得的是有用业务结果，还是只有低成本互动？ |

这些是诊断假设，不是通用基准。比较变体前要核对日期、投放、受众、版位、归因窗口、事件成熟度和样本。前段注意力高、下游转化差，可能代表 Hook 误导或吸引了不合适的人，不能单独算赢家。

下一轮测试只改变一个主要创意元素，并提前写出预期影响哪个指标。如果同时换了 Hook、画面、正文、优惠、受众和落地页，应记录为新概念，不能将结果归因于单个组件。更换 Hook 时也要检查后续内容能否兑现它的承诺。

保留用户/客户对主张和措辞的来源；不编造证明、不做无依据的前后对比，也不复用其他广告主的独特创意。平台规格与政策以当前渠道 Skill 为准。
