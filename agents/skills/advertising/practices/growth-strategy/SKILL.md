# 增长策略与渠道组合

本 Skill 帮助业务判断下一步的增长瓶颈和可测试路径，不默认把问题导向付费广告。它连接
SEO、生成式搜索可见度（GEO）、内容、付费获客、ASO、转化优化、推荐/合作、产品驱动增长
与生命周期运营；只选择与业务阶段和证据相符的方向，不要求每个业务都覆盖所有渠道。

## 决策流程

1. **明确目标与约束。** 确认产品、目标客户、市场/语言、增长阶段、商业模式、决策窗口、
   可用团队与预算。区分增长目标是有效获客、激活、收入、留存还是回收期。
2. **先定位漏斗瓶颈。** 按认知/需求发现 → 访问 → 转化 → 激活 → 留存/复购 → 推荐检查
   可见证据。没有可靠数据时，把问题写成待验证假设，不把漏斗图当成已证实的根因。
3. **筛选少数合适路径。** 按用户如何发现、比较、购买和持续使用产品，比较自然搜索 SEO、
   GEO、内容、付费媒体、ASO、合作/推荐、产品内增长、生命周期触达和 CRO。搜索流量适合
   有明确问题需求且能持续提供有用页面的业务；推荐或产品驱动路径需存在真实分享/协作价值。
4. **比较投入与反馈。** 对每个候选方向记录目标人群/漏斗阶段、所需资产与团队、首次有效信号
   可能需要的时间、可控性、测量依赖、主要风险和可复用/复利潜力。成本包含制作、工程、数据
   与维护，不只包含媒体费。
5. **形成组合与实验。** 选一个主要瓶颈和少量并行测试，写明假设、领先指标、业务结果指标、
   护栏、观察周期、归因限制与停止/继续规则。把已观察事实、推断、未知和反证条件分开。
6. **按需交接专门方法。** SEO 进入 `seo-growth`，AI 搜索引用进入
   `generative-search-visibility`，App 漏斗进入 `app-growth`，广告账户诊断进入
   `account-diagnostics`，实验与效果归因进入相应测量 Skills。

## 边界与输出

- 没有已授权且实际返回的数据时，不声称已访问网站、搜索控制台、CRM、分析系统或广告账户。
- 搜索结果摘要不能替代完整网页、站点爬取或结构化流量数据。
- 不以单一渠道、流量或点击量等同于增长；不保证排名、引用、线索、收入或投资回报。
- Skill 只给分析和实验草案，不新增 Tool、权限、外部账户访问或自动化写操作。

输出优先包含：目标与阶段、已知瓶颈及证据质量、候选路径比较、优先级/投入、实验指标与
护栏、关键未知及下一步。证据不足时明确说明当前只能提出假设。
