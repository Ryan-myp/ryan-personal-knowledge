# 付费媒体循环契约

在创建或修订任何定期 Agent 任务之前，请使用此检查清单。

| 契约项 | 所需定义 |
|---|---|
| 目的 | 一项业务成果及该检查所支持的决策 |
| 责任主体与范围 | 受信任的负责人、允许的账户/平台范围以及排除项 |
| 输入 | 已注册的读取 Tool、字段、报表时间窗口、时区、新鲜度、完整性 |
| 频率 | 由数据刷新、转化延迟和决策延迟所决定的执行频率 |
| 决策条件 | 生成 HOLD、FIX、TEST 或 INVESTIGATE 所需的证据 |
| 操作级别 | 只读报告、分阶段提案，或明确获批的有界写入 |
| 幂等性 | 每次触发的唯一标识，以及在必要时针对业务操作的去重/冷却机制 |
| 停止条件 | 数据缺失、范围未知、页面不完整、Tool 故障、策略问题、未知写入结果 |
| 恢复 | 在重试任何可能已成功执行的写入之前，先读回验证 |
| 结果 | 发现项、证据、覆盖缺口、已分阶段的操作，以及运行/任务引用 |

调度器的唯一运行记录可防止将两次触发误视为同一次执行，但它本身无法对跨独立运行重复发生的业务操作进行去重。如果循环需要持久化的跨运行状态，且没有已注册的存储能力提供该支持，则保持循环为只读模式。

## 可复用的只读循环示例

| 循环 | 推荐读取 | 对齐与停止条件 |
|---|---|---|
| 付费投放周检 | 已授权广告平台报表；如有需要再读取 GA4 来源/媒介、Campaign、会话、key event 和收入聚合 | 对齐账户时区、日期成熟度、转化定义及归因窗口；GA4 与平台数字分列报告，缺少交易/CRM 验证时不声称真实收入或增量 |
| SEO 查询与落地页复盘 | Search Console 按 date/query/page/device 的 clicks、impressions、CTR、position；必要时读取 GA4 着陆页聚合会话与 key event | 查询数据存在匿名/长尾缺失且报表延迟；检查日期范围、搜索类型和分页。无页面抓取证据时不推断页面技术原因 |
| 转化追踪健康检查 | GA4 受支持的聚合 metric 和维度，配合人工提供的 CRM/订单聚合及事件 QA 证据 | GA4 Tool 不检查 Pixel、GTM、CAPI 是否发送成功；来源数据缺失或时间窗未成熟时，报告“未知”并停止性能归因 |

这些循环只有在对应 OAuth scope、Property/站点权限及注册 Tool 可用时才可读取。Scheduler 仍由同一 Agent Runtime 执行；每次读取都受当前账号授权、Tool 权限、超时和返回行数限制。没有持久跨运行状态时，仅输出报告和待审核建议。

## 安全默认值

```text
读取当前证据
  -> 验证完整性与成熟度
  -> 与已声明的决策条件进行比对
  -> 报告证据及建议的下一步
  -> 在外部变更之前等待明确批准
```

不要将缺失的报表行、过期结果、失败的 Tool 调用或尚未成熟的转化窗口视为零值。不要仅基于单一噪声指标就暂停、扩缩容或轮转营销活动。
