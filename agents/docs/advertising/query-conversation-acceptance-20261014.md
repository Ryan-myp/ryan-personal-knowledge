## 修复的契约

- 模型、Tool、Provider HTTP、MCP、回合配置与任务执行默认超时统一为 500 秒。
  模型重试、回退和退避共用同一次模型调用的期限，不重置 500 秒窗口。
- SDK 自动重试关闭，由 Harness 的有界重试处理 429、连接错误与临时服务错误；
  尊重数值 `Retry-After`。已经输出部分流式内容时不自动重播。
- 明确查询请求要求本轮新 Tool 调用；能力介绍、历史总结不强制查询。
- 资源复合名词从动词判断中隔离，避免把 `ad set`、`assets` 误判为写操作。
- 账户目录按声明的返回 ID 字段与配置、principal 授权范围过滤。TikTok 声明
  `advertiser_id`，并在调用前拒绝未授权的账户集合。
- 已选择且获准访问的账户为短追问提供渠道上下文；明确渠道切换仍优先，
  未授权或跨渠道同名账户不自动推断权限。
- 模型只接收有界预览和明确计数；API 保留在 Tool 输出上限内的完整结果。
- Run 状态包含早先 Tool 的执行失败，不因最后一轮模型仅输出文本而误报成功。
- Google Campaign 详情使用同一次 GAQL 查询返回关联预算。
- TikTok 的 Ad-backed Creative 使用数字 Ad ID，不将视频或图片 ID 发送到 Ad Get。

## 权限与失败恢复

身份和授权来自可信 principal/configuration，请求账户是待校验目标而非身份。
所有读取仍经过账户范围和资源归属检查，未放宽白名单或 live 写入门禁。
模型重试不重启已执行的 Provider 操作；相同读取的合并与写入的幂等保护保留。
模型/Provider 持续不可用仍报告失败，不声称查询为空或成功。

## 发布说明与边界

更新的部署需重启进程以加载默认值、Tool metadata 和模型策略；无需保留旧 import
或双份执行入口。无广告数据迁移，本轮没有创建/更新/删除广告。
回滚代码时同时恢复 Tool 契约快照和超时配置，再重启；不涉及外部资源回滚。
本轮复用结构化 Run、Tool 和 HTTP 证据，不依赖新增观察性平台。

此验收不代表每个查询 API、所有广告类型及写入操作都已穷尽验证。Google Ad 列表
回合仍附带了一次不必要的关键词读取；Meta Ad 详情同时查询了关联 Creative。
