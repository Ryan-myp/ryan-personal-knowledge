# 知识库与 Skills 编辑支持

知识库和 Skills 的列表、详情均提供明确的“编辑”入口。内置内容可以从完整原文开始修改，保存为租户管理的新版本；已发布内容不会被原地覆盖。

## 编辑与发布

| 资源 | 保存行为 | 发布与恢复 |
| --- | --- | --- |
| 内置知识 | 读取完整正文，保留分类、来源、置信度、关联页面等元数据；保存为草稿，记录 `derived_from=builtin:<原文 ID>` | 发布后在当前租户的知识目录和检索中替代内置原文；下线后恢复原文 |
| 自建知识 | 未发布草稿可修改；当前或曾经发布的版本另存新版本，未提供的元数据保持不变 | 同标题或同内置来源只保留一个当前发布版本；旧版本仍保留 |
| 内置和自建 Skill | 保留整个标准包，包括 `SKILL.md`、`references/`、`assets/` 等文件；自动建议未使用的 patch 版本 | 沿用现有校验、适用的评测门禁和发布链路；下线不会删除快照 |

保存失败时保留编辑内容；Skill 发布、下线成功提示在列表刷新后仍可见。知识校验补齐现有目录已经使用的 `decision_framework` 和 `test_account_e2e` 分类，不修改 API 字段或平台术语。

## 接口与权限

- 新增 `GET /knowledge/builtin/{document_id:path}`：要求 `knowledge.read`，按精确 ID 读取已加载的内置文档，返回完整 `content`。不会把输入当作文件路径读取。
- `PUT /knowledge/documents/{document_id}` 沿用 `knowledge.write` 和可信租户身份，忽略请求中未提供字段的默认值，避免编辑正文时覆盖其他元数据。
- 知识发布先确认目标属于当前租户且未归档。目标不存在、属于其他租户或已归档时，不会下线当前有效版本。
- Skills 沿用现有管理接口和 `skills.write` / `skills.publish` 权限。用户文件只作为 advisory 上下文保存；不执行脚本、不注册 Provider Tool，不改变账户或凭证权限。

## 存储、失败恢复与回滚

沿用既有 store 和 SQLite 数据库，不迁移 schema，不直接修改部署目录下的内置 Markdown。修改关系使用现有 `derived_from` 字段；内置知识的修改版保存在当前租户的持久化记录中。

知识修改版可下线并恢复内置原文，旧的托管知识版本可重新发布。Skill 可发布原有快照回滚。代码回滚前应先下线需撤回的内置知识修改版：旧代码不认识其替代关系，可能同时检索原版和修改版。

部署继续使用原配置、原数据库和 `0.0.0.0:8766`。重启前进行 SQLite 在线备份，并对比模板和历史会话身份集合。无需新增观察性系统；沿用现有发布状态、版本和管理错误响应。

服务已更新并就绪。重启前后均为 514 个会话、14 个用户模板、354 个配置化 Tool，最近 200 个会话 ID 和全部用户模板 ID 保留。线上新增全文接口可用，四个编辑相关 JS 与工作区文件一致，资源版本为 `071e4746c81abb571a583571`。隔离浏览器测试服务已关闭，未向正式知识库或 Skill 管理写入测试内容。
