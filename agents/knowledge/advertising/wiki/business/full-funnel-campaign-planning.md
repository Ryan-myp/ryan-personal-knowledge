# 从业务目标到投放方案的全漏斗规划

完整的投放方案不是先选平台或 Campaign 类型，而是从业务结果倒推媒体任务。平台目标是优化信号和交付机制，不等同于公司的业务目标；平台归因转化也不自动代表新增客户或新增利润。

## 规划顺序

```text
业务约束与目标
  -> 目标人群与购买情境
  -> 产品/报价与证明
  -> 用户旅程和漏斗断点
  -> 可观测的优化事件
  -> 渠道在旅程中的职责
  -> 预算、素材、落地页与销售供给
  -> 测量、实验与停止/扩量条件
```

先写清楚要改变的业务结果，例如新增有效客户、贡献利润、合格商机、首次订阅或留存，而不是只写“增加流量”。再确定时间窗口、市场、库存/服务能力、可承受现金投入、价格/毛利和禁止触碰的合规边界。

## 业务指标到媒体信号

| 业务结果 | 可观测的近端信号 | 最终验收 | 主要风险 |
|---|---|---|---|
| 电商新增利润 | 商品详情、加购、结账、购买价值 | 退款后贡献利润、新客质量、复购 | 平台收入不含完整成本或退款 |
| App 高质量用户 | 安装、注册、关键行为、订阅/付费 | 留存 cohort、回收期、生命周期贡献 | 安装便宜但留存和付费弱 |
| B2B 商机 | 提交、可联系、MQL、SQL | 机会、成交、合同毛利 | 表单量不能代表线索质量 |
| 本地预约 | 电话、表单、预约 | 到店/履约、服务收入和容量 | 线索响应慢或服务范围不匹配 |
| 订阅增长 | 试用、激活、首付 | 留存、续订、退款后 LTV | 试用数上升但付费转化下降 |

优化事件应在“平台可稳定观测”与“业务确实关心”之间取舍。业务最终结果稀疏、延迟较长时，可以选择更靠前的稳定代理信号，但必须保留代理信号与最终结果之间的回传和质量评估；代理信号变多不代表业务目标已达成。

## 渠道与漏斗角色

渠道角色要根据市场中的需求形成方式、素材供给、库存和测量能力来确定，不要固定套用“搜索只收割、社交只种草”等标签。

| 规划问题 | 设计要求 |
|---|---|
| 用户何时意识到需求 | 区分主动搜索、被内容激发、比较评估、复购/召回 |
| 当前最大漏斗断点 | 用可观测指标定位，不同时把曝光、页面、报价和销售都列为首要问题 |
| 渠道承担什么工作 | 写出目标人群、触达情境、期望行为和与其他渠道的关系 |
| 目标如何映射平台 | 先确定业务事件，再按当前账户可用的目标、优化事件和 Tool schema 配置 |
| 落地页兑现什么承诺 | 广告中的价格、利益点、资格、地区和 CTA 必须在页面真实可见 |
| 哪些结果不能只看平台 | 新客、合格线索、退款、毛利、留存和增量需接入 CRM、订单、财务或实验 |

## 预算和实验拆分

预算先按“学习与供给的最小可用单元”分配，再根据成熟数据和边际结果调整；不要仅按平台数量平均切分，也不要因某个平台历史平均 ROAS 较高就把新增预算全部迁入。

1. 给每个单元定义任务、主指标、保护指标、预算上限和成熟数据所需窗口。
2. 预留可解释的探索预算；探索单元不足以得到有效观察时，不要同时堆入过多受众、创意或事件组合。
3. 首轮只验证一个主要假设，例如报价、素材角度、市场或落地页；其余条件尽量保持稳定。
4. 按事件延迟和业务周期判断数据是否成熟；未成熟数据标为暂定，不进入自动扩量判断。
5. 扩量前检查商品、现金流、库存、履约、客服/销售容量及毛利护栏。
6. 预先写出停止条件和回退动作；数据质量失效时先暂停策略结论，不把缺失值解释为零。

## 投放 Brief 模板

```text
业务结果：
市场 / 人群 / 需求情境：
产品或报价及其限制：
漏斗断点和已有证据：
主优化事件及其与业务结果的关系：
渠道职责与选择理由：
预算上限 / 币种 / 时间窗：
素材假设与落地页承接：
主指标 / 保护指标：
数据来源 / 延迟 / 归因边界：
实验单元 / 样本充分性 / 停止规则：
风险 / 供给约束 / 回退条件：
上线后 readback 与复盘责任人：
```

Brief 缺少业务结果、事件定义或停止条件时，应先补齐决策上下文，不用“行业平均 CPA/ROAS”替代账户证据。涉及具体平台目标、枚举、字段和可创建组合时，必须再查询该账户对应的当前平台文档和 Tool schema。

## 常见规划失误

- **目标混层**：把 Campaign objective 当成业务 KPI，或把 Ad Set/Ad Group 优化事件当成最终结果。
- **代理信号失真**：为了取得更多优化事件而降低质量，没有 CRM/订单回传验证。
- **预算先行**：先拆很多 Campaign，再寻找每个单元要回答的问题，导致预算和样本被稀释。
- **渠道末次触点偏差**：将平台各自归因结果直接相加，重复计算同一订单或忽略自然需求。
- **供应未对齐**：扩大媒体前没有确认库存、价格、页面、配送、服务或销售响应能力。
- **没有退出条件**：没有说明什么证据会推翻假设，导致“继续观察”无限延长。

## 复盘判断

复盘按四个问题组织：计划中的用户和任务是否真的被触达；优化事件是否可靠且及时；漏斗哪一段发生了可验证的变化；新增花费是否改善了业务价值并且可承接。将结果分别标为平台归因、后端确认、观察性变化或因果实验，不能互相替代。

方法参考：本条是跨渠道规划框架，不是某个平台的字段或性能保证。涉及平台内目标与实验能力时，应回到相应官方文档、账户实际报告和当前 Tool schema 核验。
