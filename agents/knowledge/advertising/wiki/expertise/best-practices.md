# 广告最佳实践

> **性质**：跨账户的运营决策护栏，不是平台保证、统一账户标准或效果 benchmark。
> **更新时间**：2026-10-19

## 账户结构与命名

命名应帮助运营者识别业务目标、市场、产品/受众主题、素材版本和时间范围。优先服从团队命名规范，避免把 PII、令牌、客户机密或会快速过期的状态写入名称。

结构粒度由独立预算/出价控制、市场或合规边界、素材/落地页差异、优化事件和报表可解释性决定。达到这些隔离需求后，优先采用较简单、可测量的结构；不要为“看起来精细”而过度拆分，也不要把目标、市场或落地页显著不同的单元混在一起。

Campaign、Ad Group/Ad Set、Ad 和 Creative 的含义与可变字段因平台而异。结构方案应以各平台专题和当前 Tool schema 为准，不把一个渠道的层级规则推广到其他渠道。

## 预算与实验

开始测试前，先明确：

- 业务允许的最大测试损失、总预算上限和运行周期。
- 主假设、唯一主要变量、主要结果指标及成本/质量/政策保护指标。
- 优化事件、预计转化延迟、样本不足时的处理方式和停止条件。
- 多单元之间是否需要独立预算，还是允许平台自动分配预算。

不设跨账户通用的每日预算、活跃广告组数量、预算占比或 ROAS 提升承诺。可用预算取决于可承受损失、商品/线索经济性、目标市场、事件量、竞价、交付容量和实验设计。若预算不足以支撑计划中的比较，应减少同时测试的变量或延长观察时间，而不是伪造确定性。

放量时比较新增投入的边际结果与预先定义的护栏，并核对转化成熟度、退款/线索质量、库存和履约容量。一次只做一个主要变更，记录变更前后配置、开始时间、预期方向和回退条件。短期波动或未成熟数据不单独构成放量/暂停结论。

## 出价与优化

- 先确认优化目标与业务结果一致，事件定义、去重、价值、隐私/同意状态和数据回传足够可信。
- 目标成本/回报应来自毛利、LTV、现金流和可接受的获客成本；平台目标值是控制信号，不是效果保证。
- 区分“没有资格交付”“交付不足”“转化成本差”和“测量不完整”。先排查审核、预算、排期、受众/库存、素材、落地页和事件，再调整出价。
- 修改出价策略、目标或优化事件前，检查当前账户支持的字段、继承关系、状态和平台学习影响；动态能力以官方文档和 Tool schema 为准。

## 搜索与商品流量

- Search 关键词、匹配方式、搜索词和否定词应结合用户意图、落地页、查询可见性与转化价值评估；不要只凭 CTR 或一个短窗口删词。
- Shopping/PMax/Catalog 的资格问题先查商品 ID、价格、库存、市场、商品状态、目录关系、落地页和平台诊断，再判断是否需要改预算或出价。
- 报告受隐私阈值、归因窗口、刷新延迟和分段粒度影响；不可见查询或零行不能直接解释为没有需求或没有问题。

## 复盘与知识沉淀

每条可复用经验至少记录平台、目标、对象层级、账户/市场背景、观察窗口、事件和指标定义、样本/证据、前置条件、动作、结果、风险、失效条件与回退方式。单个账户案例只能形成待验证假设；跨账户复用前应再次检查适用性。

具体工作流请继续查阅 `business/evidence-driven-performance-diagnosis.md`、`business/budget-pacing-and-marginal-efficiency.md`、`expertise/experimentation-and-learning.md`，以及对应平台的 Search、Shopping、出价和测量专题。

## 质量护栏

本页不提供固定预算、固定结构数量、固定 CPA 倍数或承诺提升比例。建议必须说明适用边界、当前证据和停止/回退条件；无来源或样本范围的数字只能标为待验证假设，不能作为自动决策阈值。涉及平台动态字段、政策或策略枚举时，必须回查当前官方资料和 Tool schema。
