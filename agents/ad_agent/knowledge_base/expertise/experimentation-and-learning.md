# 广告实验设计、学习期与放量方法

## 实验卡片

每个实验预先写清：假设、实验单元、对照、唯一主变量、主指标、保护指标、分流方式、预算/样本门槛、运行周期、归因窗口、停止条件和负责人。若同时改目标、素材、受众、预算和落地页，结果只能作为探索观察，不能据此判断单一策略。

## 平台实验与业务实验

- 平台内 A/B 或 Experiment 适合比较出价、素材、受众或设置，需遵循平台可用的分流与报告口径。
- Geo/time/holdout 适合评估渠道或高归因人群的增量，但要控制季节、促销、供给与外部媒体。
- 观测性前后对比不能自动证明因果；报告中标注实验类型和不确定性。

## 学习期管理

学习期不是固定天数，也不是“不准动”的借口。关注数据量、事件稳定性、预算是否足够探索、频次、素材供给和近期改动。硬阻塞、政策、追踪错误要立即修复；非关键优化等到观察窗口结束，避免频繁重置系统。

## 放量阶梯

```text
小规模验证 -> 事件/创意质量确认 -> 稳定单元逐步扩量 -> 边际效率复核 -> 新市场/新受众实验
```

放量前确认库存、素材、客服/销售、页面和预算上限能承接新增需求。若花费增加但合格率、毛利、留存或增量下降，应暂停扩量并回到漏斗诊断，不用总转化量掩盖质量损失。

## 样本与停止规则

实验开始前写明最小可检测差异、预期基线、显著性或不确定性口径、实验单位、分流比例、运行周期和停止条件。不要每小时查看并在偶然领先时停止；如果有强烈业务风险，可提前停止，但要标记为安全停止而非统计胜出。

当不能做随机实验时，使用匹配市场、Geo、时间序列或分层前后对比，并列出季节、促销、库存、价格、版本和媒体竞争等混杂因素。实验结束保留原始分组、变更日志和未成熟数据，防止只保存结论不保存证据。
