# TikTok 创意生命周期、Spark 与素材测试

## 创意生命周期

```text
创意假设 -> 生产/上传 -> 规格与政策检查 -> Ad 组合 -> 审核 -> 交付 -> 素材诊断 -> 迭代/淘汰
```

素材、Creative Portfolio、Identity、TikTok 原生 item、Spark 授权和 Ad 是不同对象。上传本地视频得到媒体资产，不代表获得 Spark 内容授权；Identity 可用不代表某个 creator item 可用；审核通过不代表有预算和库存交付。

## 素材角度矩阵

| 角度 | 内容结构 | 适合验证 |
|---|---|---|
| 问题/痛点 | 场景 → 失败代价 → 解决方案 | 痛点是否真实 |
| 教程/演示 | 结果预览 → 操作步骤 → CTA | 产品理解与信任 |
| UGC/证言 | 人物身份 → 使用过程 → 证据 | 原生感和可信度 |
| 对比/测评 | 选择标准 → 差异 → 结果 | 卖点是否有辨识度 |
| 优惠/时效 | 价格/权益 → 限时理由 → 行动 | 促销驱动与质量 |

每个角度至少变换 Hook、人物/场景、证据和 CTA 之一。只调整滤镜、背景或字幕颜色，通常不足以构成有效新假设。

## 前段信号与漏斗

前 1–3 秒决定用户是否继续。用前段观看、完播/有效观看、互动、CTR、LPV、CVR、CPA 和购买质量逐层观察：前段弱优先改 Hook；观看好 CTR 弱改卖点/CTA；CTR 好 CVR 弱查页面/事件；转化有量但价值差查人群和承诺。不要用一个 CTR 阈值淘汰所有业务类型和市场。

## Spark Ads

上线前必须确认 advertiser scope、creator/identity、item/post ID、授权有效期、互动保留、评论管理、落地页与 tracking。原生互动是资产价值的一部分，未授权不能通过普通上传视频替代或复制 ID。授权过期、内容删除、评论限制与广告审核失败要分开记录。

## 素材疲劳与生产节奏

疲劳需要结合频次、前段观看、CTR/CVR、负反馈、CPM、受众规模、季节和同角度占比判断。素材库按“角度 × Hook × 人物 × 产品卖点 × 语言”维护，建立可回滚版本，不要重复上传同一内容制造虚假新鲜度。生产节奏优先补新角度，其次才是微调表现稳定的版本。

## 当前执行边界

项目当前覆盖 TikTok 视频/图片/轮播/Lead/App/Spark、Creative Portfolio、Identity 和素材资产等部分 Tool。规格、授权、账号资格与 live 状态仍需以当前 Tool schema 和平台返回为准。
