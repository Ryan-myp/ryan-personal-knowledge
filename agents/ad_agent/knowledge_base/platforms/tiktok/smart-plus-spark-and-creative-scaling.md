# TikTok Smart+、Spark Ads 与创意规模化方法

TikTok 的自动化销售、应用或商品场景依赖事件质量、素材供给和足够的探索空间。Spark Ads 使用已有有机内容的授权和身份关系，普通广告使用独立素材；两者在互动资产、授权、评论语境和品牌风险上都要分别校验。

## 结构与职责

Campaign 承载目标和整体边界，Ad Group 承载预算、排期、定向、优化事件和版位，Ad 承载素材、身份、落地页和追踪。Smart+ 可能扩大系统对受众、素材或投放组合的自动探索，但不应绕过账户范围、资产授权、政策和事件校验。

## 素材供给矩阵

按 Hook、痛点/场景、证明、产品演示、优惠、CTA、语言、比例和时长建立素材矩阵。新素材需要记录创意 ID、来源、授权状态、角度、版本、首发时间和适用市场；不要只复制同一视频换字幕，否则系统看到的有效探索空间有限。

| 信号 | 可能原因 | 检查与动作 |
|---|---|---|
| 观看前段弱 | 首帧、Hook 或节奏不匹配 | 重做开头，保持后段变量不变 |
| 观看好、点击弱 | 卖点或 CTA 不清 | 在结果前置利益点与行动 |
| 点击好、转化弱 | 页面、事件或承诺不一致 | 查加载、深链、事件和页面 |
| 转化有、质量差 | 受众、人群承诺或事件过浅 | 对接有效率、付费和留存 |
| 频次上升、效率降 | 素材疲劳或容量受限 | 引入新角度或合理扩量 |

## 事件与学习

切换到更深层事件前，确认事件稳定到达、去重键一致、金额和币种正确、延迟可接受，并能在后端验证。Smart+ 或价值优化的短期波动不能只用一天数据判断；应按固定窗口观察事件漏斗、素材组合和 cohort 质量。

## Spark 风险检查

发布前确认有机帖子/身份授权、账号关系、评论与品牌安全、音乐/素材权利、链接和追踪。授权失效、原帖删除或内容编辑可能影响投放，恢复时先读线上创意状态，不能重复创建未知状态的广告。
