# 广告渠道组合、边际效率与统一决策口径

## 三套不能混用的口径

| 口径 | 适合回答 | 不能回答 |
|---|---|---|
| 平台归因 | 平台如何分配转化、用于优化 | 真实增量利润 |
| 归一化分析 | 渠道和市场的可比趋势 | 完整因果证明 |
| 增量/财务结果 | 是否带来新增利润 | 每次平台触点的细节归因 |

统一看板必须保留原始平台口径，同时计算归一化 spend、revenue、margin、CAC、LTV、payback 和增量结果。不要把四个平台的 reported conversion 简单求和。

## 边际而非平均

```text
边际 CPA = 新增花费 / 新增转化
边际 ROAS = 新增收入 / 新增花费
边际利润 = 新增贡献利润 - 新增花费
```

历史平均 ROAS 很高，可能只说明早期高意向流量有效；继续加预算后边际人群、频次、库存和创意质量都会变化。预算决策应观察阶梯放量的边际曲线，并设置品牌、客服、库存、毛利和增量保护指标。

## 渠道角色

Google Search 可承接显性需求，Meta/TikTok 可探索人群和创意，DV360 可做规模化媒体与程序化触达；实际角色取决于业务、市场、素材、事件和库存。不要只按渠道名称指定固定预算比例，先明确该渠道在漏斗中的可验证任务。

## 预算会议模板

每周回答：

1. 哪些单元花费达到样本门槛，边际效率仍然可接受？
2. 哪些单元被预算、审核、库存、定向或事件限制，而不是需求不足？
3. 哪些转化主要来自品牌/再营销，增量证据是否足够？
4. 新增预算需要什么素材、商品、销售或客服供给？
5. 如果主指标变差，先触发哪个保护指标和回滚动作？

## 归因与实验

对品牌词、再营销和高意向受众，优先设计 holdout、geo test、平台 lift 或时间序列分析。实验期间避免跨渠道同时大改预算、促销、页面和事件；若无法隔离变量，只能把结果标为观察性证据。

## 决策输出

Agent 给出建议时应同时输出：当前口径、数据窗口、主/保护指标、假设、建议改动的层级/字段、预期方向、风险、观察期、停止条件和回滚方式。没有数据时输出需要补充的查询与测量计划，而不是编造 benchmark。

## 预算分配计算

先把各渠道结果转换为同一业务口径：

```text
有效获客成本 = 媒体花费 / 后端确认的新增有效客户
贡献利润 = 收入 - 商品/履约/支付/退款/销售服务等可变成本
边际贡献利润 = 新增贡献利润 / 新增媒体花费
预算上限 = 可承受现金流、库存、履约和利润约束的最小值
```

渠道排序使用边际贡献和增量证据，不使用平均 ROAS 的简单排序。一个渠道可以平均 ROAS 高但已接近容量，另一个渠道平均值一般但新增预算仍有正边际利润；预算迁移需要记录迁移量、基线、预期、保护指标和回退条件。

跨币种、跨归因窗口、跨新老客和跨收入/毛利口径不得直接合并。无法统一时分别展示，不给出虚假的总排名。
