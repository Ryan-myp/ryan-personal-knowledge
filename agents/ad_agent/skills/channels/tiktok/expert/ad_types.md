# TikTok Ads 广告类型专家知识

## 1. Spark Ads（原生内容投放）

### 适用场景
- 品牌合作内容推广
- KOL/KOC 原生素材
- 用户生成内容（UGC）

### 核心配置
```yaml
campaign_type: SPARK_AD
ad_type: SPARK
source_video_id: "tiktok_video_id"  # 关联的 TikTok 视频 ID
```

### 专家提示
- 选择高互动率的原生视频作为素材
- 品牌账户发布的视频更适合 Spark Ads
- 可搭配 TikTok Creator Marketplace 寻找创作者

---

## 2. In-Feed 广告（信息流广告）

### 适用场景
- 品牌曝光
- 应用下载
- 网站引流

### 核心配置
```yaml
campaign_type: CONVERSION
ad_type: IN_FEED
video_url: "https://..."
```

### 专家提示
- 前 3 秒抓住注意力
- 竖屏 9:16 比例最佳
- 时长控制在 15-30 秒

---

## 3. TopView（开屏广告）

### 适用场景
- 品牌大曝光
- 新品发布
- 大型促销活动

### 专家提示
- 适合预算充足的 Brand Campaign
- 可选择音效开关状态
- 通常与 Hashtag Challenge 组合投放

---

## 4. Hashtag Challenge（话题挑战）

### 适用场景
- 病毒式传播
- UGC 内容征集
- 品牌互动

### 专家提示
- 设计简单易跟的舞蹈/动作
- 搭配 KOL 带动参与
- 设置激励机制提高参与度
